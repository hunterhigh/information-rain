# 分发 Demo 变更记录

记录本 Demo 每个可恢复版本与重要候选变化。仓库根目录 `CHANGELOG.md` 继续记录项目级变化。

## 0.4.2 — 2026-10-12

- 针对 iPhone Safari 首次下滑后白屏或卡住的反馈，iOS 封面改用轻量触摸切换路径，避免构建 61 页的 Swiper 纵向轨道；阻止封面下滑触发浏览器原生页面滚动。修复备用触摸路径在移动时提前清除手势的问题。该路径保留上下作品切换，但暂不使用 Swiper 的整屏跟手动画；真实 iPhone Safari 仍待所有者复测。

## 0.4.1 — 2026-10-12

- 修复进入世界前封面无法上下滑动切换作品：封面氛围图层不再拦截触摸，Swiper 在舞台显示后初始化，避免按零尺寸计算滑动。行为测试、内容审计和静态预览构建通过；本轮浏览器及手机真机触摸仍待复验。

## 0.4.0 — 2026-10-09

- 61 部作品均扩写或迁移为至少 10 个可达剧情节点，每个剧情节点最多左右两个选择。原有 23 部补写开篇与桥接情节；新增 38 篇扩写并重算代表审稿路径。结构审计为 1187 个节点、350 个结局、1646 条选择；文学实读仍待验证。
- 封面和阅读态统一为上滑下一部、下滑上一部，左右滑选择当前剧情。正文滚动到边界后再触发作品切换；键盘和桌面滚轮也遵循纵向作品导航。
- 启动时只装载简短作品元数据，进入作品时按需读取剧情，并预取相邻作品。预览封面延续 WebP 舞台图与缩略图；Tailwind 样式生成本地静态文件，避免运行时样式 CDN 阻塞。
- 内容 SHA-256：`2d819d8b47d0d8d980c442feeba33f39900e8a350f4737bbbb286a9a45bab58a`。手机真机完整手势验收与人类逐路径审稿尚未完成，本版仍是临时公开预览。

## 0.3.1 — 2026-10-09

- 静态发布时保留原始封面作为制作素材，只向读者提供按舞台尺寸压缩的 WebP 和小封面。61 张原图合计约 107.5 MiB，构建出的两档图片合计约 11.4 MiB。
- 运行时剧情和作品顺序未改变；内容 SHA-256 仍为 `bd313b8779f0a9f12615c389081fbe248d4d33724825b7bdd1d66009ca9f5caf`。

## 0.3.0 — 2026-10-08

## 0.2.0 — 2026-10-08

本版本汇总 `0.1.0` 之后已实施的分发 Demo 更新，并形成新的可恢复版本；已部署到 Cloudflare Pages 临时预览，手机真机验收仍待完成。

- 修正手机阅读态的触摸归属：舞台上的上下手势由应用统一处理，正文滚动到边缘后再交给上方分支或下一世界；切换时只预加载当前作品及相邻封面，避免首屏同时请求全部作品图片。
- 手机分支手势采用光流牵引：左、右、上拖动时整张阅读画面跟手，柔和光流沿拖动方向移动；移除手势过程中的浮动文字提示框。下滑作品切换逻辑保持整屏移动。
- 修复手机动效比较页的触屏拖动：手机优先由原生 Touch Events 驱动，鼠标和触控笔由 Pointer Events 驱动；多点触摸或系统取消时回弹清理。
- 将原先写在 HTML 的 19 部作品与四个注册作品统一存入内容池；展示顺序改由独立配置管理，网页只读取生成的作品目录，作品内容和封面未改动。
- 新增手机划动与场景转场动效比较页，可在同一 Cloudflare Pages 主域名下由手机和电脑访问；并列对照箭头基线、倾斜跟手、整屏移动、视差和方向提示，仅供选择，不改变主 Demo。
- 复用现有 Swiper 实现封面间触摸滑动；修复阅读态正文区域无法发起划动的问题，同时保留文本上下滚动、分支选择和作品切换之间的边界。
- 手机 9:16 舞台按可用容器尺寸等比放大并居中，给正文阅读更多空间，不改变桌面样式。
- 项目所有者于 2026-09-30 确认当前展示的作品均已通过审查；新加入作品仍需单独审查并记录。
- 采用“轻微落位”作为节点正文切换效果；保留原位叠化、柔焦叠化等方案作为设计档案。
- 主页封面统一为原有竖屏 9:16 比例；侧栏当前页改为只用文字高亮，不再显示选中底色、色条或点击后的焦点框。
- 新增辅助主页：以圆角、无描边的错落封面浏览作品，保留当前 Reels 为默认入口。
- 主页复用现有作品注册表，支持标题、作者、简介和标签搜索，以及按主题筛选。
- 参考 PeerTube 列表流程，接近列表底部时分批渲染；当前数据仍来自本地作品数组，没有接入服务端分页 API。
- 点击封面进入对应作品的 Reels；离开主页后保留筛选和滚动位置。
- 开始手机端适配：导航均分屏宽、适配安全区，调整搜索与筛选触控区域、内容页内边距和卡片信息排布。
- 修复触摸手势在多点触摸、页面状态改变或松手目标无效时残留拖动快照的问题；统一取消路径，避免旧画面挡住后续操作。
- 修复手机正文原生纵向滚动抢占上滑分支手势的问题：正文滚动到边界后才交给分支导航或作品切换；上方分支提示显示具体出口文案。
- 优化手机切换世界过场：动画快照只保留当前封面，并在过场结束后更新模糊背景与粒子，减少释放手势时的集中绘制。
- 对应生产部署：GitHub `main` 提交 `69c6de6`；Cloudflare 部署 ID `217e2c93-8af6-46e3-aefc-8a282e7f603a`。手机真机验收仍待完成，部署记录见项目决定 0013。
