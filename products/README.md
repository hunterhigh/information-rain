# 产品源码目录

产品源码和运行所需资源放在本目录，每个产品独立占一个一级目录。产品文档统一放在 `docs/products/<product>/`，避免在代码与治理文档之间产生多份产品定义。

| 产品目录 | 状态 | 用途 |
| --- | --- | --- |
| [`distribution/`](distribution/README.md) | 当前实施 | 读者发现、进入和体验作品；网页实现位于 `reader-web/`。 |
| [`tool-agent/`](tool-agent/README.md) | 预留 | 创作者工具 Agent 的源码边界；目前没有活动实现。 |

每个产品可以有独立的构建、部署和版本节奏。只有已经确认需要共用的能力才放入未来明确命名的 `shared/` 目录；不要因为同属一个 Git 仓库就默认共享运行时或数据模型。
