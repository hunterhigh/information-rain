# 世界故事的叙事与文笔审稿标准

状态：当前写作与审稿标准｜适用产品：分发产品｜建立：2026-10-08

本标准与[制作计划](PLAN.md)一起用于每个世界故事的 `BRIEF.md`、`STORY.md` 和 `REVIEW.md`。结构闭环只是最低条件；读者是否愿意留在故事里，要看文字、人物、信息控制和选择的感受。本标准用于改稿，不给作品套统一语气或流水线评分。

## 1. 先指定文笔，而不是写完后泛称“润色”

每篇 `BRIEF.md` 增加一张简短**文风卡**，在正文前确定：

| 项目 | 必须回答 |
| --- | --- |
| 叙述位置 | 第几人称、视角跟随谁、读者能知道和不能知道什么；视角何时可以转移。 |
| 声音 | 叙述者的态度与词汇范围：冷静、急促、幽默、克制、华丽等词须落到可执行的句法、节奏和观察对象。 |
| 源作继承 | 源作哪一种**技法或体验**值得继承，例如对话压迫、物件伏笔、延迟揭示、循环递进；哪些标志性措辞、角色、世界规则和场景组合必须另写。 |
| 具体目标 | 本篇选定的文学质感与节奏：长短句如何交替，描写密度和对话比重，隐喻的使用边界，哪些意象会反复出现并变化。可附两三句**新写**的样句作校准。 |
| 禁用倾向 | 针对本篇最容易滑向的套路，例如悬疑故事全靠遮掩信息、情感故事用旁白替人物解释、奇幻故事用专有名词替代可感事件。 |

可以借用来源的叙事机制，也可以决定采用另一种适合新题材的文风；不要默认沿用原作口吻。若目标涉及特定作者或作品，提炼高层的节奏、视角、信息控制与修辞功能，写出本篇自己的声音，不复制可辨认的句子或签名式表达。文风卡是写作约束，正文读起来若不成立应调整，而非机械服从卡片。

## 2. 沉浸感来自连续的处境

- 每个节点先交代人物**此刻**感到、看见或正在做什么，再让信息进入；时间、地点、角色和物件跨节点连续。读者无需记账，也能理解当前有什么风险与可行行动。
- 展示世界规则的方式是让它影响行动和代价。设定说明只有在角色眼下必须用到时才出现；新名词不能承担本应由事件完成的解释。
- 限制叙述者替人物或读者下结论。让身体反应、动作、错误、沉默、对话中的回避和付出的代价呈现情绪；关键情绪可以直说，但不能每段都附解释。
- 选择出现时仍要处在戏剧现场：下一秒会发生什么，谁在等回应，为什么没有无成本的完美选项。读者不是在回答一份伦理问卷。
- 分支之后立即给可感的反馈，并在之后让重要选择回响。合流不能抹掉行动；结局不能把此前经历压成一句抽象评语。

## 3. 文学性是精准，不是堆砌

让人物既有当下目标，也有矛盾、局限或误认；事件迫使其付代价。意象、细节和句子节奏要服务冲突与人物认识的变化。一个具体细节如果能同时承担场景、人物和伏笔，比三句泛化气氛更有力。允许复杂、暧昧与未说完的感情，但故事核心问题必须在结局得到回应。

同一作品不同路径可以有不同情绪色彩，却应共享一致的叙述身份和世界规则。结局不必全部令人安慰；失败、错过、误判和无法两全可以真实发生。困难内容要写得具体而有责任感，不用说教或无代价的安全出口抹平冲突。

## 4. 每段有牵引，不等于每段造悬念

审读 `STORY.md` 时逐段问：**这一段之后，读者为什么想读下一段？** 合格的牵引可以是行动推进、新信息、一个人物的反常回应、感官细节改变判断、关系的细微位移、某项代价逼近，也可以是情绪暂时落定后留下的新问题。每段至少做其中一件，或为紧接着的事提供不可替代的停顿。

不要把每段都写成“然而他不知道……”“门后还有更可怕的东西”式的硬悬念；反复只延迟答案会耗损信任。允许安静段落和结局的释放。章节或节点末尾的牵引比段尾口号更重要：下一节点的实际事件要兑现上一节点制造的期待。

## 5. 专门清理模型常见的防御性写法

逐路径朗读并主动找这些症状；发现时改写具体句子或事件，不靠删几个形容词敷衍：

1. **替故事解释自己**：反复告诉读者“真正重要的是”“这让他明白”“每种选择都有代价”，或用尾声概括主题。改成一件发生的事、一句有对象的对话或人物承担的结果。
2. **在冲突前退缩**：人物始终礼貌、善解人意、迅速互相理解，关键错误被意外化解，危险只被描述却从不产生损失。让人物拥有相互冲突的目标，并允许其犯错、伤人、沉默或失败。
3. **为每句话加缓冲**：成串使用“似乎、仿佛、某种、或许、也许”，在明确场景中仍不断声明不确定。只有视角人物真的无法判断时才保留不确定；能看见的动作就直接写。
4. **对称而空泛的选项**：每个按钮都像写给评审看的“谨慎处理/勇敢面对”，或一条明显正确、另一条愚蠢残忍。改成当前人物能执行的具体行动，透露真实代价但不替读者评分。
5. **通用气氛与隐喻堆积**：反复写空气凝固、心口一紧、世界安静下来，句子优美却没有新事。用本篇独有的场景物、声音、动作或关系细节取代。
6. **重复交代与兜底**：一个事实在旁白、对话、选项、结局中解释四遍；每个分支最后都安排不损失任何人的折中解。删掉复述，让结果由前面的选择真正决定。
7. **界面外的作者声音**：在正文里解释玩法、提醒“你可以选择”、替读者预告情绪或道德意义。只保留故事世界内人物能感知或表达的内容，必要规则在行动中显现。

这些是**改稿警报**，不是禁止词表。某句确有角色口吻、节奏或情节功能时可以保留；判断以完整阅读路径的效果为准。

## 6. 审稿方法与就绪条件

在 `REVIEW.md` 单列“文笔与沉浸审读”，至少做四次有区别的检查：

1. **开篇盲读**：不看来源与 `BRIEF.md`，只读首两个节点；能否说出人物想要什么、眼前阻力是什么，以及为什么继续。
2. **整路朗读**：读一条主路径和每类结局；标出视角漂移、说明堆积、悬念未兑现、节奏长期平板或突兀的高腔。
3. **逐段牵引**：给每段标出它带来的变化或必要停顿；连续两段只能交换顺序而不影响理解时，合并、删除或改写。不是用“钩子”字样强迫每段出现反转。
4. **防御性写作回查**：摘录具体问题句，说明怎样改、改后发生了什么；再读相关路径，检查是否真正更有张力，而非只变得更短。

`REVIEW.md` 记录文风卡是否兑现、最能代表本篇文笔的段落、最薄弱的路径和修改结果。若故事图已完整，但人物、沉浸、段落推进或文风仍不足，继续标为「在写」；不能仅凭结构可达、语法正确或自评“有文学性”升级为「故事就绪」。
