# 走廊口的邀请

## n01 · 展厅关门

陶音收完最后一幅画，策展人裴知在走廊口等她，手里两张闭展后的晚餐票。他刚替她争取到一次个人展，因此整栋楼的人都盯着他们会不会一起离开。陶音喜欢和他谈作品，也怕任何拒绝被听成忘恩。

裴知挡着安全出口旁半扇门，笑着说已经订了桌。陶音可以当场说清自己不接受被代为决定，也可以先走到庭院里，再把愿意和不愿意的部分分开谈。

- → n04：请他让开门，明确拒绝今晚的晚餐。
- → n05：提议去庭院谈十分钟，不默认晚餐。

## n02 · 半扇门

裴知挪开一步，脸上的笑慢慢收了。他说票可以退，接着问：“那你是不是连下次合作也不要？”陶音听见保安的钥匙在楼下响。她能在此刻指出工作与私人邀请不该绑在一起，也能暂时离开，明天以书面方式划清界限。

- → n07：当面拆开两件事，请他明确合作条件。
- → n08：先离开，次日给他和馆方发信。

## n03 · 庭院十分钟

裴知跟她走进庭院，把晚餐票塞回口袋。陶音说愿意继续聊展览，不愿在闭馆后临时被带去吃饭。他沉默很久，问若提前邀请是否会不同。雨水沿雕塑底座流到他们鞋边。

- → n09：说可以提前约一次，今晚各自回家。
- → n10：说仍不想约会，只保留工作关系。

## n04 · 门让开的宽度

陶音说完，裴知侧身让出路，却仍拿着两张票。楼下保安的钥匙声越来越近，她不想在别人面前解释自己的感情，更不愿因为旁人来了就把刚才的话收回。她站在门口，没有替裴知把票接过去。

- → n02：把今晚的拒绝与后续合作分开说清。
- → n06：先离开走廊，要求把合作条件写下来。

## n05 · 雨前的庭院

庭院有一排没来得及收的折椅。陶音选了靠出口的一张，没有坐，只说十分钟到了就回家。裴知把两张票翻到背面，那里印着不可退的字样；她看见了，却不接手他花出去的钱。

- → n03：谈展览，也把私人邀请的边界说明白。
- → n06：先问馆方评审由谁决定，再决定谈什么。

## n06 · 展览名单

陶音在手机上找到个人展的评审邮件，上面列着四位委员，不只有裴知。她把屏幕递过去，让他说清自己争取的是展期还是评审结果。裴知读完，手里那两张票忽然显得很薄。

- → n02：要求当面把工作与晚餐分开。
- → n03：去庭院继续谈十分钟，不接受当场安排。

## n07 · 两种答复

裴知说展览由评审决定。陶音问是否能把这一句也发给馆方，而不是只在空走廊里告诉她。保安已经走到楼梯口，话还来得及说完；她愿意继续合作，但不会把自己的回答变成一张欠条。

- → e01：请他发评审意见，今晚各自离开。
- → e02：不在走廊继续谈，次日书面告知馆方。

## n08 · 邮件草稿

陶音在回家的车上写邮件，第一句反复删改。她最后留下两件事：展览合作照旧讨论，私人邀请不作为合作条件。收件人栏里有裴知，也有馆方的公开地址。发送键在屏幕下方，她等车停稳才按。

- → e02：抄送馆方，留下一份能核对的边界。

## n09 · 下周的空格

陶音说提前约可以谈，裴知立即翻手机日历。她没有给出日期，先问他下次能否把邀请说成问题而不是安排。他把已经写进日历的餐厅删掉，留出一个空格，等她自己看时间。

- → e03：约下周三，今晚分别回家。
- → e04：发现自己仍不想约会，只保留工作关系。

## n10 · 收起的伞

陶音说只想保留工作关系。雨已经落下来，裴知把伞递向她，又停在两人之间，问她是否需要。她说自己带了伞，指给他看画袋旁的伞柄；这次他点头，没有再替她选择。

- → e04：各自离开，日后只就展览通信。
- → n09：若她想重新考虑，再让邀请从一个空白日期开始。

## e01 · 两张纸

裴知把票撕成两张，说个人展本就由评审决定，与吃饭无关。陶音请他把评审意见发到邮箱，他答应了，语气硬得像在背公文。下周评审如期进行，她的画挂上了墙。

开幕时裴知带其他策展人来介绍作品，两人握手，之后各自走向人群。陶音经过安全出口，门能整扇打开。

## e02 · 抄送

陶音第二天把邮件抄送馆方，写明自己愿意继续展览合作，不接受私人邀请被混进工作安排。馆方回信要求裴知退出评审，他很久没有回复她。展览延期两周，另一位策展人接手。

延期那天陶音自己重新调了画框高度。她知道自己失去了一段可能的亲近，也保住了说“不”的空间。

## e03 · 下周三

裴知在手机日历上写了下周三，先问她方便不方便。今晚他一个人去退票，陶音从另一扇门离开。下周三他们吃了顿饭，谈到展厅的灯，也谈到为什么她不喜欢被人当众安排。

他说起自己的尴尬，没要求她替他消除。结账时陶音付了自己的那一份，两人约定再见面之前先把工作邮件回完。

## e04 · 收伞

裴知点头，送她到庭院门口便停下。之后两周他只就展览给她写信，邮件里再没出现晚餐。陶音看见合作逐渐回到清楚的图纸和时间表上。

展览开幕时他站在门边向来客介绍她的作品；陶音从他身旁经过，去给一位第一次来馆的孩子讲画里那把收起的伞。
