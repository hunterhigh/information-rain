# 先给出的东西

## n01 · 碗里的水

阿砚在盐碱地迷了路，水壶只剩一碗。废井旁有只盲鸟，翅膀夹在铁网里；向导说这种鸟能听见地下水，剪下它颈侧的羽毛，就能辨出水脉。鸟扑了一下，嘴里沾满盐。

向导把剪刀递来。阿砚可以先用水洗开鸟的伤口，或先取一根羽毛确定回程方向。

- → n04：把水给鸟洗伤，松开铁网。
- → n05：先取羽毛辨路，再处理铁网。

## n02 · 空壶

鸟喝了几口，伤口露出锈红的血。阿砚剪断铁网，它没有飞，反而落在她的肩上。地平线已看不见营地；向导说若留着鸟走夜路，能听它何时转头找水，也可能把它拖死。

- → n07：带鸟慢行，按它的反应找井。
- → n08：放鸟自由，按自己的地图赶回营地。

## n03 · 一根羽毛

羽毛在阿砚手里朝北发颤。鸟痛得不再叫，向导说北边有一条干河床，今天过去才赶得上队伍。阿砚能依羽毛立即赶路，留下一碗水给仍被困的鸟；也能先剪网救它，冒着晚归失去庇护的风险。

- → n09：留下水，循羽毛赶往干河床。
- → n10：先剪网救鸟，再沿羽毛走。

## n04 · 铁丝下的羽

阿砚把水倒在鸟翅根，盐和血沿铁丝滑下来。她找到网里最紧的那一扣，剪刀刚伸进去，向导便提醒剩下的水不够两个人走到天黑。鸟却没有再扑。

- → n02：剪断铁网，带着空壶重新找路。
- → n06：先看附近有没有可接露水的草。

## n05 · 北边一抖

羽毛在手里轻轻朝北转，鸟的叫声却低了下去。向导指给阿砚看远处的干河床，离营地还有一整日路；废井周围的铁网被风刮得一阵阵发响。

- → n03：先沿羽毛辨路，再决定如何救鸟。
- → n06：查清废井旁有无新水痕。

## n06 · 井沿的盐

阿砚摸到井沿下面一条湿痕，盐壳还没结硬。这里或许有新水脉，也可能只是昨夜短暂的露；鸟把头转向那处，向导却仍望着北边亮起的营地信号。

- → n02：先松网，带鸟慢慢找井。
- → n03：先取羽辨北，留水后去追队伍。

## n07 · 肩上的重量

鸟落在阿砚肩上，轻得像一片还湿的布。它转了两次头，第三次前她听见地底一声空响；向导拿出铲子，问是否就在这里挖，还是趁尚看得见营地灯继续走。

- → e01：沿鸟的方向挖井，带它活过夜。
- → e02：放它飞走，循地图赶回营地。

## n08 · 飞开的影子

阿砚松开手，鸟飞得歪，却越过废井。地图上的叉号在前方，她走了两步发现脚下盐层比图上写得厚；向导把外套铺开，今晚还能接一点露水。

- → e02：按地图去旧井，夜里靠露水撑住。
- → e01：追回鸟的方向，试着找被沙埋的浅井。

## n09 · 留在井边的水

阿砚把最后一碗水放在废井的阴影里。鸟仍困着，羽毛指向北边；她看见铁网有一角已松，或许天黑后它能自己挣开。营地那头升起了收队的烟。

- → e03：循羽毛赶路，明天请人回来拆网。
- → e04：现在剪网，接受错过营地的夜晚。

## n10 · 最后一剪

铁网断开，鸟先没动，随后带伤掠过一片灰草。向导已经看不见营地的灯，阿砚把羽毛夹在掌心，发觉它仍指着鸟飞去的方向。

- → e04：沿羽毛和鸟影找水，夜里留在干河床。
- → e02：放鸟飞走，依地图的叉号寻找回营路。

## e01 · 会转头的鸟

夜里那只鸟又落到阿砚肩上，转了三次头，第三次时，她听见脚下有空洞声。她和向导挖开一口被沙埋的井，水浅，却够两人和鸟活过夜。清晨鸟飞走前在井沿啄了两下。

阿砚用木桩标出井位，回营地叫人来修。她没再向鸟讨一根羽毛；井的水每年都要有人掏沙。

## e02 · 地图上的叉

鸟飞得歪，却终究离开了铁网。阿砚按地图走到一处标着井的叉号，井早被盐封，地图迟了一年。向导把外套铺成接露水的布，两人在凌晨等到一小盏水，天亮才拖着空壶回营地。

几天后修井队报告，废井附近出现新水脉。阿砚知道自己当时已经离开；她把地图上的叉改成一个需要复核的圈。

## e03 · 北边

阿砚沿羽毛找到干河床，队伍按时接上她。她留下的水被太阳晒去半碗；第二天有人回废井，看见鸟已挣脱，却不知道去了哪里。羽毛一直指北，阿砚用它带队找到另一处浅水。

修井时她让人拆掉废井周围所有旧铁网。谁也不能说是那只鸟救了他们，井水确实从羽毛所指的方向来。

## e04 · 错过营地

阿砚剪网时队伍的灯从远处熄了。鸟带伤飞开，羽毛却仍指向北边；她和向导在干河床过了一夜，水壶最后几滴给了向导发烧的嘴唇。天亮鸟从上空掠过，在一片灰草上盘旋。

那里有被沙盖住的湿土。他们挖到水，也迟了两天归队。营地以为两人死了，重逢时先骂他们擅自离队，随后拿桶来取水。
