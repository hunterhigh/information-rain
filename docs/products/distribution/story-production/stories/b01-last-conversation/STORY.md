# 最后一遍台词

## n01 · 第一遍

梨汤端上来时，沈若说她下周搬走。我练过很多遍“我明白”，却先问她是不是因为昨晚那通电话。她把勺子放在碗沿，说不是一通电话，是一年里每次想独自出门，我都要追问她去哪里。

门外送货车开始倒车，滴滴声盖住我准备好的解释。我可以把练过的话说完，或先问她今晚需要怎样结束这顿饭。

- → n05：解释自己追问是因为害怕失去她。
- → n06：不解释，问她今晚想怎样结束。

## n02 · 第二遍

沈若说她听过这个理由，上个月也听过。她把汤推远一点。我忽然想起另一个更好的说法，想从刚才那句重来；她看着我，像看一个总要求重拍的导演。

- → n08：承认自己又在改写说法，停止挽留。
- → n04：请求给我最后一次机会，把话讲对。

## n03 · 椅子

她说希望吃完就走，明天再来取书。我的手仍压在她的钥匙上，那是刚才替她开门时顺手拿的。她没有伸手来抢，只把掌心摊在桌上。

- → n09：把钥匙还给她，约好取书时间。
- → n04：说要先把这顿饭谈完，暂时按住钥匙。

## n04 · 第三遍

梨汤已凉。沈若说：“你刚才问我想要什么，现在又想决定谈到什么时候。”我松开钥匙，它在桌面转了半圈。她没碰，等我自己把它推过去。

- → n10：推还钥匙，道歉后让她离开。
- → e04：继续讲自己的改变，请她今晚留下。

## n05 · 没说完的理由

我说的“害怕”刚出口，沈若的手机亮了一下。她没有看，只问：“那每次我回晚了，你发的十几条消息也是怕？”我想拿她第一次失约的那晚作证，却发现自己连她那天去见谁都记得，倒不记得她回来时有多累。

- → n02：把这个理由说完，听她怎样回应。
- → n07：停下解释，承认我其实一直在核对她的行踪。

## n06 · 她要的结束

沈若说，今晚不要再讨论谁先变了。她想把饭吃完，然后带走放在玄关的行李。我下意识看向墙上的钟，盘算还能争取多少分钟；她看见了，把勺子放回碗里，问我是否真的听见她说了什么。

- → n03：先让她把要求说完，再处理桌上的钥匙。
- → n07：承认我刚才仍在计算怎样把她留下。

## n07 · 没有排练的停顿

门外倒车声停了，屋里只剩汤匙碰到瓷碗的一声轻响。我没再找更好的句子。沈若把手放在桌沿，等我作决定；她的钥匙就在我手边，温度已经被掌心捂热。

- → n03：把谈话交还给她，问今晚她需要什么。
- → n02：把自己的害怕说清楚，但不要求她替我作答。

## n08 · 一句不带请求的话

我说刚才又在替自己找一种比较好听的说法。沈若没有立刻点头。我把手从钥匙上移开，告诉她这不是她必须安慰我的事。她终于把那半碗汤拉回来，勺子仍悬在碗上。

- → e01：不再索要最后一次机会，让今晚停在这里。
- → n04：还是想把话讲对，请她再听一遍。

## n09 · 写在冰箱上的时间

我把钥匙放到她摊开的掌心。沈若说“明天两点”，我找笔时几乎又问她能不能改到周末。她已经有车，也约了人帮忙搬书；这个安排不需要我重新批准。笔尖在冰箱纸条上停了一秒。

- → e02：写下两点，按她定的时间准备书箱。
- → n04：借取书的事，再把今晚的谈话延长。

## n10 · 钥匙转过半圈

我把钥匙推过去，它碰到她的指甲才停。沈若说：“谢谢。”这两个字很轻，像在确认一件已经属于她的东西。我想在道歉后再加一句解释，舌尖抵住牙，却看见她已经起身穿外套。

- → e03：让解释留在嘴里，替她拉开门。
- → e04：在她走之前，把准备好的改变计划全部说出。

## e01 · 没有重拍

我说刚才的解释确实是在请求她替我减轻害怕。沈若点头，没有因此改变搬走的决定。她喝完半碗凉汤，说明天会带两个箱子来装书。

她走后我把剩下的汤倒掉，发现锅底粘了一圈糖。我洗了很久，没有给她发第四段话。第二天门铃响时，箱子果然是两个。

## e02 · 明天两点

钥匙落进她手心，她说“明天两点”，我把时间写在冰箱上的纸条。那晚我们把汤喝完，没有再争谁先提出分开。她走到门口时回头看了桌面一眼，勺子还并排放着。

第二天我把她的书从高架搬下，没替她决定哪些要留下。她装满两个箱子，临走问我能否帮忙抬到车上，我照做了。

## e03 · 推过去

我把钥匙推给她，说刚才按住它是不对的。她把钥匙收起，没有接受我顺口补上的“但我只是想”。外面的送货车早开走了，整条街很安静，她能清楚听见自己开门的声音。

第二天她带朋友来取书，我在楼下等。朋友上去帮她搬，我第一次知道她早已安排好有人来接。

## e04 · 留下来

我讲了十分钟计划：不再看她的行程，去做咨询，换一把她能独用的锁。沈若听完，只问钥匙能不能还她。我还了，她拿起外套离开，梨汤一口也没喝。

我把计划写在纸上，纸到周末仍在桌上。后来我去了咨询室，医生问我那晚最后一句说了什么。我照原话复述到一半，停下来，才听见自己连她拿钥匙的声音都没留进去。
