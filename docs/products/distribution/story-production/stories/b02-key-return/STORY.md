# 钥匙的另一头

## n01 · 钥匙圈

何笛把工作室的最后一箱画搬到门口，孟修仍握着她的钥匙。他们分手两个月，租约还剩十天，画展的交接单尚未签完。孟修说钥匙放在他手里方便随时取画框；何笛看见桌上堆着他没拆的快递，已经不愿再独自来这里。

她可以现在要求归还钥匙，现场盘点；也可以先签交接单，约定换锁前的最后一次共同进入。

- → n04：要求他交钥匙，当面清点画框。
- → n05：先签交接单，写明最后入室时间。

## n02 · 少一幅

孟修把钥匙拍在桌上。清点时少了一幅小画，他说可能还在展馆，何笛却记得上周它挂在门后。两人都有理由怀疑对方，屋里还有监控硬盘，但调取需房东同意。

- → n07：请房东来见证，暂不带走有争议的画。
- → n08：带走自己确认的画，留下缺失记录。

## n03 · 十天

孟修在交接单上写下最后一次进入的日期，签完才说钥匙不见了。何笛不确定他是真的丢了，还是想保留进门的可能。房东同意第二天换锁，费用得有人付。

- → n09：现在联系房东换锁，费用各半。
- → n10：给他一晚寻找，明天再决定换锁。

## n04 · 两把钥匙

孟修把钥匙放下时，何笛才发现圈上多了一把小铜钥匙。那是公用柜的，过去一直挂在墙钩上。他说装箱工借用后忘了还。何笛没有争这句是真是假，先把两把钥匙分开，压在交接单两侧。

- → n02：先盘点画框和小画，逐件写下去向。
- → n06：请房东到场，再开始最后一次盘点。

## n05 · 日期写到纸上

交接单最后一栏要填进入工作室的截止时间。何笛写下十天后的正午，孟修想改到傍晚，说展馆的人可能迟到。她看见他袖口沾着新木屑，想起还有一幅画连框都没装好。

- → n03：把期限写清，并问他手里的钥匙在哪里。
- → n06：先找房东确认公用柜和工作室由谁锁门。

## n06 · 房东的账本

房东在电话里翻租约，纸页擦着听筒沙沙响。工作室门锁归租户，公用柜归楼里；换锁可以明天做，今天谁拿走什么却得两人自己签字。何笛把手机开免提，孟修第一次没有打断对方。

- → n02：趁三个人都听着，清点每一幅画。
- → n03：先把最后入室时间和钥匙责任写进交接单。

## n07 · 硬盘上的空白

房东到了，监控硬盘却有半天断档。何笛没把断档当成证据，她在清单上圈出小画的尺寸、画框的缺口，让孟修也签了名。装箱工的电话号码就在旧订单背面；拨出去以前，两人还得决定争议画是否留在现场。

- → e01：请房东保管画框，等装箱工回话再结案。
- → e02：先带走确认无争议的作品，留下签名记录。

## n08 · 空着的墙钩

何笛把能确认的画装上车，门后留下一个比小画略浅的方印。她拍下墙面、箱号和当天的时间，发给房东与孟修。孟修回复“收到”，又补上一句“展馆还没查”。车门关上时，她仍握着那张缺失清单。

- → e02：按清单分别处理已确认和缺失的画。
- → e01：卸下最后一箱，等房东来见证完整盘点。

## n09 · 锁匠的号码

房东报来锁匠的价钱。孟修说自己只丢了一把钥匙，何笛把交接单翻到两人共同使用工作室的那一页，请他看押金怎样写。旧锁仍能转动，真正关不严的是他们口头约定的最后十天。

- → e03：请锁匠今天到，把费用和新钥匙写进交接单。
- → e04：先给他一晚寻找，明天按约处理锁芯。

## n10 · 最后一晚

孟修答应天亮前把画册和工具箱全翻一遍。何笛没有把备用钥匙留给他，只约房东第二天早上一起开门。夜里她收到一张照片：画册摊在地上，钥匙圈露出半截。他还没说找到了，她也没有回“早知道”。

- → e04：照约定等到早晨，当面收回钥匙。
- → e03：通知房东今天就换锁，不再等他的解释。

## e01 · 第三个人

房东调出硬盘，小画是装箱工误放进公用柜。何笛当着两人取出画，孟修说了声“原来如此”，没有再提她先前的怀疑。房东收走旧钥匙，十天后按时退租。

展览开幕那天，何笛在作品说明上写了共同制作的部分，也写了最后由谁完成装裱。孟修经过那幅小画，停了片刻，继续往下一间走。

## e02 · 留一张纸

何笛拿走能确认的画，给孟修和房东留一份签名的缺失记录。小画后来在展馆找到了，却被另一组作品压坏边角。赔偿由展馆承担，两人只能合签申请。

他们在柜台一人签一页，字都很快。何笛收到赔款时把属于孟修的部分转了过去，附上画框尺寸，没有附问候。

## e03 · 新锁

锁匠傍晚到，孟修仍说钥匙也许能找到。何笛付了自己的一半，看着旧锁芯落进铁盒。第二天展馆来车装画，两人各自拿着房东发的新钥匙，按交接单上的时间进出。

十天后工作室清空。房东把新锁芯留给下位租客，何笛把这张收据夹在展览合同里，纸比钥匙轻，却能说明门由谁开过。

## e04 · 一夜

孟修第二天早晨找到了钥匙，夹在一本画册里。他把它交给何笛，还带来半夜写的解释信。何笛收钥匙，没有收信，说交接已经写在纸上。房东仍换了锁，费用从押金里扣。

孟修后来把信寄到她新住处，她没有拆，退回时在信封上写“作品事宜请发邮件”。工作室的门关了，合作还需处理；这一次地址和钥匙都不再替他们谈感情。
