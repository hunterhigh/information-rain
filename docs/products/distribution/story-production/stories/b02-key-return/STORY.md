# 钥匙的另一头

## n01 · 钥匙圈

何笛把工作室的最后一箱画搬到门口，孟修仍握着她的钥匙。他们分手两个月，租约还剩十天，画展的交接单尚未签完。孟修说钥匙放在他手里方便随时取画框；何笛看见桌上堆着他没拆的快递，已经不愿再独自来这里。

她可以现在要求归还钥匙，现场盘点；也可以先签交接单，约定换锁前的最后一次共同进入。

- → n02：要求他交钥匙，当面清点画框。
- → n03：先签交接单，写明最后入室时间。

## n02 · 少一幅

孟修把钥匙拍在桌上。清点时少了一幅小画，他说可能还在展馆，何笛却记得上周它挂在门后。两人都有理由怀疑对方，屋里还有监控硬盘，但调取需房东同意。

- → e01：请房东来见证，暂不带走有争议的画。
- → e02：带走自己确认的画，留下缺失记录。

## n03 · 十天

孟修在交接单上写下最后一次进入的日期，签完才说钥匙不见了。何笛不确定他是真的丢了，还是想保留进门的可能。房东同意第二天换锁，费用得有人付。

- → e03：现在联系房东换锁，费用各半。
- → e04：给他一晚寻找，明天再决定换锁。

## e01 · 第三个人

房东调出硬盘，小画是装箱工误放进公用柜。何笛当着两人取出画，孟修说了声“原来如此”，没有再提她先前的怀疑。房东收走旧钥匙，十天后按时退租。

展览开幕那天，何笛在作品说明上写了共同制作的部分，也写了最后由谁完成装裱。孟修经过那幅小画，停了片刻，继续往下一间走。

## e02 · 留一张纸

何笛拿走能确认的画，给孟修和房东留一份签名的缺失记录。小画后来在展馆找到了，却被另一组作品压坏边角。赔偿由展馆承担，两人只能合签申请。

他们在柜台一人签一页，字都很快。何笛收到赔款时把属于孟修的部分转了过去，附上画框尺寸，没有附问候。

## e03 · 新锁

锁匠傍晚到，孟修仍说钥匙也许能找到。何笛付了自己的一半，看着旧锁芯落进铁盒。第二天展馆来车装画，两人各自拿着房东发的新钥匙，按交接单上的时间进出。

十天后工作室清空。房东把新锁芯留给下位租客，何笛把这张收据夹在展览合同里，纸比钥匙轻，却能说明门由谁开过。

## e04 · 一夜

孟修第二天早晨找到了钥匙，夹在一本画册里。他把它交给何笛，还带来半夜写的解释信。何笛收钥匙，没有收信，说交接已经写在纸上。房东仍换了锁，费用从押金里扣。

孟修后来把信寄到她新住处，她没有拆，退回时在信封上写“作品事宜请发邮件”。工作室的门关了，合作还需处理；这一次地址和钥匙都不再替他们谈感情。
