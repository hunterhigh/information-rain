# 门外仍有风

## n01 · 升降井

我在升降井底找到母亲的签名。二十年前，她亲手关闭向外迁居的天门，留下城里的人修补漏气的地基。全城都说她贪恋权力；签名下却压着一张计算纸：那一年天门只能送走七人，她决定让城继续活。

如今新门修好，城底又裂开了。通行位只够一艘船。我握着控制盘，地面广播里有人喊我的名字，身后同伴陆砚带来一份有一百二十人签字的候船名单。

- → n04：打开公开通道，按名单组织撤离。
- → n05：封住通道，去看城底能否修复。

## n02 · 名单上的空白

名单末尾留了六个空格，陆砚说是给没赶到广场的人。天门的船长却只认重量，不认签名。再装六人，船可能坠入风眼；若只上名单内的人，守在门口的家属会眼看它起飞。

陆砚已站上甲板，把绳梯留给我。我可以上船，坚持用有限座位带出能登船的人；也可以把控制盘交给他，自己留在门边调度下一次建造。

- → n07：登船，在载重线上关门。
- → n08：留在城里，把船和控制盘交给陆砚。

## n03 · 地基的声响

城底漏气处有一圈旧铆钉，是母亲留下的补丁。工程师说若把天门的核心拆来封裂口，城能再撑十年；核心只有一个，再造需要邻城同意。另一个办法是强行驱动天门，开一条只供我通过的小路，控制盘从此归我。

裂缝里卷出一枚生锈的螺母。我想起母亲把全城留下时，没人来问过她怕不怕。

- → n09：拆下核心，修城并公开母亲的计算纸。
- → n10：强行开启单人通道，带走控制盘。

## n04 · 广场的秤

广场有人搬来粮袋，试着把船舱空隙塞满。船长把秤砣放到我手里：这不是一张能投票改掉的载重表。名单末尾的六个空格已经被人写上名字，我一眼认出其中有陆砚的妹妹。

- → n02：公开称重，让每个人看见剩下的座位。
- → n06：先请陆砚把那六个人叫到控制室。

## n05 · 母亲的铆钉

我沿城底摸到母亲留下的旧铆钉。裂缝边有新鲜的白痕，工程师说还能封一次，却必须拆掉门的核心。上方传来广场喊开门的声音；我第一次明白母亲在这里签名时听见的是什么。

- → n03：测量裂口，算出拆核心能换来的年数。
- → n06：带着测量纸回广场，先把代价说清。

## n06 · 公开的算式

陆砚把母亲二十年前的计算纸铺在控制台。那时她没有叫人来看；如今纸上的七人容量和船长刚写的一百二十人相隔太远，仍有同样的空格。一个孩子问我，若第二艘船造不出来，谁会留下。

- → n02：把载重表贴上门，组织这一艘先走。
- → n03：把裂缝图也贴出去，请留下的人一同修城。

## n07 · 绳梯

我登上绳梯，脚下六个人仍站在空格旁。船长伸手等我交盘；陆砚说邻城还有钢梁，落地后他会寄回来。门边有人问名单之外的名字谁记，我把笔从口袋里摸了出来。

- → e01：按载重线关门，把留下的名字带去邻城。
- → e02：把盘交给陆砚，退下绳梯留在门边。

## n08 · 第一颗螺栓

陆砚在船上点完人，把一颗备用螺栓抛给我。我站在门边接住它，掌心被划开一道口子。城底的风从脚下往上吹，六个没赶上船的人没有散，等我说第二艘从哪里开始。

- → e02：留下建船，先请他们把能用的钢梁标出来。
- → e01：赶在关门前登船，去邻城催第一批零件。

## n09 · 熄掉的门

工程师拧下核心，广场上的灯一排排熄了。有人冲下楼来抢最后一块蓄电池；我把母亲的旧纸递给他，告诉他这一次签名在我的旁边。修补用的铆钉还差两枚。

- → e03：封住裂缝，把决定和十年期限一同公开。
- → e04：放弃封补，把核心送回门上独自离开。

## n10 · 单人航道

风眼里只露出一条窄到不能并肩的航道。陆砚在广播里叫我把控制盘留下；我看见母亲磨出的钥匙槽，也看见城底裂缝正在扩大。再多等一刻，通道就会自己合上。

- → e04：带盘穿门，把旧城的去向交给剩下的人。
- → e03：拆盘取核心，回城底封住裂口。

## e01 · 一船的人

我在载重线处关门，六个迟到的人留在广场。船越过风眼时晃得像一只浸水的碗，最后落在邻城外的草坡。陆砚跪在舷口吐了很久，然后去敲收容站的门。

第二天我把母亲的计算纸贴在登记墙上，写明这一次关门的是我。六个空格无人替我填；从邻城寄回的第一批零件却按它们的名字编号，送去造下一艘船。

## e02 · 第二艘船

陆砚带船离开时，我站在门边记录重量。广场上六个迟到的人帮我收起绳梯，一人问下一艘什么时候来。我没有日期，只能摊开天门图纸，请他把能用的钢梁标出来。

一个月后，邻城的信鸽捎回陆砚的测量数据。城底仍漏气，我们每天要补一段；第二艘船的龙骨也已弯好。我把母亲的纸钉在工棚里，计算从此由所有肯拿尺子的人一起改。

## e03 · 十年

核心落进裂缝，城市猛地向下沉了一寸，随后稳住。天门熄灭，广场上有人砸了广播，因为他们原本能乘船离开。我把母亲的签名和今天的决议一起贴出去，留下自己的名字。

十年并不是平安的别称。第二年开始缺粮，第四年邻城才同意借图纸。陆砚每次出工都从我的桌上拿一颗旧铆钉，说下一个门要让广场上的人也看得见载重线。

## e04 · 唯一乘客

单人通道在我身后合拢，城里的广播传来一阵刺耳的空白。我落在邻城，控制盘还热着，却再也接不到旧城的信号。邻城议会收下盘，问我愿意卖出开门的方法。

我开出的价格很高。他们照付。多年后我在报纸上看见旧城的名字：它凭拆下的备用零件撑过了冬天，却再没人信任一个掌握门的人。我把报纸折好，发现盘上的钥匙槽仍是母亲手指磨出来的形状。
