# 白色告示

## n01 · 两只试瓶

水务站早班发现北区两只试瓶变色，一只来自老管，一只来自学校水龙头。检验员方芷还没有复测结果，值班室的电话却已响起：学校今天办运动会，食堂正在烧第一锅汤。

主管把公告模板递来，上面只有“安全”与“停用”两个章。方芷可以立即公开异常，也可以先让相关机构停水，再争取时间复测。

- → n05：发布临时停用公告，写明仍待复测。
- → n06：先采取预防措施，核对通知范围。

## n02 · 广场上的桶

公告贴出后，商店的瓶装水半小时售空。学校关了食堂，家长在门口排起长队。复测员打来电话：老管样本确实异常，学校样本可能因试瓶残留而误报。方芷要改公告，主管催她先把原帖撤掉。

- → n07：保留公告并更新范围，公开两项不同证据。
- → n08：撤掉原公告，待确认后一次发布结论。

## n03 · 关掉的水龙头

学校照通知停水，校长问为何附近住户还在正常用水。方芷没有一张能给他的公开纸。复测发现老管异常，半小时后北区另一所学校也报出异味；她必须决定如何追上已经流出的水。

- → n09：立即公开老管污染范围，承认此前仅通知部分机构。
- → n10：先派车逐街送水，等实验室确认全部边界再公告。

## n04 · 没贴出的纸

方芷把水车开到北区外围，叫复测员逐街取样。学校运动会已经开始，送水车没有停用公告，司机不肯直接进校门，怕被当成承认污染。复测报告还差最后一瓶，学校的汤已经盛进桶里。

- → e05：立刻进入学校，说明预防措施并停用水源。
- → e06：继续等最后一瓶结果，再启动备好的水车。

## n05 · 第一张纸

方芷在公告上写“待复测”，主管仍盯着模板上的两个印章。她把两只试瓶的来源逐一写上去，免得学校误以为全城都已确认污染。贴纸的胶尚未干，商店里已经有人抱着水桶跑出来。

- → n02：保留公开告示，等复测后逐项更新。
- → n03：先通知学校和医院停用，缩小临时范围。

## n06 · 出站前的水车

水车已装满，司机问应先开到学校还是老管街。方芷没有一张能交给他的正式告示；她看着两只变色的试瓶，知道复测不能代替已经流出去的第一锅汤。

- → n03：先逐一通知学校和医院停水。
- → n04：先派车到外围取样，等最后一瓶结果。

## n07 · 删改痕迹

学校样本可能误报，老管街却已确定异常。主管要撤下第一张纸，方芷看见家长的手机里已有截图：删掉原帖也删不掉他们见过的字。她握住笔，给每一次修改写上时间。

- → e01：保留旧版，公开两处不同证据和更新范围。
- → e02：撤下原帖，等精确地图再发布。

## n08 · 空白的四十分钟

公告从墙上撕下，胶痕还在。商店门口开始有人说全城的水都有毒，水务站电话占线；复测员发来新图，只有老管街区确诊。方芷拿起新的纸，想起空白也会被人转述。

- → e02：一次发布最终范围，记录撤稿造成的间隔。
- → e01：补回原告示并标注修订时间。

## n09 · 通知时间表

方芷把学校先停水、居民尚未接到消息的两个时间写在公告上。北区新报异味的街道已经亮灯，水车还在站里；她必须决定先让所有人知道，还是先把车驶过去。

- → e03：公开老管污染范围和此前通知顺序。
- → e04：先逐街送水，夜里再贴确认边界的公告。

## n10 · 车轮与公告

第一辆水车从站门开出，车上没有写明去哪条街。司机打电话问下一站，方芷手里的取样图仍有一段空白；她看见老管街的人已经提桶站在门外。

- → e04：继续送水，等边界确认后解释延迟。
- → e03：现在贴出已知范围，随后再派车补水。

## e01 · 改过的字

方芷在公告上标出老管街区必须停用，学校可在重新取样合格后恢复。有人骂她早晨吓坏了孩子，校长却说若没有第一张纸，汤早已端上桌。水务站连夜送水到老管街。

三天后方芷把试瓶残留的原因也贴出来，和公告的每次修改并列。广场上桶还在，排队的人已知道该提水回哪条街。

## e02 · 空白处

原公告消失的四十分钟，群聊里传出“全城水里有毒”的截屏。实验室最终确认只有两条旧管有问题，水务站发了精确地图，仍有人不信这张迟来的图。

方芷和同事逐户解释，走到学校时锅里的汤已经倒了。校长问为什么公告曾空了一段，她把撤稿的决定写在调查记录上，请主管一同签名。

## e03 · 第二张纸

方芷在街口贴出停水范围，说明学校先前得到通知，住户没有。北区有人拿着这句话向水务站索赔；学校运动会取消，医院的储水撑过了当天。老管更换用了六日。

听证会上，方芷带来两只原始试瓶，也带来通知时间表。家长问她下次会不会仍先给学校打电话。她说会，同时要让电话之后五分钟内有一张给所有人的纸。

## e04 · 送水车

水车先到老管街，后到新报异味的街。车没到的地方，邻居仍用旧管煮了午饭。实验室当晚划出范围，方芷半夜贴公告，第二天医生接诊三名腹痛的人，原因还需逐一查证。

水车司机把车次和停靠点交给她，她一行行对照住户地址。明年换管预算通过时，方芷要求附上公开预警流程；那三人的地址被写在说明第一页。

## e05 · 校门口

方芷站在校门口说明检测异常尚未确认，请食堂先别端汤。家长看见水车，立刻有人拍照发到群里；她只好当场说出采样位置和复测时间。最后一瓶确认学校样本受试瓶残留影响，老管街的异常却属实。

学校多停水半天，午餐改成面包。方芷在当晚公告里写清两处样本为何不同，水车转去老管街。校长把上午那桶没端出的汤倒掉，先向厨师解释原因。

## e06 · 提前备好的车

最后一瓶确认老管街受污染时，水车已装满，司机直接驶往那里。学校样本是误报，运动会照常结束；但老管街的几户人已用水煮了午饭。方芷随车逐户通知，仍比第一只试瓶变色晚了三个小时。

她把时间差写在复测报告首页。下一次有人说“先准备总比什么都不做强”，她会同意，然后问准备好的车要凭什么才能开出站门。
