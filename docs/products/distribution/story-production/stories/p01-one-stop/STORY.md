# 一站之座

## n01 · 还剩一站

我上车时，电子屏显示离我要下的站只剩一站，离终点还有三站。我昨晚搬了一夜书，膝盖像装了两枚生锈的门轴。全车只剩一个空座，上面放着一只装热馅饼的纸袋。袋子的主人不在附近，至少没有人承认。

司机催我刷卡，身后的人催我往里走。我可以拿起纸袋坐下，也可以问谁的袋子，替它找主人。

- → n04：拿起纸袋，在空座坐下。
- → n05：举起纸袋，问是谁的馅饼。

## n02 · 座位主人

我才坐稳，一位抱着植物盆的阿姨就说那是她的座。她买的馅饼给女儿，女儿两站前下了车，纸袋忘在这里。司机刹车，盆里的土撒在我鞋面上。阿姨不抢座，只问我能否把袋子递回去。

- → n07：把袋子和座位一起还给她。
- → n08：递回袋子，说明自己只坐到下一站。

## n03 · 举证

乘客们依次否认纸袋，直到车尾一个孩子举手，说是他母亲的。那位抱植物盆的阿姨正在帮一位拄拐的人找零钱，没看见他。孩子穿过车厢接袋子，车一晃，馅饼落在空座上，烫出一个油圆。

- → n09：清掉碎屑，请拄拐的人先坐。
- → n10：自己坐下，替母亲把袋子送过去。

## n04 · 袋底还热

纸袋刚离开座垫，里面的馅饼就烫得我换了只手。一个孩子从后排探头看，又很快缩回去。我把袋子放在膝上，想坐一站就下车；车还没开稳，抱植物盆的阿姨已经走到我面前。

- → n02：抬头问她是不是袋子的主人。
- → n06：先把袋子举高，问车里还有谁认识它。

## n05 · 一车厢的否认

我举起纸袋，前排有人摇头，后排有人把目光挪向窗外。司机从后视镜里说下站只停二十秒，要找主人得快。纸袋上的油正在透出来，把我的手指染成半透明。

- → n03：从前排问到车尾，等那个举手的人。
- → n06：先请司机等一站，免得馅饼留在车上。

## n06 · 下站的二十秒

车靠站，孩子挤到我身旁，说母亲就在前面。他伸手接袋子时，阿姨的花盆碰到扶手，土落在我的鞋上。司机说门要关了，站台上的人还没上完；我得先把东西交给能接住的人。

- → n02：转向抱花盆的阿姨，问她要不要坐下。
- → n03：让孩子带路，把袋子送到他的母亲那里。

## n07 · 让出的半步

阿姨接回袋子，却把座位往我这边让了半掌，说自己站得住。我已经站起来，膝盖一声轻响；她听见了，把没沾土的馅饼塞给我。车门将开，我的书箱还在脚边。

- → e01：谢她的馅饼，把座位和纸袋一同还给她。
- → e02：请她拿好纸袋，自己再坐到下一站。

## n08 · 下一站而已

我告诉阿姨只坐一站，她点头，抱着植物盆站在旁边。孩子替我盯着站牌，偏偏前方红灯排起长队；热馅饼的气味和一夜没睡的困意一起升上来。

- → e02：坐到下一站，承担睡过站的风险。
- → e01：现在起身，把座位还给阿姨。

## n09 · 油圆边缘

我用纸巾擦座位，油印只淡了一圈。拄拐的人扶着杆等我擦完，司机又提醒下一站就到了。孩子把剩下的饼握在掌心，问我是不是要下车。

- → e03：请拄拐的人坐，自己握着饼到终点。
- → e04：先坐下替孩子递饼，再把座让出来。

## n10 · 一块热饼

我坐下时裤脚碰到了油圆。母亲伸手接袋，拄拐的人就在她背后；孩子盯着我腿上的印子，像想提醒又不敢说。刹车灯亮了，我还来得及站起来。

- → e04：送回袋子，起身请拄拐的人坐。
- → e03：先擦净座位，让他坐下再送饼。

## e01 · 门轴

阿姨坐下，把植物盆放在脚边，还硬塞给我一个馅饼。到站时我扶着门杆下车，膝盖照旧吱呀作响。她隔着车窗喊：“你的鞋！”我低头，发现鞋面上长了一棵小小的绿苗，是她盆里掉出的。

我把苗放在书箱里，走完回家的两条街。书箱很重，馅饼还热，车已经拐过街角。

## e02 · 下一站

阿姨把纸袋抱好，站到我旁边。前排的孩子数着“一、二、三”，像给我剩下的坐姿计时；我偏偏在红灯处睡着了。醒来车已进终点，司机敲扶手叫我下车。阿姨早走了，鞋上的土还在。

我错过自己的路口，拖着腿往回走。车上多坐了三站，回家还得多走三站；晚餐时我把这账算给朋友听，她笑得险些把汤洒掉。

## e03 · 一站路

拄拐的人坐下，母亲一边道谢一边捡馅饼。孩子坚持给我一块没落地的，说我帮忙找到了主人。车到终点前，我一直握着那块烫手的饼，不敢再放到任何座位上。

下车时司机喊我把卡拿好。我摸遍口袋，卡压在手心里，已经被热馅饼蒸得卷起一角。

## e04 · 油圆

我坐在油圆旁边，把纸袋送回母亲手里。拄拐的人仍站着，司机下一脚刹车让他撞到扶手。我起身请他坐，裤脚留下一圈油印。孩子看了一眼，说那是他母亲最喜欢的馅。

到站后我在玻璃门上看见裤脚，像被盖了个证明到此一游的章。膝盖没休息够，倒多了一个可以笑自己的理由。
