# 第二次掌声

## n01 · 红灯

颁奖厅里，你的名字被念得很慢，像一枚金币在桌上旋转。你接过年度记忆修复奖，台下那位失踪矿工的母亲也坐在第一排。大屏幕播放你修复的录音：矿难发生前，矿工说他自愿留下。掌声盖住录音最后的杂音。

主持人把话筒递来，要你说一句最能代表这份工作的感想。你昨夜反复听过原带，那段杂音里其实还有一个声音，命令矿工别离开。

- → n04：照着提词屏感谢机构，让掌声继续。
- → n05：在直播话筒前说出你听见的第二个声音。

## n02 · 不属于你的醒来

你说得很好，连矿工的母亲都站起来鼓掌。她走到台边，问能否听到完整原带。你答应了。台上的红灯忽然灭掉，天花板裂出一条晨光。

闹钟把你叫醒。奖项是梦，母亲的约见是真的。录音机构八点要你签字，确认“自愿留下”的修复文本。你手机里还有昨晚截下的那段命令，声纹指向机构的一名主管。

- → n07：带着截录去见矿工母亲，推迟签字。
- → n08：签下文本，按约把完整原带交给她。

## n03 · 空场

你说出第二个声音，台下没有人喊叫。主持人低头看提词屏，像那上面写着一个你看不见的句号。矿工母亲起身，朝你走来；每跨一步，座椅便少一排。

闹钟响了。你在自己房间，昨夜截下的命令还在手机里。八点前机构要拿到你的确认签名；矿工母亲八点半会到门口。梦里你已经说过一次，现实中红灯还没亮。

- → n09：把截录发给公开听证会，同时去见她。
- → n10：先让她听原带，由她决定是否公开。

## n04 · 提词屏的下一行

屏幕滚出“感谢修复团队”几个字。你照着念，台下母亲的脸被一道追光照亮，她没有笑，只把手放在座椅扶手上。掌声像一层厚布盖住录音尾端，那个发号施令的声音却在你耳里越来越清楚。

- → n02：把致辞说完，走下台后再面对她。
- → n06：在最后一句前停住，请播放员重放原带尾声。

## n05 · 一句不在稿上的话

你说录音里还有第二个声音。主持人的手停在话筒线边，导播间的玻璃后有人摘下耳机。矿工母亲站起身，不是为你鼓掌，而是想走近听清；你还没说那声音属于谁。

- → n03：把你听见的命令说完整。
- → n06：请现场先放未经修复的最后十秒。

## n06 · 没有播出的十秒

播放员按下暂停，大屏幕只剩一条静止的波形。你在梦里看见波峰后面又多出一根细线，像有人隔着矿井石壁敲了一下。主持人问你要继续致辞还是说明录音差异；你抬头，红灯仍亮。

- → n02：先把致辞说完，醒来后再核对原带。
- → n03：当众说出那句命令，承受现场的沉默。

## n07 · 八点前的门铃

梦醒后，手机上的截录还在。你把签字笔放回抽屉，先打开原带文件核对时间戳；门铃响时，离八点只差七分钟。矿工母亲站在门外，手里拿着一副旧耳机，你没有先替她按播放键。

- → e01：请她进来听完整原带，再谈是否公开。
- → e02：先去机构签字，把原带按约交给她。

## n08 · 签名栏旁

机构的表格留着一格“修复者确认”。你把声纹截图放在纸边，主管只看了一眼，说“那是另一次录音的串音”。你请他写下这句话，他把笔推回来。矿工母亲的约见时间已经过了五分钟。

- → e02：签下机构文本，再把原带交给她。
- → e01：先离开签字桌，把原带交给她自己听。

## n09 · 发送之前

听证会的收件箱已填好，附件名却会把矿工最后一分钟完整暴露给陌生人。你想起梦里母亲从第一排走来的样子，把公开链接从屏幕上移开又移回。她尚不知道你昨夜发现了什么。

- → e03：发送截录给听证会，并当面承担她的责问。
- → e01：先去见她，让她决定公开的范围。

## n10 · 耳机的另一端

你给她留了一个可以暂停的按钮。母亲先听见儿子的声音，随后听见命令，手指一直放在播放器边。机构在手机上催签字，你把屏幕翻扣在桌上；这一次没有提词屏告诉你何时开口。

- → e01：让她把原带听完，再一起决定证据怎样提交。

## e01 · 两个人听

矿工母亲把耳机戴上，听到命令时没有立刻摘下。录音转到儿子最后一句，她才用手指按住播放器，不让它继续。你告诉她声纹比对只能说明高度相似，听证会会要求原带和设备记录。她说她要去，也要你去。

机构下午撤掉你的权限。她走出门前，把耳机还给你；红色播放灯仍亮着，声音还停在那句命令之前。

## e02 · 签名

你签了字。矿工母亲在大厅的公用播放器上听完原带，指着文本没有写进的那句命令问你：“这是谁删的？”你说自己只负责修复，她看了看纸上的签名，没再问第二次。

当晚机构宣布录音争议已解决。你回家路过电器店，橱窗里的直播重播颁奖典礼；梦里那个奖杯没有出现，屏幕只映出你握着笔的手。

## e03 · 直播开始

截录先于你抵达听证会，机构的律师也先到了。矿工母亲在门口看见你，目光落在手机屏幕上的公开链接。她说：“你本来可以先告诉我。”你没有辩解。你们一同进去，却坐在不同的席位。

公开播出的声纹让调查开始，也让她儿子的最后一分钟在一夜间被陌生人反复截取。你作证时，话筒红灯亮了。散场后你把手机递给她，屏幕上是你写好、尚未发出的撤下片段申请；她接过去，从第一行开始改。
