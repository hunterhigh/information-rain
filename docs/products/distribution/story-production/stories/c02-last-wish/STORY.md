# 最后一道门

## n01 · 套餐

殡仪馆的柜台上摆着三张套餐表，周遥手里却只有父亲写在木屑背面的七个字：送我回旧桥那边。桥在拆迁区，车不能进，馆方说绕行要加钱，按标准路线则能赶上今天的火化。

哥哥把银行卡放到桌上：“照表办吧，爸不会怪你。”周遥看见卡角有一道他咬出的印。她可以先争取绕路的费用，也可以先去旧桥，确认父亲说的到底是哪一处。

- → n04：跟馆方谈一条能抵达旧桥的路线。
- → n05：请哥哥守在馆里，自己先去旧桥。

## n02 · 账单

经理同意绕路，但要撤掉花车和告别厅，费用才够。哥哥不肯：“姨妈已经通知亲戚来厅里。”周遥把父亲的木屑纸推到他面前，哥哥读完才说，父亲最后几年从不愿提旧屋。

柜台后的时钟走过九点。周遥可以删去告别厅，让亲友到桥边送行；也可以保留仪式，将父亲的纸条交给档案员，请她记录未完成的愿望。

- → n07：撤掉告别厅，绕路去旧桥。
- → n08：按原路线送行，留下父亲的纸条。

## n03 · 两根门柱

旧桥已没了桥面，只剩两根门柱似的石墩。父亲年轻时做过桥上的木栏；拆桥的工人说，栏板被存进了区仓库。周遥拨给哥哥，哥哥说馆方还能等四十分钟。

她可以带走一小片栏板，在原定仪式上讲清父亲的工作；也可以请求把灵车开到石墩旁，哪怕没法等所有亲戚到齐。

- → n09：带栏板回馆，保留家人聚齐的送别。
- → n10：让灵车到旧桥石墩，叫亲友自行赶来。

## n04 · 路障之前

周遥在地图上把能走的街一条条圈出来，司机指着最后一个路口：“车只到这里，剩下要抬。”哥哥看见那段细线，问她有没有想过姨妈的腿。周遥把父亲那张木屑纸压在地图角上，七个字一半落在桥边。

- → n02：同馆方重算费用，把能走和要步行的路写清。
- → n06：先去旧桥看看，确认那段路现在能不能走。

## n05 · 先到的人

周遥把柜台留给哥哥，独自走过拆迁围板。她记得父亲说过桥栏要顺木纹刨，拐弯时却认不出原来的街。工人从围板内推车出来，木屑沾在袖口；她举起那张纸，工人先看见的是背面的铅笔痕。

- → n03：继续找桥面留下的东西，打电话给哥哥报位置。
- → n06：先问工人灵车有没有可能靠近旧桥。

## n06 · 四十分钟

哥哥打来电话，馆方最多还能等四十分钟。周遥站在路障边，能看见石墩，也能看见车轮到不了的碎砖。她把电话开免提，让司机和哥哥都听见同一句话：旧桥并没有全消失，今天的送行仍须有人决定在哪儿开始。

- → n02：回馆里改路线和费用，争取让全家到桥边。
- → n03：先走到石墩，找一个灵车能停的近处。

## n07 · 被撤掉的厅

告别厅取消后，姨妈的名字仍在来宾表上。周遥一户户打电话，说不再有椅子和录音，只能在灰路上站一会儿。有人说赶不上，她没有劝；哥哥在旁边数车费，数完把单子折进衣袋。

- → e01：让愿意来的人在桥边送父亲最后一程。
- → e02：把车改回原路线，至少保留完整的告别仪式。

## n08 · 未完成的一栏

档案员找出一张空白附页，让周遥自己写父亲的愿望。她写下“旧桥”，笔停在“抵达时间”前。哥哥说纸条也能留下，但纸不能替车轮走路；她抬头看见厅门外亲戚已经到了。

- → e02：把愿望订进记录，按原路线送行。
- → e01：放下附页，临时改去旧桥，请亲友自行赶来。

## n09 · 木栏上的尺寸

区仓库的看守找出一块旧栏板，背面有父亲写错又改过的尺寸。周遥不敢拆整块，只取下一片已松动的边角。回馆的路上，她把木片包在手帕里，想好要在亲戚面前讲那一夜父亲补木栏的事。

- → e03：带木片回告别厅，让父亲的手艺被家人听见。
- → e04：请灵车转到石墩，把木片留在桥边。

## n10 · 石墩旁的空地

周遥找到能停一辆车的硬地，石墩在十步之外。她把位置发给哥哥，屏幕上接连弹出姨妈和两个表亲的问号。司机已打开车门等答复；如果现在开进来，亲友是否能赶上，只能由他们自己决定。

- → e04：让灵车先到石墩，通知亲友自行赶来。
- → n09：先去仓库取一片木栏，再回馆里等家人到齐。

## e01 · 桥边

灵车绕进拆迁路，鞋底沾了灰的亲戚陆续追来。姨妈抱怨没有椅子，站久后却开始说父亲当年怎样在暴雨里修桥。哥哥扶着她，没再看空着的花车位置。

车离开时，周遥把木屑纸折进衣袋。父亲没留下解释旧桥的话，她也不替他说；桥边那一小段石路，今天确实有人陪他走过。

## e02 · 存档

告别厅里有花、录音和完整的座位。周遥在读悼词时停了一次，把那张纸交给档案员，请她和火化记录订在一起。哥哥当晚开车带她去旧桥，车停在路障外。

他们在那里没有补一场仪式，只把父亲用过的尺子放在石墩上量了量。哥哥说下周再来，把桥栏存放的地方问清楚。

## e03 · 一小片木

周遥带回被虫蛀出的窄木片。告别厅的灯白得刺眼，她在台上讲父亲做栏板时，把尺寸写错一寸，后来补了整夜。姨妈笑出声，哥哥第一次知道那夜父亲没有回家。

她将木片放进父亲的衣袋。车按标准路线走了，没经过桥；送别结束后，她和哥哥带着新问来的仓库地址去了旧街。

## e04 · 迟到的人

灵车停在石墩旁，只有哥哥赶在出发前到。姨妈迟了十分钟，周遥已经请司机慢慢开走。姨妈骂她擅作主张，骂完又要了一张桥的照片，带回去给没到场的人看。

那晚哥哥替周遥修父亲留下的木门，门仍歪一点。她说不必再刨，父亲每次关门都用肩轻顶一下。哥哥试了试，门恰好合上。
