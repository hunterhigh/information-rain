# 两封未寄的信

## n01 · 排练箱

我在排练箱里找到两封信。修布景的路遥邀我周日去看老戏院拆下的吊灯；演员陈镜邀我在首演后去河边吃面。两人都写了“如果你愿意”，字迹却完全不同。今晚首演，我必须把排练箱清空，信不能再藏回去。

我和路遥相处时总能安静做事；陈镜一开口，连我坏了的台词也能接成笑话。我把两封信放在化妆台上，先决定和谁当面谈。

- → n04：找路遥，问那盏吊灯为什么值得看。
- → n05：找陈镜，谈首演之后的那碗面。

## n02 · 拆下的光

路遥带我到后台，吊灯已拆成几十片玻璃。他说想请我挑一片做书签，不必答应周日的约会。灯光打在他的手背，旧玻璃割出一道细口。我替他拿来药箱，才想起陈镜的信还在衣袋里。

- → n07：答应路遥周日去看吊灯，也坦白另有邀请。
- → n08：谢绝约会，先给陈镜一个明确回复。

## n03 · 首演前

陈镜正在练那句总忘词的台词，见我来，先让我替他听一遍。他问我是否看过信，语速很快，手却把折好的剧本捏出皱痕。我可以答应吃面，说明今晚还会向路遥回信；也可以说现在不愿开始任何约会，独自看完首演。

- → n09：答应吃面，演后向路遥回信。
- → n10：婉拒两封邀请，自己坐进观众席。

## n04 · 后台的门帘

路遥在门帘后扶一盏只剩骨架的灯，指尖沾着玻璃粉。我还没开口，他先问我能不能帮忙拿住那截铜环。我想到陈镜的信，没把它藏到更深的口袋，只用空着的手握住铜环。

- → n02：问路遥为什么想让我看这盏灯。
- → n06：先确认今晚两封信都要回复，再谈邀请。

## n05 · 忘词的地方

陈镜在舞台边反复念同一句，总在最后一个字前停住。看到我，他想把停顿讲成笑话，笑到一半却看向我手里的两封信。场务催他去候场，走廊只剩不到一分钟。

- → n03：趁这分钟谈首演后的面。
- → n06：先说我还要回复另一个人，不给他含糊的答复。

## n06 · 两封信的纸边

排练铃响了。我把两封信并排放在空椅上，路遥那封边缘沾了金色粉，陈镜那封被反复折出白线。两个人都给了我拒绝的余地；我不能拿其中一封当作拖延另一封的借口。

- → n02：先和路遥谈那盏灯，再把话说明白。
- → n03：先和陈镜谈吃面，演后立即回复路遥。

## n07 · 玻璃片的裂缝

路遥挑出的玻璃片边缘有一道旧裂。他说能磨平，再问我周日来不来。我告诉他还有另一封邀请，话说完才发现自己一直捏着药箱的纱布。他没有催，只把那片玻璃放在灯下让我看清。

- → e01：答应周日去仓库，也给陈镜明确回信。
- → e02：放下玻璃片，先回应陈镜的邀请。

## n08 · 幕边的回信

我把玻璃片放回盒中，路遥替我合上盖，没有问我是不是选了别人。陈镜已经上场，幕边只能听见他把那句老忘的台词说对。我可以等他谢幕，也可以今晚就各自写信，不把误会拖到明天。

- → e02：谢幕之后答应那碗面，次日回绝路遥。
- → e04：今夜回绝两人，独自看完首演。

## n09 · 面馆的方向

陈镜说河边有家小店，散场后灯还能亮半个钟头。我告诉他我会去，也要先给路遥回信。他把剧本翻到空白页，让我写下店名，像怕舞台一忙又把这句约定弄丢。

- → e03：演后赴约，并给路遥一封清楚的回信。
- → e04：擦掉店名，告诉两人今晚都不赴约。

## n10 · 第七排的座位

我找到了第七排的票，纸上印着我的名字。陈镜在幕边向我挥手，路遥正把吊景升起；两个人都要把今晚的戏做完。我也可以先把两封信写完，再坐下来看这场首演属于谁。

- → e04：清楚回绝两人，然后独自坐进观众席。
- → e03：演后去吃面，把给路遥的回复写好。

## e01 · 一片玻璃

首演后我先写信给陈镜，感谢他，说明不会去吃面。周日路遥带我看吊灯仓库，玻璃片在桌上排成一条小河。他没问我为何选他，我也没用“比较”来解释。

我们挑了一片有裂纹的，夹进一本剧本。第二年戏院换新灯时，我仍记得那道裂缝从哪边开始；路遥每次说自己修得不好，我就把书翻到那页。

## e02 · 回信

我把玻璃片放回盒里，去找陈镜。路遥听我说完，指了指外面：“他快上场了。”我在幕边等到谢幕，才答应那碗面。陈镜紧张得把辣椒撒进了我的汤，赔罪时又讲起自己小时候第一次登台。

第二天我把拒绝约会的信交给路遥。他照常来修景片，只是几周内不再同我一起收箱子。我没有追上去要求他立刻和好。

## e03 · 河边面馆

陈镜演完最后一句台词就来找我，妆还没卸干净。我们在河边吃面，他没有像台上那样抢着讲笑话，反而问我白天究竟在做什么。回去后我写给路遥，告诉他这次不去看吊灯。

路遥把信收下，第二天将一小块安全的玻璃片放在排练箱里，当作给全剧组的纪念。我没把它当作一句没说出的邀请。

## e04 · 观众席

我给两人分别回了信，把排练箱清空。首演时我坐在第七排，陈镜忘了半句台词，路遥在暗处挪了吊景，舞台照样转了过去。谢幕后他们各自忙，我一个人沿河走到面馆。

老板说只剩一碗面。我坐下，打开剧本，看见有人在页边写“这里停一拍”。我照着停了一拍，再翻下一页。
