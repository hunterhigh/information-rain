# 死者簿上的空格

## n01 · 湿纸

风灾后的收容站只有一支能写的笔。登记员乌青正在为停尸棚里的无名者画衣物特征，医生从隔壁喊她帮忙抬伤员；抬人要越过积水，回来后纸可能被潮气泡烂。等候认领的家属已在门口站了一排。

乌青能先把笔交给家属，让他们记认得出的名字；也能带笔去医生那里，边帮忙边记录伤者身份。

- → n02：把簿留给家属，先去抬伤员。
- → n03：带簿进诊室，先记录需要救治的人。

## n02 · 借笔的人

乌青回来时，一位家属在簿上写了三个名字，旁边有人反对：其中一个人只是失联，不能被写成死亡。医生又派人来催，说一名伤员需要转院，身份不明会耽误手续。

- → e01：保留家属笔迹，加上“待核实”，去办转院。
- → e02：暂停转院协助，逐一核实簿上名字。

## n03 · 病床号

乌青在诊室记下七名伤员，帮医生联系到一辆转院车。停尸棚的看守来找她：雨水正漫过木箱，一张旧口袋里的证件快化了。车司机已经发动引擎，她现在离开，最后一名伤员的转院单要别人补。

- → e03：请医生代补转院单，去抢救证件。
- → e04：写完转院单，再去辨认停尸棚。

## e01 · 铅笔字

转院车赶在桥封前走了。乌青给那三个名字都标上“待核实”，当晚找到其中一位失联者还活着。家属红着脸来改簿，他指着自己写下的笔迹，说以后要先问清楚。

其余两位的身份在第三天确认。乌青没擦掉铅笔下方的压痕，旁边注明了核实时间；那一页记录了等待中的错误，也记录了改正。

## e02 · 每个字

乌青核实出两个名字，第三位确实还活着。转院单晚了二十分钟，伤员错过第一辆车，夜里由另一辆绕远路送走。医生在交班簿里写下延误，乌青在死者簿上也写下自己选择的时间。

一周后伤员寄来报平安的明信片。乌青把它放在两本簿中间，不拿任何一本去抵消另一本。

## e03 · 口袋里的布

乌青抢在纸化前辨出证件上的姓，名只剩半个偏旁。她把沾泥的布交给家属辨认，终于为无名者填上完整姓名。医生代补的转院单漏写一项过敏史，车到半路又折回核对。

伤员最终平安转院。乌青和医生一起改了表格：代填也要两人复核。死者簿那一页夹着布，不再是一个空格。

## e04 · 水线

转院车顺利开走。乌青赶到停尸棚，证件已泡散，只有口袋缝线还能辨认。她请看守不要丢，把衣物描述写下，连续四天请人来辨。第五天一位妹妹认出了姐姐自己缝的歪针脚。

名字终于落在纸上，旁边多了五个日期。妹妹问为何这么晚，乌青没有说“忙”，只把水线碰到簿页的那夜讲给她听。
