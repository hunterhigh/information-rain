# 三件行李

## n01 · 背包口

雾谷气象站失联六小时。救援员江篱要从陡坡上去，背包只能装三件：绳、保温毯、备用电池、采样箱。采样箱里有今晚山洪预报所需的雨量片；站里还有一名值班员。江篱把绳和毯先放进去，剩下一格留给电池或采样箱。

队长说太阳下山前必须走出谷口。江篱知道没电就无法与后方通话，没箱则拿不到雨量片。

- → n04：装电池，把采样箱留在坡下。
- → n05：装采样箱，不带备用电池。

## n02 · 呼吸声

值班员被倒下的架子压住腿，江篱用绳拖开架子，毯盖住他。无线电里队长说山洪可能提前，叫她立刻下山。值班员却指向台上最后一张手写雨量表，上面有一个异常的红点。

- → n07：拍下雨量表，背人立即撤离。
- → n08：先复核红点位置，再带人撤离。

## n03 · 纸片

江篱把雨量片装入箱，值班员已被冰雹打湿。她用毯裹住他，手机只剩一格电，没有信号。谷口分两条路：近路有松动的碎石坡，远路沿溪流走，若洪水先到就会堵死。

- → n09：走碎石坡，绳先系在值班员身上。
- → n10：沿溪走远路，先护住装雨量片的箱子。

## n04 · 第三格

电池卡进背包最后一格，采样箱只能留在坡下。江篱把箱子盖扣紧，拜托后队来取；队长在电台里重复了接收位置。山上冰雹刚停，站里的天线却一直没有动静。

- → n02：循着天线进站，先找值班员。
- → n06：先问队长下游水位，再决定带什么资料走。

## n05 · 纸箱的重量

采样箱比电池轻，江篱仍觉得背包往一侧坠。没有备用电源，站上唯一能把信息传出去的可能是值班员手机。她把绳盘在肩上，走近门时听见里面有人敲了两下铁架。

- → n03：进站取雨量片，查看值班员的伤势。
- → n06：先敲门应答，确认他还能指路。

## n06 · 最后一声无线电

山下的队长说水位正在涨，随后信号断成杂音。江篱在站外找到一张被雨打湿的旧预报图，上游支沟和村庄只隔一个折角。她把图塞进衣服里，推开站门。

- → n02：先救人，再用电池向后方报告红点。
- → n03：先取雨量片，带人走出无信号的山谷。

## n07 · 模糊的红点

手机屏上的照片糊了一层水汽。江篱用手指在屏上描了红点的边，值班员说那个点也许在旁边一格；背包里的电台传来队长催撤的声音，屋外碎石开始往下滚。

- → e01：传出照片，先背值班员下山。
- → e02：再查原表，把准确坐标报给队长。

## n08 · 一格之差

江篱把纸摊在膝上，重新对齐刻度。红点确实落在另一条支沟，她向队长报坐标时，脚下的石头被水推得微微一晃。值班员握住绳，示意她别再看纸了。

- → e02：报准位置，带人沿碎石坡撤离。
- → e01：先把照片传出，背人离开险坡。

## n09 · 绳结

江篱把绳系在值班员腰上，自己踩上第一块碎石。采样箱在背包侧袋敲着岩壁，她不敢把手腾开；值班员抬头看了一眼将黑的天，说能不能先把箱子交给她。

- → e03：先护人下坡，箱子滑落也继续走。
- → e04：改沿溪绕行，把人和雨量片一起带出。

## n10 · 溪流声

沿溪的路更平，水声却越来越近。江篱把箱子垫在值班员背后，桥头有一截新冲来的树枝；若桥先断，两人只能在高地等到天亮。值班员伸手替她托住箱底。

- → e04：走远路，遇洪水就在高处过夜。
- → e03：折回碎石坡，把绳先系到值班员身上。

## e01 · 照片

江篱背着人到谷口时，手机拍的红点已经模糊。队长根据照片先发出低区撤离通知，后来复核才发现站里的笔墨晕开了，红点位置差了一格。幸好下游水位真在涨，撤离仍救了人，也让一批农具泡在无人看守的院里。

值班员脱险后补画雨量表，江篱把那张模糊照片和修正表并排交给调度室。

## e02 · 一格的时间

江篱复核出红点属于上游另一支沟，把坐标用无线电报给队长。两人下坡时碎石已被水打松，绳拉断一股，她把值班员推到安全处，自己摔伤了脚踝。

洪水绕开村庄，淹的是废弃矿棚。她在医院听到这个消息，先问带回的雨量表有没有干。队长把表摊在窗边，纸角压着一颗小石头。

## e03 · 借来的脚

江篱把绳系在值班员腰间，自己先试每块石头。采样箱滚下坡，雨量片散在水里；两人在落日前到了谷口。值班员的脚伤未加重，预报组却失去最靠近山顶的一组数据，只能按更宽的范围发布警报。

山下的人多撤了两个村。江篱在报告中写清箱子掉落的位置，等路重新开放，她会陪调查队回去找。

## e04 · 溪边

江篱把箱子垫在值班员背后，沿溪一步步走。洪水先冲断回谷口的木桥，她们困在高处一夜，靠保温毯轮流裹住双腿。第二天救援机找到她们，雨量片完整，值班员却因失温住院很久。

预报组用数据缩小了撤离范围。江篱去病房时没提这个好处，只带来站里那只没坏的搪瓷杯，让值班员先喝一口热水。
