# 钟城入门

## n01 · 测音石

钟城招学徒的队伍排到堤上。穆禾把湿透的推荐信折成四层，仍遮不住落款：旧河区。钟院不收那里的孩子，据说他们天生听不准钟差。她父亲却靠听闸门回声，在洪水来前敲响了第一声警钟。

考官把测音石交给她。穆禾一碰，院内七座钟同时偏了半拍。别人只听见杂响；她听见最小那座钟的齿轮里夹着沙，今晚报潮时它会慢。考官皱眉问她听出了什么，旁边已经有人记下她的姓。

- → n04：指出坏钟，冒着被当作异类的风险证明自己。
- → n05：只报出考试要求的音差，先拿到学徒名额。

## n02 · 七口钟

穆禾说完，考官带她进了钟房。齿轮果然藏着细沙，却不是洪水带来的：沙袋缝线新得发白。院长命人关门，让她今晚独自校钟，明早对外只说是院里例检。她可以得到正式名额；找到是谁动了钟，就另当别论。

堤外传来卖鱼人的叫声。报潮错半拍，旧河区第一批收网的人最先遭殃。穆禾握着拆下的沙袋，闻见上面有熟悉的码头桐油味。

- → n07：当众展示沙袋，让全城知道钟曾被动过。
- → n08：先校好钟，接受院长安排的无名学徒位置。

## n03 · 半拍之内

考官在纸上打了“合格”，让她去后院领工服。入夜后，小钟迟了半拍。穆禾隔着窗看见院长从钟房出来，袖口沾着白沙。她有了入院的钥匙，也看见堤外的渔船已经点灯准备离港。

值夜学徒问她怎么还不去睡。穆禾听见钟里沙粒滚动的声音，每转一圈都更重。现在拆钟会留下她的名字；沉默到天亮，旧河区的人未必有机会回来问。

- → n09：用学徒钥匙进钟房，独自校准并留下记录。
- → n10：叫醒堤外的人，把怀疑和自己的身份一起说出去。

## n04 · 落款的红墨

穆禾说出小钟里的沙，考官先看推荐信的落款，再看她的脸。排队的人向前挤了一步，有人问旧河区的耳朵能不能听七座钟。她没反驳，只把测音石贴到自己耳旁，让考官也听齿轮卡住的那一声。

- → n02：带考官去钟房，找出夹在齿轮里的沙。
- → n06：先请另一名学徒一起听，留一个见证。

## n05 · 合格的半拍

穆禾报出纸上要求的音差，考官打了勾。她握着学徒钥匙，仍听见那一座小钟慢半拍；堤外渔船已经开始备网。名额落到手里，没让坏钟自己变好。

- → n03：进院后按规程查钟，别在考试场多说。
- → n06：找一个愿意听的人，先说明小钟的危险。

## n06 · 两个人听

值夜学徒把耳朵贴近小钟，起初只听见轮齿，后来听出一粒沙在每转一圈时划过铜边。他说钟院今晚不准停钟检查，又问穆禾是否愿意把自己的名字写在记录上。堤外的渔船正往水边推。

- → n02：立刻向考官指出沙，要求进钟房查验。
- → n03：先以学徒身份入院，夜里留下检修记录。

## n07 · 沙袋的缝

沙袋的白线新得刺眼。穆禾把它放在窗前，码头桐油的味道还在，考官却说她若拿到外面，所有钟都要停。穆禾想到父亲那年敲响的警钟：停钟会乱，错钟也会乱。

- → e01：敲响练习钟，请全城先避开错误报潮。
- → e02：先校好小钟，再从院内调查沙袋来源。

## n08 · 没写名字的房间

院长给她一张学徒房的钥匙，门牌只写“第七钟助理”。穆禾用它打开小钟的侧盖，沙粒落在掌心；她也听见外头有人把练习钟锁上。明早报潮只要准时，今晚她做过什么便可能无人知道。

- → e02：校准小钟，暂时接受无名的位置。
- → e01：带沙袋和记录出门，让堤外的人先知情。

## n09 · 值夜簿

穆禾在值夜簿写下拆钟时刻，墨水浸开旧河区三个字。她没有看见谁塞了沙，只看见院长袖口的白粉；不能把怀疑写成目击。她把拆出的砂粒包好，压在簿页角上。

- → e03：校准后留下真实记录，署名承担夜检。
- → e01：不等天亮，拿记录去警告堤外渔船。

## n10 · 练习钟的绳

穆禾摸到练习钟绳，值夜学徒提醒她，擅敲会取消考试资格。她把推荐信塞进衣袋，手掌仍能摸出父亲落款的凸痕；小钟里那粒沙每转一圈，就离报潮又近一圈。

- → e01：拉响练习钟，让渔船先停下。
- → e03：带着学徒钥匙进钟房，留下署名记录。

## e01 · 提早的警钟

穆禾敲响手边的练习钟，堤上的渔船一艘艘熄灯。钟院说她擅自扰乱报潮，翌日撤了考试资格；城里的人却找出了沙袋，院长的儿子在商队账上留有收钱校慢钟的签名。

调查那天，旧河区的人在院门外等穆禾。有位老渔夫递来一只裂口小铜钟：“你父亲当年用它敲过一次。你今天再敲，就不用求人收你了。”穆禾接过钟，没有立刻回答。她想先问钟院谁负责清理那七口钟。

## e02 · 名字不在表上

她把小钟校回原位，报潮准时。第二天院长宣布例检完成，给她一间能避雨的学徒房，门口铭牌上只有“第七钟助理”。穆禾摸着那块新木牌，掌心还有沙袋留下的桐油味。

傍晚她在旧河区看见渔船平安回来。没人知道她昨夜做了什么。钟院的人已经把齿轮上的沙扫净；她把那根新缝线夹进推荐信里，决定下一次有人动钟时先拿它作证。

## e03 · 夜校

穆禾校好钟，在值夜簿写下拆出沙粒的时刻和位置，署了真名。报潮时渔船平安返航；天亮后院长看了簿子，没有升她为正式学徒，也没敢删那一页。他让她继续值最冷的夜班。

她白天在旧河区睡，夜里带着自己的铜工具回院。每次进门都要经过那本簿子。第一页记着她第一次被听见；后面还有很多空页。
