# 玻璃巢

## n01 · 灯芯碎了

岬角灯塔熄了。许渡沿着旋梯上行，听见礁外船只以三短一长回应求光。备用灯芯摔成碎玻璃；塔顶唯一能代替它的，是嵌在风巢里的一截透光羽骨。那只海鸟被上夜风暴掀断翅，羽骨还连着血肉。

许渡把手伸进巢里。鸟没有啄他，只把身体压在两枚尚未破壳的卵上。灯室地板积着雨，离下一轮船队转过暗礁只剩一刻钟。

- → n04：取下羽骨，立刻修灯。
- → n05：先固定鸟翼，另找不伤它的透光材料。

## n02 · 骨光

羽骨抽出时，鸟撞了一下他的手腕，随后安静了。许渡把它嵌进灯芯座，光束穿过暴雨，照到第一艘船的帆。塔下有人喊：还有一艘小渔船贴着更近的礁线，正靠鸟巢这侧的旧副灯找方向。

副灯的镜片坏了，需要把主灯转过去，会让外海的大船暂时失光。巢里的鸟还在呼吸，卵滚到雨水边。

- → n07：转动主灯照小渔船，让外海船队自己减速。
- → n08：维持主灯方向，先保住船队航道。

## n03 · 窗玻璃

许渡用围巾包住鸟翼，听见楼下守塔的小岚在敲门。她端着一块旧窗玻璃，边缘磨得发白：“能用，但裂纹会把光劈成两条。”两条光可能像两座灯塔，船在暗礁前会犹豫。

塔顶还有一面手动反射镜。许渡可以守在镜旁随船移动光束，让小岚去楼下照看鸟巢；也可以先掰开玻璃裂缝取其中完整的一条窄片，灯会弱，但不必有人在暴雨里持续操镜。

- → n09：亲手操镜，把两条散光合成一条路。
- → n10：裁成窄灯芯，赌船能看见那一点弱光。

## n04 · 巢边的雨

许渡把手伸向羽骨，鸟把卵往身下拢。他找来一块干布垫在巢沿，免得抽骨时把卵推入积水。塔外三短一长又响了一遍，这次更近；他不能先把鸟救好再去谈船。

- → n02：取下羽骨，抢在船队转礁前点亮主灯。
- → n06：先问小岚有没有别的透光材料可用。

## n05 · 被风吹开的药箱

小岚把药箱送上来，纱布在风里展开。许渡替鸟固定断翼时，它的爪子紧扣着巢边，不肯松开两枚卵。窗玻璃是唯一够大的备材，裂纹却像一条第二航道。

- → n03：用窗玻璃试光，尽量不碰羽骨。
- → n06：先到塔顶看两条航道究竟差多少角度。

## n06 · 两条水脊

许渡趴在塔窗边，一条水脊向外海大船弯去，另一条贴着近礁的小船。过去副灯能照后者，如今镜片碎了。小岚在楼下喊鸟巢还在漏雨；光源和光路是两件事，今晚却只能由同一双手处理。

- → n02：取羽骨点亮主灯，再决定光束照向哪里。
- → n03：保住鸟巢，用旧窗玻璃和手动镜试光。

## n07 · 灯座的止动销

主灯转向近礁时，止动销卡在半途。许渡用肩抵住灯座，窗外小渔船的帆终于从暗处露出来；外海船队却开始减速，号声在雨里彼此追撞。小岚问他要不要把灯转回去，手已搭上销柄。

- → e01：固定近礁光束，让外海船队自行降帆。
- → e02：转回主航道，先让大船安全过礁。

## n08 · 看不见的副灯

许渡守住外海方向，大船的帆一张张穿过光。礁边那艘小渔船只剩铃声，他看不见船底离石尖有多远。鸟在巢里动了一下，卵还贴着积水；他知道现在转灯，另一边会立刻失光。

- → e02：让主灯稳定照向船队，等小船自行减速。
- → e01：转灯照小船，请外海船队降帆等待。

## n09 · 镜柄的盐

许渡把手动镜柄用布缠住，仍被盐粒磨得发痛。小岚下楼照看鸟巢，靠哨声告诉他近礁是否还有船。两条散光在镜面上短暂重合，像一条会抖的路，他得决定能不能撑到最后一艘船经过。

- → e03：守着手动镜，不让分开的光误导船只。
- → e04：改裁窄玻璃，让光虽弱却稳定。

## n10 · 一线完整的玻璃

许渡沿裂纹掰下窄片，手套里的掌心被划开一点。装进灯座后，光只剩原来的一半；近礁的小船吹起铃，似乎看见，又似乎在请求他们等天亮。小岚问要不要改回手动镜。

- → e04：保持窄而稳定的灯光，让船自己决定减速。
- → e03：拆下窄片，亲手操镜引导船只。

## e01 · 两处光

许渡把主灯转向近礁，小渔船顺着光贴过石尖。外海三艘船同时降帆，最末那艘还是擦坏了船腹；水手在晨潮前堵住裂口。小岚上塔时，鸟已死去，两枚卵仍在巢里。

许渡把羽骨从灯芯里取下，放到巢边。新灯芯三日后才送到。那三夜他自己守灯，每次转动光束，都先去看有没有小船靠近礁侧。

## e02 · 外海

外海船队平安驶过，近礁的小渔船却等不到副灯，搁在浅石上。天亮后渔民涉水把人背回来，没有伤亡，船底的渔网和半个月的收获都留在礁上。

许渡提着修好的灯芯下楼时，鸟巢安静得只剩卵壳被雨滴敲出的细声。渔民没责怪他；领船的老人只问灯塔今夜能不能同时照见两条航道。许渡回答：还不能。

## e03 · 手动镜

许渡一手压住窗玻璃，一手转镜。光束被雨打得颤，却始终落在礁外的水脊上。第一艘船靠近时，他听见楼下小岚吹哨，提醒他还有更小的一艘。他一直站到风停，手臂抬不起来。

鸟熬过了夜，卵也没有浸水。晨光里小岚替他松开握镜的手指，发现指缝里的盐已磨破皮。许渡把玻璃卸下，决定下次送灯芯的船来时，先请人装一面不用独自举一夜的镜。

## e04 · 细光

窄灯芯只亮了半座塔。船队起初减速，随后循着一线稳光逐一绕过暗礁；最后的小船看不清，只能抛锚等天亮。许渡和小岚听了一夜礁外的铃，始终不知道船上有多少人。

天亮时，他们看见小船停在安全水道，水手正把湿帆重新升起。鸟在巢里抖了抖包着布的翅。许渡把那块剩下的裂玻璃留在窗台，提醒自己昨夜的光够用，是因为有人肯等。
