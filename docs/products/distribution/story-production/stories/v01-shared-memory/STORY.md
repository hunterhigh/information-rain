# 同一段雪

## n01 · 档案盒

清除员叶垣奉命销毁证人苏徊的档案。档案盒打开时，里面是一张雪地合影，两个人肩并肩，左边是他自己。叶垣不记得拍照那日，手背却有与照片里一模一样的烫伤。

苏徊被关在楼下一间没有窗的等候室。上级催他在钟响前按下销毁键。叶垣可以先去问苏徊那段雪，或先查档案盒里被剪掉的一页。

- → n02：到等候室见苏徊。
- → n03：翻查被剪掉的原始记录。

## n02 · 照片里的两人

苏徊看见照片，说那天他们一起把一批工人从雪线救出。叶垣后来签了保密书，她拒签，才被列为证人。她没求他相信自己，只问那些工人的名字还在不在。

- → e01：停止销毁，带她去查工人名单。
- → e02：照命令销毁证词，保留照片作私人记忆。

## n03 · 被剪的一页

被剪页的复写印还在盒底：事故责任人不是苏徊，而是下令封山的上级。叶垣当年的签字压在下方，说明他曾看过这页。他现在可以把原始记录复制给监督会，或先去找苏徊，问她愿不愿出面作证。

- → e03：立刻复制记录，提交监督会。
- → e04：先带证据见苏徊，由她决定公开范围。

## e01 · 名单

叶垣切断销毁机电源，带苏徊找到工人名单，十七个名字，一个也没少。他们把名单和照片送到监督会；叶垣的保密违约一同进入调查。苏徊走出大楼时天没有下雪，只把外套扣得很紧。

第二周有人来询问叶垣的旧签字。他不再说自己不记得，照着档案盒上的日期，把他愿意承担的部分一行行说完。

## e02 · 私人相册

销毁机吞掉证词，照片被叶垣藏进抽屉。苏徊离开等候室时没看他；她从别处找来两位工人，在街上举出事故时间和姓名。没有原档，她们的申诉被拖了很多年。

叶垣每年都看那张雪地照，记忆仍断在同一处。照片没替任何人作证，倒像一张收据，证明他曾亲手把可作证的东西烧掉。

## e03 · 复写纸

监督会收到复写纸，立刻暂停销毁程序。苏徊也因此在不知情时成了公开证人，记者堵在楼下，她躲进后门两天没有出门。叶垣找到她，说证据已经送出，听见她问：“我的名字是谁替我交的？”

调查开始了，她仍得自己决定是否到场。叶垣把监督会的地址留在桌上，退出等候室，去补一份说明他未经同意披露身份的记录。

## e04 · 她来决定

苏徊先看过被剪页，要求遮住一名仍在职工人的住址，再把记录交出去。监督会多花一日核实，但工人的姓名和封山命令终于进入案卷。叶垣的签字也在那里。

公开听证当天，苏徊没有坐在他旁边。散场时她说雪地里的事她记得，不代表两人要恢复过去的关系。叶垣把照片交给她，她夹进案卷，带走了自己的那一半记忆。
