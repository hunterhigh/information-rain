# 门牌背面

## n01 · 征用令

边城贴出征用令的早晨，余澄店门的铜牌又被人抹了灰。征用的是会修钟和线路的人；他两个孩子的学籍却因出生地盖着红章，一直办不下来。招募官指着表格说，只要他去前线修报时台，回来可以重新申请。

店里那座祖父钟停在六点。妻子把红章的拒绝书放在旁边，没劝他。余澄可以报名，带着招募官的口头承诺走；也可以留城，公开替被拒的家庭整理记录。

- → n04：报名修前线报时台。
- → n05：留城，开一本公开的拒绝记录簿。

## n02 · 误点

前线第一个冬天，余澄把被炮火震歪的钟校准。他收到妻子的信：孩子仍没入学，招募官已经调走。营长愿意替他写一封功绩证明，却要求他删去日志里一次误报的时间。那次误报让两名信使没能回来。

纸上的分钟差只占一行。余澄可以换证明，也可以保留原始日志，让回城后的申请更难。

- → n07：签更正单，带着功绩证明回家。
- → n08：保留误报记录，寄一份给信使家属。

## n03 · 名字册

余澄的记录簿放在店门口，最初只有三页，入夏时写满了两本。城政厅派人来，说愿意给他的孩子办学籍，条件是把其他人的名字册交给他们保管。妻子当晚把两本册子分别藏在钟壳里和灶台下。

余澄知道一家人的机会就在桌上，也知道这份名单一旦被收走，邻居再无凭据。

- → n09：交出原册，换取孩子入学。
- → n10：留下原册，组织邻居一起申请。

## n04 · 出城的表格

招募官递来一支不出墨的笔。余澄拿自己的铅笔签名，看见表格下方“家属优待”一栏空着。妻子没有替他追问，只把孩子的两张拒绝书折成小方块，塞进工具箱的缝里；一路上它们会同螺丝一起响。

- → n02：带着工具箱出城，亲自修前线报时台。
- → n06：要求把家属承诺写在纸上，再决定是否出城。

## n05 · 店门口的第一页

邻居第一个写下孩子的名字，写错了一个字，又用指甲刮掉重写。余澄把簿子挂到铜牌下，午后已有三户人来，有人站在街角望了很久却没靠近。公开的名字能聚人，也会让每个人被认出来。

- → n03：让邻居自己填写，再继续公开保存。
- → n06：先去问清城政厅如何使用这些记录。

## n06 · 同一枚红章

城政厅窗口的职员认出余澄，说前线证明和邻居联名册最后都要盖同一枚红章。她把印泥合上，不肯答应哪种办法更快。门外有孩子背着空书包跑过，余澄听见铜牌在风里碰了门框一下。

- → n02：接受前线工作，以个人功绩再来申请。
- → n03：回店里继续记录，让更多家庭一同递交。

## n07 · 更正单的背面

营长把更正单翻到空白背面，示意余澄在这里签字。那两名信使的姓名被记在另一册失踪簿上，时间若改了，家属就无法据此追查他们最后的路。纸并不厚，余澄隔着它摸到铅笔刻进桌面的凹槽。

- → e01：签字，带功绩证明回城，再独自记住真实时间。
- → e02：把更正单退回去，将原始日志寄给家属。

## n08 · 两封信

余澄把日志抄了两份，一封给家里，一封给信使家属。封口前，他发现自己没把可能失去功绩证明的事告诉妻子。营地邮袋明早才走，信还在手上；他可以加一行说明，也可以先让证据出去。

- → e02：寄出日志，并在给妻子的信里写清代价。
- → e01：抽回家属那封，改签更正单换证明。

## n09 · 钟壳里的册子

余澄把灶台下那本拿出来，边角被烟熏黄。妻子说城政厅只答应他们两个孩子，并没答应还册子的日期。门外有人来找自己的那一页，余澄隔着门听见纸在对方手里被搓皱。

- → e03：交出两本原册，换今天就能入学的盖章。
- → e04：不交原册，请来访的人一同签下一次申请。

## n10 · 钟声过街

第二本册子传到街对面的裁缝店。余澄怕遗失，逐页抄下名字，抄到自己孩子时停笔；他们也在等课桌，不能因为他选了公开记录就少算这一年。裁缝把纸推回来，说会轮到每一家作证。

- → e04：把册子交给轮值邻居，组织下一次联名申请。
- → e03：收回两本原册，先换自己孩子的入学证明。

## e01 · 铜牌

功绩证明换来了孩子的学籍，店门的灰却没少。余澄每年春天都接到军营送来的旧钟，修到那次误报的日期便停手喝一口水。二十年后，女儿拆开他的工具箱，看见一张未寄出的信使家属地址。

她问那一分钟发生了什么。余澄第一次没有拿“为了你们”作答，只把原来记在心里的时间写给她。女儿拿走纸条，第二天替他寄出了信。

## e02 · 没有证明

信使家属收到了日志，营长撤掉余澄的功绩申请。回城后，孩子又等了三个月才进学校，是妻子和邻居带着卷宗一同去争来的。余澄修钟的手冻得不太灵，常把小螺丝掉进地缝。

许多年后，女儿把那份日志装进边城档案馆。馆员问父亲的身份，她写“钟匠”；在旁边一栏，她写下两个信使的名字。

## e03 · 一本空簿

孩子入了学。城政厅收走册子后，其他家庭的申请逐一失去证人，几户人搬走，余澄没去送。他把店门铜牌擦得很亮，铜牌下面却仍有人刻了一个小小的问号。

女儿成年时在箱底找到册子的封面，没有内页。她去找那些搬走的人，花了六年重抄一本。余澄病中翻到自己的名字，纸边写着她补的一句：父亲也曾做过选择。

## e04 · 排队的人

余澄让邻居轮流保管两本册子。城政厅拒绝第一批申请，也拒绝第二批；第三次来时，队伍从店门排到街角。孩子晚了一年入学，妻子每天借课本给他们补字。

余澄老了，钟又慢了六分钟。女儿给它上弦，门外有人带着一张新的拒绝书来敲门。她打开记录簿，先问那人叫什么。
