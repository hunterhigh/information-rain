# 空场之后

## n01 · 谢幕

我在舞台上最后说了一次“水会退”。台下的人站起来，掌声沿着后排一步步靠近。三年前的洪水被编成一出剧，我演那个在闸口等父亲的孩子；现实中的父亲没有回来。导演给我递花，花茎上还缠着固定灯线的黑胶布。

散场时，我看见节目册把父亲写成了“自愿留守”。他当年被关在闸门外，这件事有一份维修记录。我去后台找导演，看到他正把下一场的台词贴在镜子上，其中一行是我此刻要说的话。

- → n04：拿维修记录质问导演，让他改掉父亲的死因。
- → n05：走到观众尚未离开的大厅，自己讲出记录。

## n02 · 镜子上的字

导演承认看过记录。“写成失误，剧会被停，”他说。他把一卷录音磁带放到桌上：那是父亲在闸口最后留下的声音，比维修记录更完整。导演说，只要我明晚照原剧演，他会把磁带交给我。

我拿起磁带盒，里面其实没有带，只有一张写着“下一场”的纸。镜中的我还握着花束，胶布从手指上慢慢松开。门外传来工作人员催换景的脚步。

- → n07：把空盒留在镜前，带维修记录去剧院外公开。
- → n08：答应再演一晚，换取他所说的原带。

## n03 · 观众席灯亮着

大厅里还有十几个人排队买剧照。我读出维修记录的日期和闸门编号，一个女人问：“那今晚台上的孩子是谁？”我说：“也是我。”她把剧照放下。工作人员赶来，说剧院允许演后谈，但必须先报备主持人。

我望向大厅尽头。那里有一面给观众留话的白墙，写满“勇敢”“牺牲”和父亲的名字。还有一扇直接通向街道的玻璃门，门把上挂着刚收起的演出海报。

- → n09：留在大厅逐一回答，不让主持人替我整理说法。
- → n10：带记录到街上，把海报翻过来写真实经过。

## n04 · 胶布的黑印

我把维修记录从花束下抽出来，纸边粘上黑胶布。后台的换景声很近，导演正在对下一场的台词划线；他看到记录上的闸门编号，先认出了编号，才认出了我的手在抖。

- → n02：让他当面解释为什么改写父亲的死因。
- → n06：先找舞台档案，核对节目册是谁最后签发。

## n05 · 散场的人

大厅只剩十几个人，剧照摊在桌上。有人认出我，问演父亲那一幕是不是很难。我拿出维修记录，没有先回答难不难；那一页写着他被关在闸门外的时间，比台词晚了十一分钟。

- → n03：在还没走的观众面前读出记录。
- → n06：先找节目册的签发页，再说明错的是哪一句。

## n06 · 节目册的底稿

档案柜里留着三版节目册：最早一版写“被隔在闸外”，后两版变成“自愿留守”。我把三页并排拍下，听见大厅的门铃又响了一次。导演可以解释是谁改的，观众也有权听见改过以前的句子。

- → n02：带底稿回后台，让导演说明修改来源。
- → n03：带底稿到大厅，当场读出三版差异。

## n07 · 空磁带盒

我把盒盖打开给导演看，里面只有纸条，没有父亲的声音。他说真正的带在档案室，明天能拿；镜子上的新台词已贴好。他不是没有证据，只是在用证据换我再演一次。我的拇指仍粘着花束上的胶布。

- → e01：带记录去剧院外公开，不再等他的承诺。
- → e02：同意再演一晚，要求明天当面交原带。

## n08 · 明晚的排练表

导演在排练表上圈出我的名字，说演完就给原带。我请他把约定写在表背面，他犹豫，最终签了名。纸在我手里，今晚观众的掌声还在走廊里回响；明晚台上那句错话仍得从我口中说出。

- → e02：拿着签名再演一晚，随后取回原带。
- → e01：撕下排练表，带维修记录到街上公开。

## n09 · 一个观众的问题

那位放下剧照的女人问我为什么还演这出戏。我说剧院发工资，也说每次站在闸口道具旁，我都盼望那扇门这次能打开。她没有替我把话说得更体面，只把自己的电话号码写在节目册背面。

- → e03：留在大厅回答到关灯，再找印刷厂改册。
- → e01：拿着她的号码去街上，把记录写给更多人看。

## n10 · 海报的背面

海报从玻璃门取下，背面比我想的薄。卖票的老人帮我压住一角，问要写父亲的姓名还是闸门编号。我说都写，先写编号；号码不会哭，却能让明天来找记录的人找对地方。

- → e01：在街上写下真实经过，任路人停下来读。
- → e03：把海报带回大厅，继续亲自回答观众。

## e01 · 海报背面

风把海报吹得立不住。我请门口卖票的老人替我按住一角，在背面写下维修记录的编号和父亲被锁在外面的时间。几个散场的人停下来拍照，也有人说一场戏不该被这些细节毁掉。

第二天剧院撤下了演出。我没拿到原带；档案馆却来信，说他们找到另一份闸口通话记录，愿意让我先听。我把花束丢在门口，黑胶布还粘在拇指上，回家路上怎么也搓不掉。

## e02 · 明晚还有一场

我照原词演完，仍说“水会退”。谢幕时导演没有上台。后台镜子前放着真正的磁带，父亲的声音在前半段清楚，后半段被水声吞没。他没说自己愿意留下，只是反复问外面的人能不能开门。

磁带在我手里，观众却已经离开。明晚节目册还会照旧印。我坐在空场中央，从第一排座椅开始录自己的版本，这一次不等灯光师给信号。

## e03 · 留在灯下

我把记录递给每一个愿意看的观众。有人问父亲是不是救了别人，我说我不知道；有人问为什么还演这出戏，我说我需要这份工资，也想看看自己能不能在舞台上把他叫回来。

剧院最后关了大厅的灯。那位放下剧照的女人留下电话号码，说她家也有人在那场洪水里失踪。我没有替她承诺什么，只把节目册中“自愿留守”那一行划掉，明天去找印刷厂。
