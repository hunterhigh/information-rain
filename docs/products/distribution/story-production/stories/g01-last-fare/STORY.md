# 最后一程车费

## n01 · 表跳了

夜渡车的计价表在桥头跳到零。司机阿术收了乘客的车费，车后座的孩子却说父母还在河对岸的安置站等她。桥已经断了，码头只剩一班小船，阿术若离开现在的队伍，明早就赶不上车队的考核。

孩子手里有张被水泡糊的站牌。阿术可以照合同把她送到桥头，或者先开去码头，看看小船是否还在。

- → n04：停车结账，让孩子在桥头下车。
- → n05：开向码头，继续送她过河。

## n02 · 后视镜

孩子下车后站在雨里，没人接。阿术倒车回来，问她有没有能打通的电话。号码末尾缺了一位；码头的灯正在熄。车队管理员在频道里报考核时间，他还剩十分钟决定是否走。

- → n07：照车队路线离开，把孩子交给桥头值守员。
- → n08：取消考核，陪孩子等到有人确认接走。

## n03 · 尾班船

小船仍拴在码头，船工说只能载一个乘客，车得留下。阿术的车贷还有四个月，他若跟船走就得让车在没人的河岸过夜；只送孩子上船，河对岸的站牌又可能已经换了。

- → n09：让船工送孩子，自己守车并联络站方。
- → n10：锁车上船，亲自带她找父母。

## n04 · 雨里的站牌

孩子把泡软的站牌贴在车窗上，印出的地名有一半糊成蓝斑。阿术照合同按下结束行程，计价表的零仍亮着。他看见桥头值守棚有灯，却没人站在棚外接人，便把车窗降下一点，问她能不能认出对岸的站名。

- → n02：先让她在桥头等，再找值守员核对去向。
- → n06：不急着结单，查一查安置站是否已经搬走。

## n05 · 码头灯

阿术掉头时，车队频道里又报了一遍考核集合时间。孩子把站牌攥在胸前，没说谢谢，像怕这两个字一出口车就会停。码头灯从雨里浮出来，船工正把最后一根缆绳往桩上绕。

- → n03：赶到船边，问清小船能载多少人。
- → n06：先联系河西值守员，确认对岸还有人接船。

## n06 · 河西的回音

值守电话打了两次才通，对方说安置站搬过，孩子父母的名字尚未查到。阿术把旧站牌上的残字一个个念过去；值守员让他别再按旧地址开，先把孩子留在有灯的地方。船笛响了一声，桥头值守棚也亮着。

- → n02：把车开回桥头值守棚，当面办交接。
- → n03：到码头追尾班船，亲自核对对岸站点。

## n07 · 一张有姓名的收据

桥头值守员拿来收据，先写日期，才让孩子自己说名字。阿术看着她把姓字念错又重说，想起安置站的号码末尾仍缺一位。他若现在走，值守员会继续找；若留下，考核名单上那一格就会空着。

- → e01：签好交接，按车队路线赶去考核。
- → e02：把收据暂留在手里，陪孩子等河西回电。

## n08 · 雨棚里的十分钟

孩子在后座睡着前问过一次：“他们会不会找不到这里？”阿术把桥头值守棚的号码写在站牌背面，交给值守员。车队频道已经换了下一班车的名字；他把对讲机音量调低，让孩子先睡。

- → e02：留到父母确认接走，再给车队说明缺席。
- → e01：让值守员签收，自己去赶最后的考核时间。

## n09 · 对岸的三下光

船工把孩子接上船，阿术留在湿岸上。河西值守员答应接应，却只能用手电回应，他看不见上岸的人是谁。车后轮已经浸到水里，挪车会错过第一道光；不挪，车贷又会多一笔修理钱。

- → e03：守着信号直到确认孩子被接到，再处理车。
- → e04：锁车追上船，亲自陪她到安置站。

## n10 · 船板晃动

阿术把车钥匙装进内袋，船板在脚下沉了一寸。孩子终于松开站牌，问对岸会不会有食堂。船工说山坡上还亮着灯；阿术没有许诺一定找得到人，只让她记住刚才电话里那位值守员的名字。

- → e04：陪她下船，一路找到父母再回来。
- → e03：把她交给船工，回岸上联络值守员。

## e01 · 签收

值守员签了收据，阿术赶上考核，车队给他加了一个夜班名额。两天后他路过桥头，值守员告诉他孩子当晚被转去河西临时宿舍，父母第二天才找到她。收据上的字被雨晕了，但姓名还认得出。

阿术把这张单据留在车里，每遇到一个桥头目的地，先问对岸有没有人在等。

## e02 · 雨棚

管理员把阿术的名字从考核表划掉。值守员接到河西电话时，孩子已在后座睡着。父母从绕道来的货车上跳下，连谢都没说，先把她抱紧。阿术回到驾驶位，看见表还停在零。

第二周他换了一家不做考核的车行，收入少了些。孩子父亲寄来一张手画的新站牌，阿术贴在仪表盘旁，纸角总被暖风吹起。

## e03 · 留车的人

阿术看着小船划过去，按船工要求把站牌照片发给河西的值守员。二十分钟后，对岸的手电闪三下：接到人了。车在岸上被水泡坏一个轮毂，他修到凌晨，考核也错过了。

隔天车队说他没按时到场，不能补考。阿术在维修单背面写下河西值守员的号码，下一趟夜渡他会先问清楚是谁接船。

## e04 · 对岸

车门锁好后，阿术和孩子挤上船。对岸安置站已搬到山坡，船工给他们指了路。他们走了四十分钟才在食堂找到孩子的父母；父亲正端着两碗凉汤找人。

天亮后阿术回码头，车窗被砸，收款机不见了。他把损失报给车行，赔款分六个月扣。每逢有人问他这趟赚了多少，他说不出数字；他记得的是孩子在坡上认出父亲的那一声。
