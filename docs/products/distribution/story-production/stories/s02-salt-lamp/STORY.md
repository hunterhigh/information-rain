# 盐井最后的灯

## n01 · 第一声钟

第一声警钟从井顶传下来，阿榆脚下的盐壳便裂了。黑水从缝里冒出，先浸过靴底，再没过脚踝。她把瓷闸芯塞进衣襟；这东西要送进育幼层主泵，第三声钟前装不上，下面的门会被水压顶开。

腰带上还剩两支暖剂。拧断瓷颈，热液能让冻僵的手再听使唤半个时辰。井口铁栅里卡着一尾盲鱼，鳃盖一开一合，尾鳍把管壁敲出细小的三连音。阿榆见过这种鱼在水下穿过人进不去的裂缝。她也看见鱼腹已被盐刃划开，再不暖过来，它游不了。

- → n02：折一支暖剂倒进栅下的水里，先让鱼活过来。
- → n03：把两支暖剂收好，独自去找通往主泵的路。

## n02 · 白水里的尾音

热液在冷水里散成一缕橘色，盲鱼猛地摆尾，从栅齿间挤了出去。阿榆伸手去捞空瓷管，指尖已不大灵便。鱼没有游远，反而在前方旧检修口敲了三下。那是一道半塌的水缝，只容一个人侧身钻进去；水流直通育幼层，冲劲足以把闸芯从她衣里卷走。

干梯在另一边，扶手完好，图纸写着它也通主泵。第二声警钟忽然响了，铁梯上落下一阵白盐。阿榆手里只余一支暖剂，而鱼仍在水缝里等。

- → n04：把闸芯绑紧在腕上，跟着三连音钻入水缝。
- → n05：谢过那尾鱼，抓住干梯的扶手上行。

## n03 · 铁门后的人

阿榆循着图纸奔向主井。第二声钟响时，一声沉闷的锤击从检修铁门后传来。值夜的老苇被倒灌水压在门里，透过观察孔看见她，举起两根手指：门闩冻死了，他的腿也被架梁压住。老苇管过二十年旧井，知道育幼层每一条废弃的旁路。

阿榆摸到闩上的白霜。用一支暖剂能松开它，老苇也许还赶得上；但门内的水会在她救人时灌满靴筒。旁边另有一扇小铁盖，通向图纸上的直井。把暖剂浇在盖锁上，她可以一个人先下去。老苇又敲了一下门，这次很轻。

- → n06：先融开老苇的门闩，把人从梁下拖出来。
- → n07：融开直井铁盖，带闸芯先走。

## n04 · 水缝里的叉口

阿榆侧身挤进水缝，盐岩把她肩上的布撕开一道口。盲鱼在前方敲了三下，左边随即传来泵室铁叶的震动；右边有一股向上顶的缓流，通到干梯下方。她摸到腕上的绑绳正在松，第三声钟的绳锤已经被人拉起。

- → n08：扯下一截衣袖重新绑闸芯，跟鱼走向泵室。
- → e02：先攀进干梯井，保住闸芯和还能用的双手。

## n05 · 梯上的白盐

干梯每上一级，白盐便从扶手上剥落一级。阿榆看见铁梯顶端的检修牌：直通主泵，但阀门得先在下面手动卸压。她回头，鱼的三连音仍从隔墙传来。两条路都能送到闸芯；只有一条可能赶在钟声前把压力放尽。

- → n09：继续攀梯，找顶部的卸压手轮。
- → n08：从半开的检修口回到水缝，跟着鱼找底部阀门。

## n06 · 门闩后的重量

暖剂浇下去，门闩终于转动。老苇的腿压在梁下，阿榆拖不动；他用扳手敲了三下身后的薄砖，说砖后就是旧检修井。阿榆若现在拆砖，水会先撞进门内。老苇把扳手塞给她，手背上全是白霜。

- → n10：撑住门，把梁下的人先拖到砖墙旁。
- → e04：留下扳手和暖剂，先走直井送闸芯。

## n07 · 直井的盖

小铁盖开了一指宽。阿榆把第二支暖剂倒在锁眼，水汽扑到脸上；门里传来的锤声停了。她知道只要撬开盖，十几步便是泵室。也知道老苇还在门后，没人会比她更早听见那阵停下来的敲击。

- → e04：掀开铁盖，赶在钟响前装好闸芯。
- → n06：把盖放回去，转身去融老苇的门闩。

## n08 · 泵室门前

鱼在一道圆形铁门外打转。门缝很窄，阿榆只能先把闸芯递过去，再让水流把自己推入。瓷芯离手时，绳结会不会松，她看不见；身后的干梯口还在水面以上。铁叶转得越来越快，钟声却还没有落下。

- → e01：把绑绳咬在齿间，连人带闸芯挤进泵室。
- → e02：收回闸芯，改从干梯去主泵。

## n09 · 卸压手轮

梯顶的手轮被盐封住。阿榆用扳手敲掉一圈硬壳，轮盘只动了半格，便又卡死。水下传来三连音，盲鱼似乎找到了另一侧的闸口。她把最后一支暖剂捏在掌心：用在手轮上，梯路还能继续；留着它下水，手指才可能握住瓷芯。

- → e02：把暖剂浇在手轮上，从干路进入泵室。
- → n08：收好暖剂，沿检修口下水去找盲鱼。

## n10 · 薄砖后面

阿榆和老苇抵住门，合力砸开薄砖。第一股水撞进来时，老苇用伤腿卡住梁，把她和瓷芯推向墙后的窄井。他没说那条路以前为什么被封；只在她爬进去前把自己的工具袋递给她。她伸手去接，听见第三声钟在头顶被敲响。

- → e03：带着工具袋穿过旧井，把闸芯送进主泵。

## e01 · 会敲门的水

水缝把阿榆推出时，她在泵室地上滚了两圈，闸芯仍绑在腕上。手指弯不过来，她用牙咬开最后一支暖剂，把瓷芯压进机座。第三声钟刚起了个头，就被主泵重新转动的轰鸣盖住。育幼层的门没有开。

回程的水已经涨到胸口。阿榆找不到来时的缝，指尖先失去感觉，接着是整个左手。管壁却响起三下，又三下。盲鱼游在前面，身后跟出一串白影，把她带到一处高出水面的旧风井。她爬上去时，左手的两根指头再也握不拢；鱼群在井下敲了一阵，便各自散进黑水。

## e02 · 完好的扶手

干梯没有断，阿榆一格格爬到了主泵。她用了最后一支暖剂，双手稳稳把瓷芯旋进机座，机械应声醒来。可是第三声钟先一步响过：育幼层那道旧门已经被水顶开，主泵只能阻止水继续上涨，不能把孩子们的床铺变干。

她顺着扶手下去时，看见一排小鞋浮在走廊。值守的人正在把孩子抱上高台，没有人受伤。阿榆握紧尚且温热的手，从图纸上找到下一段干梯，叫值守员先把孩子的鞋捞起来。水缝那边传来鱼尾拍水的轻响，随后听不见了。

## e03 · 旁路

老苇被拖出铁门时，靴子里已灌满盐水。他没道谢，抹掉脸上的白霜，抓住阿榆的袖子指向一堵看似实心的墙。墙后有检修井，他年轻时亲手封上的。两人砸开薄砖，瓷闸芯从井里送到主泵，第三声钟响完，水终于不再往上爬。

育幼层还是进了水。阿榆跟老苇赶到时，值守的人已把孩子们抱到高台，留下的被褥漂成一片。老苇坐在台阶上，腿肿得穿不回靴。他指着那些孩子，让阿榆先去报主泵的故障位置；明天修井的人要知道，救下他们的那条路为什么会被封过。

## e04 · 留在门里

直井比图纸上短。阿榆落到泵室时还有时间校准瓷闸芯，第三声钟响起前，育幼层的进水门便合上了。孩子们隔着玻璃向她招手。她把手贴上去，掌心的暖剂已经凉透。

抢修队赶到主井，花了两个时辰才拆开老苇的门。他还活着，左腿却被浸水的架梁压坏了。老苇的女儿来接他，问阿榆当时有没有听见敲门声。阿榆看着自己靴边的干盐，点了头。女儿没有再问，只把父亲的工具袋从她手里接了过去。
