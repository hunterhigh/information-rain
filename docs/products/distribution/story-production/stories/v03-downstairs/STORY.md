# 向下的梯

## n01 · 负一层

旧影院停业十八年，我第一次走到负一层的楼梯口。母亲总说父亲在那场火里抛下观众；档案员却寄来一张地下室钥匙，说那晚的值班带还在。楼上看门的老叔咳了一声，提醒我六点就锁门。

钥匙冰凉。我可以下去找值班带，也可以先回楼上问老叔为何愿意把我放进来。

- → n04：下到负一层，找值班带。
- → n05：回楼上，同老叔谈火灾当晚。

## n02 · 带盒

地下室只有一盏应急灯。值班带盒旁写着父亲的名字，盒内却空了；背后藏着一张维修单，注明他在火起前要求关闭一扇坏了的防火门。门最终没关，签收处是另一个人的字。

- → n07：带维修单上楼，请老叔辨认签名。
- → n08：继续搜空带盒，寻找谁取走了录音。

## n03 · 老叔的手

老叔给我看他的右手，三根手指伸不直。他当年负责放映，说父亲下去救人后再没上来；母亲以为父亲先逃了，是因为没人敢告诉她尸体在哪里。老叔记得值班带曾被一名调查员取走。

- → n09：请他陪我去找调查员留下的记录。
- → n10：先回家把老叔说的话告诉母亲。

## n04 · 楼梯的灰

第二级台阶踩下去时，灰尘从扶手里腾起。我小时候听母亲说父亲在这里转身逃走，便一直想象他向上跑。现在钥匙在手，负一层的门却朝里开；老叔站在楼上，没有催。

- → n02：进地下室找值班带盒。
- → n06：先问老叔钥匙为何今天才寄来。

## n05 · 六点之前

老叔把挂锁放到桌上，告诉我六点前可以随时上来。他的右手攥不拢钥匙，左手却把一张旧平面图推过来，指向地下室后排的门。那扇门在火灾报告里没有出现。

- → n03：请他从火起那刻讲起。
- → n06：先看平面图，再问谁拿走值班带。

## n06 · 后排那扇门

图上后排门通向地下室。维修单的箭头指着它，旁边留着父亲的笔迹；老叔说他至今记得门没关上的声音。我摸到纸边一处焦痕，想知道它来自那夜还是后来被人烧过。

- → n02：下楼核对维修单和带盒。
- → n03：让老叔辨认纸上的笔迹。

## n07 · 另一人的签字

老叔看见签收栏时停住，慢慢说出维修经理的名字。那人已经死了，但档案员仍能按编号找出事故报告。我把单子举到窗边，父亲在火前写的时间比广播响起早了四十分钟。

- → e01：带维修单给档案员，也给母亲看。
- → e02：先追查录音，看他火后说了什么。

## n08 · 领用条

带盒底部贴着一条卷起的纸，写着调查员姓名和市档案馆编号。老叔在楼上咳了一声，我看表还差五分钟锁门；若把这张条带出去，明天就能听见录音。

- → e02：带条去档案馆，和母亲一起听。
- → e01：先把维修单交给老叔辨认签字。

## n09 · 馆门前

老叔陪我到档案馆门口，右手在口袋里握了很久。他承认那夜见过父亲下楼，却没敢跟去；我没叫他替我向母亲解释。馆员递来两份记录，一份有父亲名字，一份有老叔的。

- → e03：两份都看，再一起去见母亲。
- → e04：先回家同母亲说，约她来亲自读。

## n10 · 家里的旧相册

我把老叔的话带回家，母亲没有立刻打开相册。她问值班带还在不在，我说知道馆里的编号，周末可以一起去。她把旧影院的钥匙放在相册旁，等我说完，才伸手碰它。

- → e04：等她准备好，一起去馆里查证。
- → e03：今天先请老叔陪我去看两份记录。

## e01 · 签收人

老叔认出签名是当年负责维修的经理。经理已去世，维修单仍足以改写事故报告的一行责任说明。我把它交给档案员，母亲看过副本后沉默很久，说她一直以为父亲没回来是因为不要我们。

她没在那天立刻原谅谁，傍晚却请我把维修单放进父亲的旧相册。相册终于有了火灾当晚的一页。

## e02 · 被取走的声音

我在柜底摸到带盒里的领用条，调查员当年把录音送往市档案馆。门上锁前我跑出去，第二天去馆里听到父亲最后一段话：让观众沿后排门离开。他的声音很平常，像平时提醒我下楼别跑。

我把录音给母亲听。她听到一半按了暂停，说还要一点时间。我陪她坐在桌边，没替她把剩下的声音放完。

## e03 · 两份记录

老叔陪我去档案馆，调查员的记录确认父亲在地下室救出三人。老叔也承认自己当年看见父亲下去，却没再去找他。回程地铁上，我们并排坐着，谁也没说英雄两个字。

母亲听完报告问老叔能否来家里吃顿饭。他说先去买一束花，下周再来。楼梯口的门那天关上了，我知道自己以后仍能找到这条路。

## e04 · 楼上的灯

我先把老叔的话带回家。母亲听完说她早知有人去地下室，却不敢问是不是父亲。我们约好周末一起去档案馆，查值班带在哪里。

周末她走在我前面，下楼时扶了一下栏杆。档案馆还未开门，我们在台阶上等；开门的人来时，她先一步站起，把写着父亲名字的纸递了过去。
