# 借来的命令

## n01 · 错位的一刀

港口的自动吊臂每过三十秒响一次。祁桥在第四次响声里看见女人的刀，刀尖停在他喉前三寸。她耳后嵌着一枚灰色线扣，嘴里说“清除航线泄露者”，手腕却朝相反方向发抖。

祁桥能跑进检疫闸，闸门会把她留在外面；也能把手里的维修钩插入线扣下方，让命令中断几秒。她抬眼看他，眼神不像请求，更像在努力记住自己还可以做什么。

- → n02：用维修钩切断线扣，冒险留在她身边。
- → n03：退进检疫闸，先保护证据和自己的命。

## n02 · 线扣松动

线扣冒出一丝焦味。女人把刀扔到地上，第一句话是：“别碰我脑后的第二根线。”那根线连着港务局的总控，剪断会把她过去三年的记忆一起烧掉。她说自己的名字叫岑，却想不起是谁把她送到这里。

吊臂又响了，巡逻队正往码头来。祁桥有一份泄露名单，能证明总控拿船员做试验；把名单发出去会触发总控清除，岑可能再失去一次自己。

- → e01：先带岑离开总控范围，再公开名单。
- → e02：立刻公开名单，冒险切断所有人的控制。

## n03 · 闸门两侧

检疫闸合上，岑的刀撞在玻璃上，留下一道白痕。祁桥把名单接入闸内终端，看见屏幕跳出一行“清除未完成，重试”。岑在外面松开刀，改用自己的肩膀挡住后面赶来的巡逻队；线扣一下一下闪红。

终端允许祁桥远程断开她的线扣，也允许他只锁门等港警来取名单。断开会让巡逻队也收到警报，锁门则可能让岑重新被接管。

- → e03：远程断开线扣，打开闸门接她进来。
- → e04：锁住闸门，带名单等待港警。

## e01 · 潮位之外

祁桥和岑爬过废弃潮位标，线扣的红灯终于不再闪。她坐在堤上，一件件说起自己记得的事：港口早餐店，弟弟的鞋码，三年前雨天买过的玻璃杯。祁桥只听，没有替她把空白填满。

名单送到外海记者手里时，港务局已找不到岑。她决定先去见弟弟，再想自己是否愿意作证。祁桥把维修钩还给她；她笑了一下，说以后最好别用它碰别人的脑袋。

## e02 · 全港警报

名单一发出，总控的隐藏线扣接连熄灭。码头上有人倒地，也有人突然停住手里的工作，茫然看着自己的双手。岑抓住祁桥的衣袖，问他是不是自己的弟弟。祁桥说不是，她便慢慢松开了。

港务局的试验当天曝光，急救队忙了整夜。祁桥站在病房外，知道证据若再晚交，明天还有人会执行命令；也知道岑可能一辈子都得重新认识那家早餐店。

## e03 · 闸门开了

线扣断电，岑在门外跪下，刀滑进排水沟。祁桥打开闸门，她第一步不是进来，而是转身把巡逻队的无线器踢进海里。她记得自己刚才差点杀人，也记得控制台的地址。

两人带着名单去港警处，岑坚持在证词上签自己的名字。警官问她受谁指使，她摸了摸耳后的烧痕：“这也是我来这里要查的。”

## e04 · 完整的证据

港警从内侧带走名单，闸门外的岑已被巡逻队扶起来。她的肩还在抖，眼神却重新变得平直。祁桥说她刚才试图帮自己，警官在记录上加了一句“需核查控制装置”，没有立刻拦下巡逻队。

名单保住了，祁桥也活着。三日后港务局被调查，他去问岑的下落，只得到一个调岗编号。他把那道玻璃白痕的照片附在证词后面；名单上的人有姓名，她也应该有。
