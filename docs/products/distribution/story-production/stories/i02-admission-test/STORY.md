# 准入测试

## n01 · 第三层梯

风在塔身空洞里吹出哨声。陈醒沿着训练梯爬到第三层，腰间的安全扣每抬一步便撞一下铁管。楼下的照明站缺人，拿到今晚的培训章，他明天就能去修母亲那条街的路灯。

教官让他停下，问：“你在家里最后一次承认自己胆小是什么时候？”陈醒以为听错了。教官指着梯侧一段断裂的扶手：越过去前必须回答，训练站的规矩是先让人说出弱点，再让人学会求援。

- → n04：说出上个月在事故现场退后的事。
- → n05：说“我来学安全操作，不来交家庭账”，要求继续训练。

## n02 · 退后一步

陈醒说完，教官没有笑，只让他复述当时离地面有多高、手边有没有第二个固定点。陈醒忽然发现，自己记得每一根钢索，却不记得曾向谁求助。教官把一枚求援铃挂到他扣带上：“说出害怕还不够，今天要用它。”

风把对面平台的活动门吹开，门扣住了同组女孩的护绳。她在门外喊，自己还能撑住。陈醒伸手就能碰到那段断扶手。

- → n07：拉响求援铃，等地面同伴固定第二根绳。
- → n08：不想再被看作退缩，独自跨过断扶手。

## n03 · 不是问卷

教官把训练板夹在腋下：“你可以不回答。那就按器材规程过梯，今晚的章只证明你会操作，不证明你会叫人帮忙。”陈醒接过规程，发现断扶手旁另有一个旧检修孔，能从塔里绕到对面，却要先卸下自己的主扣，再装在内侧锚点。

女孩的护绳被活动门卡住了。她说不用管，脚下却已经踩空半格。陈醒一手抓住检修孔边，一手摸到了腰间的求援铃。

- → n09：按规程卸扣改走内井，同时让地面同伴盯紧她的绳。
- → n10：先拉铃，不以考试速度换她的风险。

## n04 · 事故现场的高度

陈醒说那次退后不是因为看不见伤者，而是因为脚下的梯子突然松了一格。他记得自己抓住横杆后装作检查工具，没向任何人喊。教官没有问他为什么胆小，只让他指出现在脚下哪一根铁管也在松动。

- → n02：把当时没说出的求援动作在这里练一遍。
- → n06：先查断扶手和固定点，再决定是否继续跨梯。

## n05 · 不回答的权利

陈醒说不愿把家庭里的话交给训练站。教官收起记录板，照规程重新问器材状况。陈醒松了口气，却在检查安全扣时发现主绳磨出一圈白丝；规程不会替他喊人，他仍得自己决定要不要说出问题。

- → n03：按器材规程继续训练，注意检修孔的路线。
- → n06：把磨损的主绳指出来，请地面同伴复核。

## n06 · 第二个固定点

地面同伴用手电照向塔里，光停在一枚旧锚点上。它还承重，却有锈粉从螺母边缘落下。陈醒想到母亲那条街的路灯，明晚能否去修，现在系在一个没有人敢保证的金属圈上。

- → n02：向教官说明害怕，也当场试用求援铃。
- → n03：不谈私人经历，逐项检查并改走内井。

## n07 · 铃绳拉直

陈醒握住铃绳，先向女孩喊“别再踩门边”。她听见了，脚从活动门上移开半寸。地面同伴还没把备用绳拉紧，教官看着他手中的铃，等他决定是现在求援，还是赌自己先跨过去。

- → e01：拉铃，让第二根绳先固定她。
- → e02：放开铃绳，独自跨过断扶手。

## n08 · 一步的距离

断扶手离他只有半臂长。陈醒先把手伸出去，铁管轻轻动了一下；女孩说自己还能撑，他听见她的声音比上一句高。他若退回去拉铃，成绩可能慢一格；继续跨，风险落在他们两个人身上。

- → e02：抓住扶手跨过去，试着独自救她。
- → e01：收回手，先叫地面同伴拉紧备用绳。

## n09 · 内井的锚点

陈醒在检修孔边停住，先让地面同伴报出女孩护绳的张力。他把主扣卸下又锁到内侧锚点，自己重复听见一声清脆的咔哒。门外的女孩骂他动作太慢，他却看见锚点旁有一条新划痕。

- → e03：复查锁扣，从内井去拉住活动门。
- → e01：暂时停下内井路线，先拉铃让同伴接应。

## n10 · 听得见的求援

陈醒拉住铃绳，铃没立刻响，原来被扣带压在身后。他把它拽出来，朝下方同伴喊出女孩所在的平台编号。风把前半句话吹散，第二遍有人答应了；女孩的护绳仍卡着，他没有把回应当作已经获救。

- → e01：继续求援，等备用绳确实收紧。

## e01 · 铃声

铃声从塔里传到地面，同伴拉紧备用绳。女孩被带回平台，谁都没有掉下去。训练章直到半夜才盖好，陈醒的成绩栏写着“需再次练习跨梯”。教官把板递给他，没有改那行字。

第二天上工，母亲那条街的灯还是坏着；他先陪女孩去检查护绳，再同她约好下个夜班一起修。街道要多黑一晚，但没有人需要在黑里等一场坠落。

## e02 · 断点

陈醒跨过去了，也抓住女孩的护绳。断扶手从固定孔里脱开，划破他的前臂；两人被备用网兜住。教官为他们解绳时一句话也没说，把那枚没响过的铃放在陈醒染血的手心。

培训章没有发。维修站把断扶手封存调查，明天的路灯由别组去修。陈醒回家时绕过那条街，看见母亲站在窗里，借对面楼的一点光穿针。

## e03 · 检修孔

内井比图纸窄。陈醒把主扣重新锁好，听见女孩在外面骂他动作慢。他从内侧拉住活动门，地面同伴收紧绳，女孩的脚终于回到平台。教官检查扣锁，手指在陈醒用力过猛磨白的金属上停了一下。

章盖在规程栏，求援栏却空着。陈醒问能否补考，教官说随时。他把章带去照明站；那晚修第一盏路灯时，他先在塔下喊了一声：“谁帮我看绳？”
