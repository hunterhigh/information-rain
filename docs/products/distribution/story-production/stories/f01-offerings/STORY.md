# 林中偿物

## n01 · 红根

你在退潮时走进红树林，寻找能补堤的红根。堤外十几户人已把家具抬上桌。第一锹刚落，树根里传出敲击声，像有人从木头内部问你要带走多少。你背包里有一袋从村里带来的种子，腰上挂着祖父留下的铜锤。

潮水下次涨来前，你只能挖走这一段根。你可以先把种子种回空地，或先把铜锤留在树下，换取一条更稳的挖掘路。

- → n04：种下种子，再挖红根。
- → n05：把铜锤留给树，沿敲击声找根。

## n02 · 泥里的新点

种子入泥后，几只小蟹从根穴爬出来。你找到一段老根，足够补堤，却连着两棵能挡浪的幼树。只挖一半，堤可能仍会漏；全挖，林缘下一次风暴会空一块。

- → n07：挖半段根，回村补最薄的堤口。
- → n08：挖整段根，同时标下幼树位置。

## n03 · 锤声

铜锤挂在树枝上，一下一下被风敲响。声音把你引到落潮后露出的枯根，不必砍活树；枯根被盐浸多年，外皮一碰就裂。你可以就地修削，再背回村；也能回头砍一段活根，确保堤能撑住今晚。

- → n09：用枯根，先在林里削掉腐层。
- → n10：砍活根，明天带人来补种。

## n04 · 种子的深度

第一把种子浮在泥面上，潮水一来就会漂走。你用鞋跟压出小坑，挨个埋进去。村里带种子的人曾说这些苗要三年才挡得住浪；今夜的堤却只剩几个时辰。远处屋顶有人挥灯，催你回去。

- → n02：留下记号，继续找能立刻补堤的老根。
- → n06：先探一圈林缘，找不伤幼树的根段。

## n05 · 铜锤落枝

铜锤离手后，敲击声忽然变得更清楚。你循声走了十步，发现一截枯根横在活根上方，像一道塌下的桥。枯根能取，抬走时却会碰掉活树的新芽；你把背包放下，量了量两边的空隙。

- → n03：先试枯根的硬度，再决定怎样带走。
- → n06：沿林缘找另一处落潮后露出的根。

## n06 · 水线上方

林缘泥地上有两种印：小蟹留下的新孔，和上次修堤人拖根留下的深沟。你在沟尾找到一段可取的旧根，长度差一点；把两截接起来能撑过今晚，却得有人守到天亮。铜锤从远处传来一声，潮水已开始转向。

- → n02：回到幼树旁，用老根补足缺口。
- → n03：去取枯根，今晚先做可更换的接桩。

## n07 · 半段的重量

根在锹下断开，断面比你估的短。回村路上你几次停下，把它横在肩上量堤口的宽度；差的那一掌要靠沙袋。第一户人家的灯还亮着，屋主已经把装盐的麻袋倒空，等你说该放在哪里。

- → e01：先堵最薄处，叫村人备沙袋守夜。
- → e02：回林里多挖半段，把整处堤口一次补严。

## n08 · 被拔起的幼树

整段老根松动时，旁边一棵幼树也被牵得歪了。你把它扶正，用锹柄在泥里刻下位置。堤能在今夜合拢，林缘却留下一个没有根握住的空洞；背包里的种子还有半袋，回村前你得决定是否把它埋下。

- → e02：记下空洞，先带足够的根回去补堤。
- → e01：截回半段，把余下的根留给幼树和泥地。

## n09 · 皮下的硬木

腐皮一层层削去，里面的木质还硬。短的是长度，不是强度。你把枯根在两棵活树之间转了一个角度，找出不会碰掉新芽的搬运方向；村里有铜箍，能把差的那截接到堤桩上。

- → e03：带回削好的枯根，用铜箍补缺。
- → e04：担心长度不够，改取旁边的活根。

## n10 · 第二天的承诺

活根被锯断时，树冠抖落一阵盐叶。你把砍口盖上湿泥，知道这挡不了下一场潮。天边已有村里人的火把，走在最前的正是明早愿意来补种的人；你要把这处空地指给他们看，不能只说“以后再来”。

- → e04：带走活根，同时把补种位置交代清楚。
- → e03：放下锯子，改用已削好的枯根。

## e01 · 半段

你带回半段根，堤口堵住了，夜里仍有一线海水渗进第一户厨房。村人搬来沙袋守到天亮。你第二天带他们去看林缘新种的地方，教他们辨认该留的幼树。

海水退后，厨房地上留下浅白盐圈。屋主没擦掉，等下次修堤时拿它量水位。

## e02 · 标记

整段根补住堤，村里人睡了一夜。第二次风暴来时，缺了幼树的林缘被浪啃去一片。你带着先前刻在木桩上的位置回去，找来人补种，直到新苗长稳前还要守那段堤。

祖父的铜锤仍在腰间，每次钉木桩都会敲出同一声。你知道那片空地是从哪一锹开始的。

## e03 · 枯木

你在树下削到手指发麻，背回的枯根短了一截。村人用铜箍把它接到堤桩上，今晚挡住了水，明年还得换新的。第二天你回林里取铜锤，发现树枝已长出一圈新皮，把锤柄箍住了。

你没有硬扯。堤上后来改用一把普通铁锤；红树林里每到风起，还会传来那一下空空的铜声。

## e04 · 明天的树

活根结实，堤在夜里没漏。你第二天真的带人回林里补种，却发现砍口附近的土已被潮水冲走，种子漂不住。大家搬来竹篱，把泥一点点拦回去。

铜锤还挂在那棵树上。你终于取下它，钉好最后一片竹篱，再把锤子交给下一班守堤的人。
