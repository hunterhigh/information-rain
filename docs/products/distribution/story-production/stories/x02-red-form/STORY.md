# 红色表格

## n01 · 其他类

港口夜班化验员甘宁测出三号仓上方有刺激性气体，仪器却无法判定来源。报警系统只有“火灾”“泄漏”“其他”三栏；选“其他”会排到第二天，选“泄漏”则立即全港停工。仓里还有十八名装卸工。

甘宁看见一名工人从仓门出来，不断揉眼。她可以先按“泄漏”拉警报，或按“其他”并直接打电话给三号仓撤人。

- → n04：按泄漏警报，全港停工。
- → n05：按其他类，直接通知三号仓撤人。

## n02 · 全港的灯

警报亮起，全港吊机同时停下。主管赶来责备她证据不足，要求改回“其他”。甘宁手里有两份样本：一份来自仓顶，一份来自工人衣袖；后者已经送去复检。她可以在公告里写清尚未确认的来源，也可以等复检后再解释。

- → n07：马上公布采样位置和不确定处。
- → n08：维持停工，等复检后再公布细节。

## n03 · 电话占线

三号仓班长终于接通，说已让人到门外集合，但系统仍显示“其他”，隔壁四号仓继续作业。风正朝四号仓吹。甘宁可以向主管要求手动扩大停工，留下自己越权的签名；也可以去四号仓当面劝工人撤出。

- → n09：签越权单，手动停四号仓。
- → n10：跑去四号仓，逐班请人离开。

## n04 · 红灯之前

甘宁的手指停在“泄漏”键上，屏幕要求二次确认。十八名工人仍在三号仓里，值班表上四号仓又有一队刚换班；她把揉眼的工人衣袖样本放到屏旁，按下确认。

- → n02：拉响全港警报，等待复检。
- → n06：先打电话让三号仓点人数，再按下警报。

## n05 · 其他类

系统给“其他”排到次日，甘宁立刻拿起电话，拨了三次才接到班长。电话里机器声太响，她不得不逐字说清“先出门、再点人”；窗外风向标正朝四号仓转。

- → n03：继续电话撤人，准备扩大停工。
- → n06：先核对风向和另一份样本。

## n06 · 风向纸

她把两张采样纸压在桌上，仓顶那张变了色，工人衣袖那张还在等待复检。风向记录告诉她气味会在几分钟内到四号仓；主管办公室的灯亮着，报警屏却只能选三个词。

- → n02：用“泄漏”拉停全港，随后说明来源未明。
- → n03：按“其他”并直接逐仓通知。

## n07 · 公告栏

全港灯停了，司机聚在闸口问发生了什么。甘宁写下“来源未明”，又写下三号仓样本位置；主管说这四个字会引起恐慌，催她等衣袖复检。她看见人们已经开始自己编原因。

- → e01：公布采样位置、症状和暂时行动。
- → e02：维持停工，等复检后统一解释。

## n08 · 等待的两小时

复检室电话还没响，码头外已排起长车。甘宁想至少告诉司机从哪扇门绕开，主管坚持等结果；一个工人拿来同事眼睛发红的照片，问能否先交给医务室。

- → e02：等复检，事后补上临时通报格式。
- → e01：现在公开已知位置和未确认的原因。

## n09 · 签名栏

手动停四号仓需要写越权理由。甘宁写到“风向”时，闻到窗缝里已经有一点刺激气味；主管站在她身后看了一眼，没有帮她签，也没有夺笔。

- → e03：签单停机，让调查来核对风向记录。
- → e04：先去四号仓当面叫人停机。

## n10 · 仓门之间

甘宁跑到四号仓，班长指着系统里的“其他”，说没人授权停机。她把采样纸递过去，班长才闻到那股味；一名工人揉眼，另一名仍在起重机上。

- → e04：逐班撤人，记下这几分钟的代价。
- → e03：回值班室签单，立即手动拉停四号仓。

## e01 · 两份样本

公告写着气体来源未明、三号仓样本异常、所有人先离开。有人因“未明”骂她吓人，也有人按采样地图绕开下风口。复检确定是夜里清洗剂误混，处理队封了罐，天亮解除停工。

主管让她补填红色报警表，她在“其他说明”一栏写进工人衣袖的样本编号，旁边加上真正看见的症状。

## e02 · 晚来的解释

复检两小时后确认清洗剂误混，仓里的人早撤了，全港却一直不知道为何停工。码头外挤满司机，传闻从爆炸到投毒都有。甘宁公布完整报告时，吊机重新启动，司机们还在问上一条传闻是真是假。

下次夜班，她在报警屏旁贴了一张临时通报格式：原因可未明，位置和行动必须先说。

## e03 · 一笔越权

四号仓停工后，风把气味带进了空堆场，没有人吸到第二轮。复检确定清洗剂误混，主管签下解除令，也在甘宁的越权单上写了责任调查。她接受询问，带去风向记录和两份样本。

调查没有处分她，系统却仍只有三栏。她和班长提出新增“原因待查、先撤相邻区域”，工人们把这行字贴在休息室，等系统真正更新。

## e04 · 每一道门

甘宁跑到四号仓，班长不肯停机，说系统没有警报。她把湿了的采样纸递给他闻，两人争执的几分钟里，一名工人眼睛刺痛。班长终于拉下闸，送那人去医务室。

报告出来后，甘宁在记录里写下自己没有扩大警报的决定，也写下受伤工人的检查结果。下次再有“其他”，她会先让系统把风吹向哪里标出来。
