# 重排之夜

## n01 · 第一声卡

我和前妻在排练室录一段旧戏，片酬够还这月房租。戏里男人请求女人别走，台词写了三页。我们在第三句卡住：她说“钥匙已经还你”，我却抢在她前面说了下一句。录音师按停，红灯灭了。

我想重来，把那句请求讲得像不在请求。她把剧本折到这一页，指着台词旁自己画的一个小点：“先听完。”

- → n05：请求重录，按剧本完整演一遍。
- → n06：放下剧本，问她那个点是什么意思。

## n02 · 第二次

我们重录。她说完“钥匙已经还你”，我这次沉默了三秒，录音师正要比手势，她忽然念出剧本里没有的一句：“你连沉默也练过。”红灯还亮，我以为她即兴。她却走向控制台，拿出一盒标着去年日期的录音带。

- → n07：请她把去年那段录音放出来。
- → n08：拒绝听旧带，要求按合同录完今天的戏。

## n03 · 页边的小点

她说小点是去年我们分开那天，我每次打断她的位置。录音师抬头，说这段戏原本由她写，根据那次谈话改的。我终于看见台本封面上她的署名，自己刚才一直折着它。

- → n09：请她说明她愿意留下怎样的版本。
- → n10：停止录音，离开排练室。

## n04 · 红灯未灭

去年录音里，我说了六次“我们重来”。今天她说这戏可以录，但要把男人最后一句请求删掉，留下女人开门的声音。录音师等我们签改稿单。我的房租仍在下周到期，她也不会替我垫。

- → e03：同意删句，完成新版本。
- → e04：保留原稿，接受她退出录制。

## n05 · 回到第一句

录音师重新亮起红灯，我照着剧本从第一句读起。她的声音在“钥匙”两字上停了一下，我这回没抢过去；空出的三秒比台词还长。她把去年录音带拿了出来。

- → n02：听完这一遍，问她录音带的来历。
- → n06：先问她页边小点为何标在这里。

## n06 · 被折住的署名

她把剧本封面翻回来，自己的名字正写在我手指压过的地方。我松开纸，录音师也关了监听；排练室突然能听见走廊的脚步声。她说那个小点不是舞台提示。

- → n03：请她把那天的停顿讲完。
- → n02：先按剧本重录，再听去年那段录音。

## n07 · 旧带的六次

录音里我说了六次“我们重来”。她按停在第六次之后，问今天的最后一句能否删去；录音师把改稿单放到我们中间。片酬照付，我却再不能用原句把门叫住。

- → n04：讨论删句后的版本与署名。
- → n08：把旧带合上，仍按原合同录完。

## n08 · 合同角落

我把合同翻到录制条款，那里写明改稿须双方签字。她没有争，只把旧带收回盒里，开始做下一遍准备；我的房租日期在手机上亮起，像替我催她答应。

- → e01：按合同录完原稿，之后不再追问她的评价。
- → n04：放下合同，听她提出的改稿条件。

## n09 · 门的声音

她说可以留下男人的呼吸，却要删掉最后那句请求。录音师打开排练室的门试声音，铰链吱得难听，她却说别修。那一声像去年走出去时我始终没听见的东西。

- → n04：签改稿单，商量如何录四秒街声。
- → n10：暂停录制，让她单独决定是否继续。

## n10 · 停录键

我按下停录，红灯暗了。她把剧本从桌上拿走，说明天若找别的演员可以照常录；录音师没有挽留我，只记下还未完成的页数。门外的街声从缝里进来，刚好四秒。

- → e02：离开排练室，接受没有片酬的结果。
- → n04：回来商量删句，完成今天的录制。

## e01 · 合同

我们按合同录完三页，最后一句我演得很轻。她拿到片酬，没在散场后留一秒。播出那天我听见自己的停顿恰到好处，像一段抛光的旧伤口。

房租付清了。我把那盒去年录音带留在她的储物柜，不再写信要求她告诉我演得对不对。

## e02 · 门外

我走出排练室，片酬没拿到。她和录音师后来请别的演员重录，我在网上听见成片，男人那句请求被删了，门打开后有四秒街声。

我给她发了一条消息，说明欠下的道具费用会还。她回了收款账号，没有回别的。我第一次让一段对话停在对方给出的地方。

## e03 · 四秒街声

我们签了改稿单。她录开门声时用的是排练室那扇重门，铰链吱了一下，不够漂亮，录音师留了。片酬仍足以付房租，我的最后一句台词则只剩呼吸。

播出后她发来成片链接，没有附评价。我听完那四秒街声，听见远处卖花人的吆喝。第二遍播放时，我把耳机摘下来，窗外也正有人在楼下叫卖。

## e04 · 换人

她退出录制，制片人找来另一位演员，保留原稿。新演员按台词哭得很好，我的房租也付上了。首播后她在作品署名处要求标明自己的原案，制片人照办。

我没有向她解释自己的选择。下一部戏开录时，我翻到封面先看作者名字，手指停在第一页，没有急着翻到自己的台词。
