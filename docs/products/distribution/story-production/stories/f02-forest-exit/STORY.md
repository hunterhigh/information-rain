# 林外的路

## n01 · 回声

林薇第三次经过同一棵被雷劈开的杉树。她来找失踪的测绘员，却在树下看见对方留下的水壶和纸条：“我在这里修路，不必找我。”林里回声总比脚步迟半拍，守林人站在远处，手里有一枚能指向出口的铃。

守林人说，铃要换一年的劳动。林薇没答应。她可以先沿纸条提到的旧路找人，也可以到杉树旁休息，观察回声如何改变。

- → n04：沿旧路寻找测绘员。
- → n05：留在杉树旁，听一整轮回声。

## n02 · 新木桩

旧路尽头有新钉的木桩，测绘员正给迷路的孩子标方向。他说自己会在林里待一个月，等学校来接替，不需要被“救走”。孩子却说母亲在林外等，林薇必须决定是继续劝他离开，还是先把孩子送出去。

- → n07：尊重他的决定，带孩子走木桩路。
- → n08：请他一起送孩子，沿途再谈去留。

## n03 · 迟半拍

林薇坐到天色变薄，发现回声并非重复脚步：朝东走，回声来自身后；朝西走，回声落在前方。守林人再次举铃，她已能分辨一条可能的出口，但纸条主人还在林内。

- → n09：按回声自己出林，把纸条交给寻找的人。
- → n10：在杉树旁立标，留下帮下一位迷路者。

## n04 · 旧路的缺口

旧路在一处塌陷前断了。林薇看见新泥上的两组脚印：大人的步子深，孩子的浅，朝另一侧绕去。纸条上的“不必找我”被雨水洇开，她把它折好，没再把测绘员想成等人拖出的伤员。

- → n02：沿脚印绕过塌处，先确认他和孩子在哪里。
- → n06：回到杉树，试着用回声判断绕路方向。

## n05 · 水壶的刻痕

水壶底部刻着测绘员的姓名和一个日期，是三周前补划的。林薇把它放回原处，蹲在杉树旁听自己的脚步：一声来自脚下，一声像从更远的路口折回。守林人没有摇铃，只抬头看了她一眼。

- → n03：等下一轮回声，摸清出口怎样偏移。
- → n06：沿水壶刻痕所指的旧路，找其他路标。

## n06 · 两种方向

林薇用树枝在泥上画出听到的两条声路。旧路向北，回声却把人引向西边的一处低地；低地里有新钉木桩的铁屑。她若继续找人，天黑前只能走其中一条，不能把守林人的铃当作答案。

- → n02：跟着铁屑找测绘员留下的新木桩。
- → n03：先弄懂回声，给自己留一条出林路。

## n07 · 第十八根

孩子一路数木桩，到第十八根忽然停下，说第十九根昨天还在前面。林薇弯腰，发现木桩被鹿撞倒，尖端朝着另一条岔路。她将它扶正，孩子已听见母亲叫自己的名字，但还分不清来自哪边。

- → e01：按测绘员留下的路标送孩子出林。
- → e02：回去请测绘员同行，让他亲自确认岔路。

## n08 · 一起走的三个人

测绘员把工具袋背上，孩子走在两人之间。他反复说只送到出口，脚却在看见林外灯光时慢了下来。林薇没有催他解释一个月的约定；她先问孩子红围巾是不是母亲的，孩子点头，拔腿往前跑。

- → e02：陪他把孩子交给母亲，再约定接替日期。
- → e01：让他回去补最后的木桩，自己带孩子出林。

## n09 · 出口前的回声

回声先从左边撞回，林薇照记下的规律向右走，终于看见林外的天。纸条还在口袋里，水壶却留在杉树旁。她能把自己知道的方向画给寻找的人；她不知道的是测绘员此刻是否仍在那条旧路上。

- → e03：出林报平安，并如实标明自己没有找到他。
- → e04：折回杉树立标，再沿新路寻找他。

## n10 · 第一根木桩之前

林薇挑了一截能看见年轮的倒木，把箭头刻在不会被雨冲走的一面。守林人看着她，终于开口说这条路每年都被人误画成直线。她把箭头转了半圈，留出通向杉树的弯道；远处传来三下敲木声。

- → e04：沿弯道继续立标，等测绘员循桩而来。
- → e03：把方向记清，先出林把消息交给寻找队。

## e01 · 门外

孩子一路数木桩，到第十九根时看见母亲的红围巾。林薇把水壶还给测绘员，告诉他说外面有人会来接替。测绘员把最后一根木桩递给她，请她插在出口处，免得孩子下一次走错。

母亲抱起孩子，问测绘员还好吗。林薇说他在修路，并把接替日期写给她看；她没有替他说“永远留下”。

## e02 · 三个人

测绘员听见孩子要找母亲，收起工具同行。他们出林时已晚，母亲在路口举灯。测绘员看见灯，突然说自己并不记得上次看见林外的夜是什么样。

他仍决定明天回去把路标补完，约定一个月后出来。林薇没有把这个约定当胜利，只在日历上圈住日期，到时带新的木桩去接他。

## e03 · 纸条

林薇跟着回声走出林，没找到测绘员。寻找的人读完纸条，有人松口气，有人要再进林里亲眼确认。她把自己看见的水壶位置画在地图上，也写下没看见的人。

次日学校组织新的寻找队。林薇跟去，不再为出林的办法付一年的劳动；她带上昨夜画的箭头，免得别人只靠她的记忆。

## e04 · 第一根桩

林薇从背包取出铅笔，在杉树旁立下第一根木桩。守林人没给她铃，只指了指林里缺口的方向。三天后，测绘员循着新桩来找她，两人发现彼此都以为对方失踪。

他们合力修出一条路，林薇在第五天出林报平安。她会再回来，先同外面的人说清日期，杉树旁也留下了可读的路标。
