# 林外的路

## n01 · 回声

林薇第三次经过同一棵被雷劈开的杉树。她来找失踪的测绘员，却在树下看见对方留下的水壶和纸条：“我在这里修路，不必找我。”林里回声总比脚步迟半拍，守林人站在远处，手里有一枚能指向出口的铃。

守林人说，铃要换一年的劳动。林薇没答应。她可以先沿纸条提到的旧路找人，也可以到杉树旁休息，观察回声如何改变。

- → n02：沿旧路寻找测绘员。
- → n03：留在杉树旁，听一整轮回声。

## n02 · 新木桩

旧路尽头有新钉的木桩，测绘员正给迷路的孩子标方向。他说自己会在林里待一个月，等学校来接替，不需要被“救走”。孩子却说母亲在林外等，林薇必须决定是继续劝他离开，还是先把孩子送出去。

- → e01：尊重他的决定，带孩子走木桩路。
- → e02：请他一起送孩子，沿途再谈去留。

## n03 · 迟半拍

林薇坐到天色变薄，发现回声并非重复脚步：朝东走，回声来自身后；朝西走，回声落在前方。守林人再次举铃，她已能分辨一条可能的出口，但纸条主人还在林内。

- → e03：按回声自己出林，把纸条交给寻找的人。
- → e04：在杉树旁立标，留下帮下一位迷路者。

## e01 · 门外

孩子一路数木桩，到第十九根时看见母亲的红围巾。林薇把水壶还给测绘员，告诉他说外面有人会来接替。测绘员把最后一根木桩递给她，请她插在出口处，免得孩子下一次走错。

母亲抱起孩子，问测绘员还好吗。林薇说他在修路，并把接替日期写给她看；她没有替他说“永远留下”。

## e02 · 三个人

测绘员听见孩子要找母亲，收起工具同行。他们出林时已晚，母亲在路口举灯。测绘员看见灯，突然说自己并不记得上次看见林外的夜是什么样。

他仍决定明天回去把路标补完，约定一个月后出来。林薇没有把这个约定当胜利，只在日历上圈住日期，到时带新的木桩去接他。

## e03 · 纸条

林薇跟着回声走出林，没找到测绘员。寻找的人读完纸条，有人松口气，有人要再进林里亲眼确认。她把自己看见的水壶位置画在地图上，也写下没看见的人。

次日学校组织新的寻找队。林薇跟去，不再为出林的办法付一年的劳动；她带上昨夜画的箭头，免得别人只靠她的记忆。

## e04 · 第一根桩

林薇从背包取出铅笔，在杉树旁立下第一根木桩。守林人没给她铃，只指了指林里缺口的方向。三天后，测绘员循着新桩来找她，两人发现彼此都以为对方失踪。

他们合力修出一条路，林薇在第五天出林报平安。她会再回来，先同外面的人说清日期，杉树旁也留下了可读的路标。
