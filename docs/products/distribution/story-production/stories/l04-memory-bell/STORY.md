# 归还感受的钟

## n01 · 调谐室

柳霁在深海站听见钟响，手里的压力表没有跳。钟声原本是提醒值守员有人伤亡；十年前站方把她的恐惧和悲伤调低，让她能在灾后继续下潜。现在她连高兴也只能从记录上认出来：呼吸快了两次，手掌出汗，应该是高兴。

闻岚找到旧调谐器，能把被截断的记忆信号接回去。站长却发来命令：今晚必须给柳霁再做一次清除，否则她的异常反应会影响外墙维修。柳霁看见自己在过去十年签过的同意书，最上面那张字迹歪得像哭过。

- → n04：让闻岚接回信号，亲自看那些被削去的记忆。
- → n05：先保留现在的自己，去问站长当年的同意书怎么来的。

## n02 · 一秒钟的重量

信号刚接上，柳霁便想起第一次下潜时搭档的声音。她在调谐椅上弯下腰，胃里的东西涌到喉口；仪表仍在报外墙裂缝，今晚维修不能等。闻岚伸手要扶她，她把那只手按回去：“给我十分钟，别替我决定。”

站方说可以再清除一次，让她立刻恢复熟练；也允许她停职，由别人接替外墙。接班员刚到深海站，曾在浅层出过事故。柳霁听见钟第二次响，把交接表转向自己，先画出了裂缝旁那枚肉眼看不见的旧铆钉。

- → n07：保留记忆，交出今晚的潜水资格并教接班员。
- → n08：为完成维修，同意暂时再次压低情绪。

## n03 · 签名是谁写的

站长没有否认第一张同意书出于急救，却说后来每张都是柳霁自己签的。柳霁翻到第三年，看见纸边有她画的一只小鲸；那年她曾养过一条病鱼，鱼死后她要求把悲伤也一并关掉。签名是真的，决定却是在一个越来越听不见自己的状态里作出的。

外墙的渗漏点亮了走廊红灯。站长递给她新的清除表，闻岚把旧调谐器放在旁边。两件东西都没有伸出手来替她签字。

- → n09：公开全部同意书，要求暂停站内的永久调谐制度。
- → n10：先接回信号，再亲自安排外墙维修交接。

## n04 · 调谐器的旧刻度

闻岚把旧调谐器摆上桌，指给柳霁看十年前刻下的深度线。那一格比现在的安全范围还深；她记不起是谁画的，却认得自己握刀时留下的毛边。接回信号可以从最轻的一档开始，她仍要决定由谁按下开关。

- → n02：自己握住开关，让闻岚只负责监看仪表。
- → n06：先查每份同意书的时间，再决定接回多少。

## n05 · 第一张纸

柳霁带着同意书去站长室，纸上的签名有一处被水洇开。站长说那晚她刚从灾后下潜回来，连自己的床号都答不上；柳霁看见纸角的折痕，是有人把表叠好塞给她的。十年后的签名又该怎样解释，站长没有主动说。

- → n03：逐张问清签名和每次调谐的原因。
- → n06：让闻岚一起核对记录，不单听站长的说法。

## n06 · 值班簿的空页

值班簿记着每次调谐后的出勤，却很少记下柳霁醒来时说过什么。第三年那页夹着一枚小鱼鳞，已经干得发白。外墙裂缝警报亮起，她把那页放进口袋，第一次想到当年也许不只有站长一个人看见她签字。

- → n02：接回信号，亲自面对记忆，再决定今晚谁下潜。
- → n03：继续查同意书，同时安排替班员到位。

## n07 · 透明板上的裂缝

柳霁画出那枚旧铆钉，接班员问如果它在水下脱落该往哪边退。她握着笔，胃里仍翻涌，却能把逃生绳的位置讲清。闻岚把交接表放在两人之间，等她亲手签下今晚不下潜。

- → e01：保留记忆，教接班员完成外墙修补。
- → e02：担心新人出事故，选择再调低情绪自己下潜。

## n08 · 针尖上方

站方把新的同意书放到调谐椅旁。柳霁在“暂时”两字下画线，要求写明何时复检、谁保管她针落前说的话。站长说先修外墙再补文件；闻岚没有替她回答，只把笔递到她手里。

- → e02：签下暂时调谐，修完外墙再面对代价。
- → e01：放下笔，改由接班员下潜，自己留在控制室。

## n09 · 公告板前

柳霁把第三年那张小鲸贴上去，值夜员停在公告板前，说自己也靠调谐撑过一场事故，不想今天就被人取走装置。她没有去撕那人的表，只请大家看每张签字前是否真有时间停工和反悔。

- → e03：公开十年记录，要求重新讨论每次签字的条件。
- → e01：先完成个人交接，把制度争论留到外墙修好后。

## n10 · 十分钟过去

信号一点点回来，柳霁想起病鱼死的那天自己把水倒进排水口，站了很久。闻岚问要不要关掉调谐器，她摇头，先看向外墙裂缝的图。十分钟还没让她习惯悲伤，却够她画出那枚旧铆钉。

- → e01：保留记忆，指挥接班员完成外墙维修。
- → e03：把同意书公开，要求制度先停下来接受核查。

## e01 · 交接表

柳霁没有下潜。她把裂缝位置画在透明板上，带接班员走了三遍手势。钟第三次响时，他从外墙发回修补完成的信号。柳霁在控制室哭得看不清指示灯，闻岚替她读数，没有替她握笔。

第二天她申请休假，在交接表上写了自己的名字，也写下回来后只接愿意做的工作。她怕深海仍会怕，明明十年里从没有怕过；可她第一次不需要根据仪表猜这是什么感觉。

## e02 · 第四张表

调谐针落下，柳霁的呼吸很快稳了。她修好外墙，站长在记录上写“反应恢复正常”。回到宿舍，她看见桌上有一张闻岚留的纸，记着她在针落下前说过“别替我决定”。柳霁读了两遍，懂得句子的意思，却想不起说话时为什么握紧了椅边。

她没有扔掉那张纸。第二天交接班前，她把纸折进新的同意书里，要求下次调谐前有人替她把它读出来。

## e03 · 公告板

柳霁把十年的同意书贴上公告板，连第三年那张小鲸也贴了。有人支持她，有人说自己靠调谐才能活过夜班，不该被她一人叫停。柳霁没有要求所有人立刻摘下装置，只要求今后每次签字前都能停工、见证、反悔。

闻岚带接班员去修外墙，直到凌晨才封住渗漏；站方暂时撤了柳霁的潜水权限。闻岚问她后不后悔，她说还不知道。走廊的钟在换班时响了一下，她第一次留在原地听完它，而没有去摸压力表。
