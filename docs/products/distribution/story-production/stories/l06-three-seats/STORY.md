# 三张座位

## n01 · 空排练厅

巡回剧团的车明早出城，黎深在空排练厅摆了三张椅子。第一张是灯光师常坐的，她昨夜问他巡演结束后要不要同住；第二张是编剧的，抽屉里还留着他写给她的信；第三张是黎深自己的。他一直没回两个人的话。

门开时，两个人一起进来。编剧把信放在桌上：“我们今天把话说完。你不用演得好，只要别让我继续猜。”灯光师站在窗边，手里还捏着明早的车票。

- → n04：坦白自己对两人都有感情，却还不能许诺。
- → n05：立刻选一个人，给出明确答复。

## n02 · 真话的温度

黎深说完，灯光师把车票压平：“谢谢你现在说。可我不去一场还要等你决定的巡演。”编剧没有走，她问是否至少能把那封信还给自己。黎深递过去时发现信纸折角被他摸得发软。

巡演负责人正在外面催最后一份演员名单。黎深可以请两人都留下，承诺以后慢慢谈；也可以尊重她们各自的决定，自己面对明天缺人的舞台。

- → n07：让她们走，亲自告诉团长需要换人。
- → n08：请她们留下，约定巡演后再给答案。

## n03 · 被叫到名字的人

黎深走向编剧，说想和她在一起。灯光师点了头，取走车票，没有等他说歉意。编剧却没有高兴：“你昨晚还说需要时间。你现在答，是因为我站在这里吗？”黎深握着她的信，答不出来。

门外的团长敲了三下。编剧说她仍愿去巡演，但不愿在车上继续当一个被仓促选中的人。黎深能收回刚才的话，也能承认自己的选择带着恐慌，再让她自己决定是否接受。

- → n09：承认仓促，不要求她立刻回应。
- → n10：坚持刚才的承诺，请她相信自己。

## n04 · 第一张椅子

黎深看着灯光师手中的车票，知道她问同住时并没有要一份台词。编剧的信还躺在桌上，折角被他摸得发软。他想说“两个人都重要”，却听见走廊里团长在清点明早上车的人数。

- → n02：把不确定说出来，不再让她们继续猜。
- → n06：先请两人分别说清各自能接受什么。

## n05 · 被握住的信

黎深拿起编剧的信，灯光师没有拦，只把车票放到自己的椅背上。这个动作比一句“随你”更清楚：他的答复一出口，明早谁会上车也可能改变。编剧等着他看完最后一行。

- → n03：告诉编剧自己想和她在一起。
- → n06：承认此刻的选择可能只是怕两人都走。

## n06 · 团长在门外

团长敲门问名单能不能定，没人回答。编剧说她可以去巡演，不等于可以等黎深的感情答复；灯光师说她也有自己的工作，不会用辞职逼谁选择。黎深把排练表翻过来，背面还空着，他得先对眼前的人说话。

- → n02：坦白自己没有准备好承诺，接受她们各自决定。
- → n03：若真想同编剧在一起，现在明确说出并承担后果。

## n07 · 替补名单

黎深去找团长，说灯光位和后两站剧本都可能要换人。他没有把原因说成两位同事突然失约。团长把铅笔递来，让他亲自写替补名单，第一场开幕前还要重新走位。

- → e01：让两人离开，自己承担换人和演出延误。
- → e02：回去请求她们为工作留下，感情答复延期。

## n08 · 车票压在桌上

黎深请两人留下，灯光师说她只会为演出留，不会为一个延期的答案留。编剧把信收进袋里，问团长何时发新的排练表。黎深听见她们已经在谈工作，自己却还想把“以后”当成一笔没有期限的借款。

- → e02：让工作先继续，承担延期带来的关系变化。
- → e01：停止请求她们留下，连夜安排替补。

## n09 · 收回那句话

黎深把信还给编剧，说刚才急着选她，是怕两个人都离开。编剧没有马上接信，问他若灯光师明天仍上车，会不会改口。他无法保证未来，却能保证不再把今晚的恐慌说成爱情的证据。

- → e03：承认仓促，让编剧自己决定是否继续靠近。
- → e04：坚持选择，请她相信今后的具体行动。

## n10 · 写在排练表上

黎深说想同编剧在一起，也愿意把巡演后的同住、排练分工逐项谈清。她没因计划详细就立刻答应；灯光师已经拿着车票离开排练厅。团长又敲门，三人的关系不能由明早的发车时间替他们定案。

- → e04：保持承诺，接受编剧提出的现实条件。
- → e03：承认自己答得太急，给她独自考虑的空间。

## e01 · 第二天的名单

团长气得把排练表摔在地上，连夜找来替补灯光师。编剧也退出了最后两站。黎深一个人上车，窗外那三张椅子还在大厅里，谁也没来搬。

第一场演出临时换灯，开场迟了九分钟。黎深在谢幕后给两人各发了一封信，只有对自己说过什么、没做到什么的事实，没有请求原谅。手机很久都没有亮；剧团仍要在下一城搭台。

## e02 · 延期的答案

团长说一夜找不齐替补，她们为了各自的工作留下，车也准时出发。巡演第四夜，灯光师把操作台交给替补，告诉黎深她不想再等；编剧坐在观众席最后一排，看见两人的争执从幕边透出来。黎深翻开巡演日历，第四站旁边仍写着他亲手记下的“以后再说”。

他在那场演出后取消同住的谈话，先把工作和私人关系的边界说清。剧团没有散，但三个座位不再挨在一起。

## e03 · 可以不接受

黎深把信放回编剧手里，说自己怕两个人都走，才急着作答。编剧说这句比刚才的话可信，却仍需要一个人安静一阵。她去巡演，只同他谈剧本和排练；灯光师已离队。

黎深在车上把三张椅子的草图夹进台本，提醒自己每个人都有自己的门。到第三站，编剧愿意一起吃饭；他们没把那顿饭当成承诺，只认真谈了下一场戏。

## e04 · 说出口的选择

编剧最终留下，条件是黎深别拿“我已经选了你”堵住以后真正的争执。灯光师下车时把备用灯位图交给团长，没留给黎深。第一站的台上灯光少了一道暖色，演员按新位置走完了戏。

黎深和编剧在后台吃冷饭，谈起同住的时间和工作分配。她不再让他用一句漂亮的“相信我”跨过这些具体问题；他也终于能把筷子放下，一项项回答。
