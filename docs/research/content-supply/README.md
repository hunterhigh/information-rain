# 自供给分发内容资料

状态：活动资料库｜适用产品：分发产品｜建立日期：2026-09-30

这里集中保存与未来自供给分发内容有关的**数据、外部作品资料和思考**。当前首批是作者公开发布的 Twine/Twee 源文件快照，供后续批量内容生产寻找结构和写法灵感。它们是参考材料，不属于正在运行的[读者内容池](../../../products/distribution/reader-web/content-pool/README.md)，也不代表已决定采用任何作品的题材或机制。

## 目录

| 位置 | 内容 |
| --- | --- |
| [data/catalog.json](data/catalog.json) | 作品级索引、固定来源版本、原始路径、文件校验值及可机械读取的节点/链接计数。 |
| [works/](works/) | 一部作品一个目录；保留作者原始源文件路径，每部作品有来源说明。 |
| [notes/](notes/) | 此资料库的范围、整理判断和后续思考。 |
| [collect_twine_sources.py](collect_twine_sources.py) | 按已选作品清单重新获取公开文件的脚本；只用 Python 标准库。 |

## 首批范围

2026-09-30 的初始快照从 48 个带 `twine` 和 `interactive-fiction` 标签的 GitHub 仓库开始。19 个仓库含相关扩展名，共 244 个可读取的源文件。按作品边界整理、剔除纯模板及工具样例后，归档 **24 个作品或作品样本、223 个源文件，约 1.67 MB**。其中部分是单篇故事，部分是一个章节、草稿或测试样本；`scope` 字段和各作品 README 已标明，不能把文件数当成独立作品数，也不能把节点数当成可玩分支数。

本批只覆盖这个明确的 GitHub 搜索样本，不代表网络上 Twine 作品总量。原始素材保持字节不变；每个文件的 SHA-256 在目录中。重新获取时使用 `python docs/research/content-supply/collect_twine_sources.py`；GitHub CLI 登录或 `GITHUB_TOKEN` 可避免匿名 API 配额不足。脚本会固定每个来源的提交版本并更新目录。

## 使用边界

- 查找作品时先读 [作品索引](data/catalog.json) 的标题、范围和来源，再进入对应的 `works/<作品>/source/`。
- 首批归档只建立可追溯素材基线；后续的结构比较、创作启发和判断写入 [notes/](notes/)，不直接改写产品定义。
- 如需将任何灵感转成信息雨作品，先创作独立内容并走分发产品自己的内容流程；外部原始文件保持在本资料区。
