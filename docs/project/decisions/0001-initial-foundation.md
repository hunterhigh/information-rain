# 0001: 先建立文档型研究仓库

## Context

产品愿景仍在形成，已有二维文字 Demo 只能代表局部实验，当前最重要的是保存清晰且可修正的认识基线。

## Decision

使用 docs-only 基础建立本地 Git 仓库，并以 README 作为当前项目入口。

## Rationale

这样既能形成长期工作位置，又不会用过早的软件架构替代产品探索。

## Alternatives

- 立即建立移动应用代码仓库
- 继续只在聊天中保存想法

## Consequences

- 当前不会产生可运行产品
- 后续确认原型方向后需要重新选择技术路线并推进项目阶段
- 重要纠正、决定和实验结果需要持续写回仓库

## Review when

当下一项工作从概念讨论转为可运行的手机交互原型时重新评估。
