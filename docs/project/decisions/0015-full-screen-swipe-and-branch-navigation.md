# 0015：整屏作品切换与左右分支导航

日期：2026-09-30｜状态：已采纳并实施

## 决定

- 作品之间采用 TikTok 式整屏纵向滑动：当前作品离开舞台，下一作品整屏进入。
- 阅读中的左、右滑动仍然用于进入当前节点实际提供的对应分支；界面保留可点击的左右箭头和分支名称，不能只靠手势猜结果。
- 手指横向移动时，当前分支按钮与方向提示同步反馈；释放并达到手势阈值后，当前阅读画面沿所选方向整屏滑出，再显示目标节点。
- 不存在的分支不可滑入；减少动态效果设置生效时，过场动画缩短。
- 作品自身定义各出口的含义；手势只表达选择方向，不替作品规定固定的故事语义。

## 原因

TikTok 的纵向整屏切换适合作品流的浏览节奏；信息雨故事内部则存在内容决定的左右分支。将作品切换与节点分支分开，避免同一个纵向手势既切作品又选故事分支。保留箭头按钮，能让不使用手势的读者看见并选择左右路径。

## 验证状态

已在读者页面实现横向跟手提示和方向性整屏离场动画；上下作品切换沿用 Swiper 全屏舞台。真机体验尚待项目所有者核验。
