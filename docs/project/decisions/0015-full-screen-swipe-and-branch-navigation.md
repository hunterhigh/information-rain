# 0015：整屏作品切换与三向分支导航

日期：2026-09-30｜状态：已采纳并实施；光流反馈于 2026-09-30 更新

## 决定

- 作品之间采用 TikTok 式整屏纵向滑动：当前作品离开舞台，下一作品整屏进入。
- 手机阅读界面不显示常驻方向箭头或拖动文字框；左、右、上分别进入当前节点对应的分支，桌面端保留可点按的方向按钮。
- 分支拖动时，整张阅读画面（标题、作者和正文也在其中）跟随手指移动；作品自身出现一道向选择边缘牵引的柔和光流。松手达到提交条件后，旧画面沿同一方向离场并接续显示目标节点；不够条件则回弹。
- 下滑用于整屏进入下一部作品，与分支的光流反馈分开表达。阅读正文时只有在正文滚动到边界后，纵向手势才用于上方分支或下一部作品，避免阅读和导航抢同一个手势。
- 不存在的分支不可滑入；减少动态效果设置生效时，过场动画缩短。
- 作品自身定义各出口的含义；手势只表达选择方向，不替作品规定固定的故事语义。

## 原因

TikTok 的纵向整屏切换适合作品流的浏览节奏；信息雨故事内部则保留内容定义的三个出口。将下滑作品切换与上滑分支区分开，并用页面内的光流表达分支方向；桌面仍可直接点选。

## 验证状态

已在读者页面实现整屏快照跟手、目标分支光流、松手后的方向性切换；手机端隐藏常驻箭头和拖动文字框；纵向作品切换协调正文滚动。浏览器自动检查通过，真机体验尚待项目所有者核验。
