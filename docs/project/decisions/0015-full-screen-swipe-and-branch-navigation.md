# 0015：整屏作品切换与左右分支导航

日期：2026-09-30｜状态：已采纳并实施

## 决定

- 作品之间采用 TikTok 式整屏纵向滑动：当前作品离开舞台，下一作品整屏进入。
- 手机阅读界面不显示常驻方向箭头；存在左、右出口时，以纯文字显示分支名称和“左滑/右滑”提示。桌面端保留可点按的方向按钮。
- 手机手指横向移动时，整张阅读画面跟随手指移动，并显示将进入的分支名称；释放并达到手势阈值后，旧画面沿所选方向整屏滑出，再显示目标节点。
- 纵向浏览作品使用整屏切换；阅读正文时只有在正文滚动到边界后，纵向手势才用于上方分支或下一部作品，避免阅读和导航抢同一个手势。
- 不存在的分支不可滑入；减少动态效果设置生效时，过场动画缩短。
- 作品自身定义各出口的含义；手势只表达选择方向，不替作品规定固定的故事语义。

## 原因

TikTok 的纵向整屏切换适合作品流的浏览节奏；信息雨故事内部则存在内容决定的左右分支。将作品切换与节点分支分开，避免同一个纵向手势既切作品又选故事分支。手机端用分支文字提示替代常驻箭头，拖动时显示确切目标；桌面仍可直接点选。

## 验证状态

已在读者页面实现整屏快照跟手、目标分支提示、松手后的方向性切换；手机端隐藏常驻箭头并保留左右分支文字；纵向作品切换协调正文滚动。真机体验尚待项目所有者核验。
