# 0002: 建立私有 GitHub 远端

## Context

初始文档型项目阶段没有包含 GitHub 远端。项目所有者于 2026-09-23 明确要求将已完成的项目内容发到 GitHub。

## Decision

在当前登录账号 `hunterhigh` 下建立私有仓库 `information-rain`，以 `main` 为默认分支，提交并推送当前项目文档、实验脚手架及其检查工具。此次上传不包含部署、公开发布或产品 Demo。

## Rationale

私有仓库可提供异地保存与可追溯协作，同时保留项目尚在愿景与实验准备阶段的非公开属性。

## Consequences

- 初始项目简报中“不建立 GitHub 远端”的边界由本决定调整；其他第一阶段边界不变。
- 后续新增协作者、改为公开仓库或部署产品，需要另行决定。
- 本地与远端 `main` 应保持一致；推送后核对提交和仓库可见性。
