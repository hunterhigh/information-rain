# 0011：分发产品作为当前唯一实施主线

日期：2026-09-29｜状态：项目所有者已确认

## 决定

长期技术愿景仍包含工具产品与分发产品两条方向；当前的实施路线图只覆盖分发产品，并以现有分发 Demo 作为持续迭代的工作基线，目标是逐步形成可上线的完整产品。

工具产品仍是长期方向，但不进入当前实施队列。恢复工具产品工作时，应建立独立的产品范围、术语和路线，不默认与分发产品共用用户、内容模型、代码或后端接口。

## 工作影响

- 不再把 round-01 的多个候选 Demo 作为当前需要组合测试的对象。
- 当前分发 Demo 是主动维护版本。先整理产品本体、路线图、工作基线与文档治理；再依路线图逐步补齐正式产品能力。
- 历史测试、撤回 Demo 和比较材料需要在索引中标明状态、用途与归档原因。动画对比页现作为设计档案保留；后续决定采用轻微落位并实施，`UT-01` 已关闭。原位叠化和柔焦叠化仅作未来迭代参考，不是待办。
- 产品验证仍是未来打磨和上线过程的一部分；本决定不要求现在开展 Demo 试玩或多个 Demo 对比。

## 边界

本决定不选定技术栈、数据库供应商、托管平台、账号方案或公开发布日期。正式服务需要使用托管的持久化数据环境；临时开发电脑不作为产品数据的唯一保存位置。
