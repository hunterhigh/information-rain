# 0006：双产品结构与媒介验证顺序

日期：2026-09-28｜状态：项目所有者已采纳的战略方向；不是产品功能规格

## 决定

1. 长期方向明确包含两个产品：**工具产品**与**分发产品**。工具产品负责创作/组织可展开的内容；文字拓扑 Agent 是其中一个主要功能。分发产品负责让人发现、进入、继续消费不同内容，不等同于工具界面。
2. **全梦**保留为技术愿景的名字。**信息雨**是产品的信息流方法，指当前位置有多个可到达的信息走向；它不是现阶段给任一产品强制确定的品牌名称。具体可达路径和回返后果继续由内容决定，见[决定 0003](0003-content-defined-trajectories.md)。
3. 验证媒介表达时保留**文字 → 插画 → 短视频**的渐进构想。这是降低生产成本、逐层验证体验的战略顺序，不意味着后一媒介必然替代前一媒介，也不禁止有证据时调整顺序。
4. 已有 Kimi 原型作为分发产品的可操作线索继续优化，但它的 30 个内容不因纳入实验就自动通过作品质量或版权评审。界面与交互优化不改写其中的作品、插画或内容分支。公开上线另过合规与产品阶段门。

## 对既有记录的影响

早期 README 把「信息雨」当作整个产品的暂定名、把工具与分发混为一个产品的表述，以本决定为准。round-01 旧 product-01 v0.1 仍是已撤回的内部机制样本，不能因为新原型存在而恢复合格状态。原实验脚手架中「第一轮文字媒介」只约束旧轮次的比较实验，不推翻这里的跨阶段媒介验证方向；插画已作为新原型封面存在，其价值仍待验证。

## 未决定
