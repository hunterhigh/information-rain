# 0004：先自动产出与评审 Demo

日期：2026-09-24｜状态：已确认

项目所有者要求：「不要考虑我的需求，按照一个既定的原则去产出就好了，这种自动demo的产出与评审才是我们需要的。」这修正了原实验脚手架中每个候选先经多轮讨论、写满篇幅门槛、由所有者批准后才可做 Demo 的顺序。

执行原则沿用[决定 0003](0003-content-defined-trajectories.md)：尽量给予内容决定路径的自由度，不由产品预先统一规定返回后未选方向是否可进入。Agent 根据研究和该原则自行选择可检验的机制，直接制作可操作 Demo，运行自动检查并进行诚实的自我评审；随后呈交所有者实际体验。所有者的真实体验仍不能由自动评审替代，也不把 Demo 的预写内容声称为在线生成或正式内容体验。

为了尽快让机制暴露问题，研究与简明机制说明足以支撑首个 Demo。长文 `DESIGN.md` 可以在有价值的方向上再写，原篇幅标准只在决定制作该文档时适用，不是 Demo 的许可条件。每次 Demo 的事实、限制、自动测试结果、主观评审和未验证之处分别记录。
