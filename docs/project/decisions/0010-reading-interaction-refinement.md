## 已确认方向

项目所有者确认分发 Demo 下一轮需要覆盖以下三项：

1. 让小、中、大三档正文文字大小真正适配阅读区域和画面，避免文字溢出或挤乱操作区。
2. 略微放大中央的 9:16 阅读舞台，保持其原有居中位置。
3. 放慢作品切换，并降低滚轮或手势轻微输入造成的意外切换。

实施值：字号为 14/16/18px 并分别调整行距；阅读文字限制在舞台内容区内，超出时在正文区域滚动，同时随字号扩展背景渐变；桌面舞台放大约 5%，保持 9:16 和原中心位置；作品切换动画由 280ms 调至 380ms，并提高滑动、滚轮和触屏切换阈值。实际体验仍待项目所有者确认，参数可在试用后微调。
