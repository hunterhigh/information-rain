# 项目阶段路线

长期愿景仍保留[工具产品与分发产品](decisions/0006-two-products-and-medium-validation.md)两条方向；当前只有分发产品进入实施路线。工具产品保持独立，不混入当前工作队列，见[决定 0011](decisions/0011-distribution-product-as-active-roadmap.md)。

分发产品从当前 Demo 逐步迭代到可上线完整产品的阶段、交付和退出依据，统一维护在[分发产品实施路线图](../products/distribution/roadmap.md)。当前工作状态以[工作基线](working-baseline.md)为准。

项目级阶段门继续适用：

## 内部试用前

- 明确试用身份与权限；隔离测试数据；提供问题记录和基本恢复路径。

## 正式上线前

- 在非生产环境验证目标版本；完成备份恢复、运行检查、费用边界与回退方案。
- 审查目标市场的内容权利与适用要求。私有试验不等于公开发布许可。

## 关键基础设施前

- 完成恢复演练、权限审查、容量降级、事故处理与责任交接。
