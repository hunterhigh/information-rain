# 项目协同文档

此目录管理跨产品共用的项目范围、工作状态、阶段和协作规则。分发产品、工具 Agent 的具体业务定义和路线图请到 [`docs/products/`](../products/README.md)。

| 文档 | 用途 |
| --- | --- |
| [项目简报](brief.md) | 保留项目建立时的范围与后续授权变更。 |
| [工作基线](working-baseline.md) | 当前有效产品主线、代码位置、活动状态和下一步。 |
| [架构起点记录](architecture.md) | 记录最初 docs-only 的历史选择，不代替当前产品架构。 |
| [项目路线图总览](roadmap.md) | 汇总跨阶段路径，分发产品的细节见产品路线图。 |
| [阶段门](stage-gates.md) | 规定内部试用、正式上线和关键基础设施的进入条件。 |
| [文档与版本协同规则](documentation-workflow.md) | 管理资料归属、状态、索引、变更日志与版本。 |
| [实验脚手架](experiment-scaffold.md) | 仅在路线图批准独立实验后采用。 |
| [决定索引](decisions/README.md) | 查找已采纳的产品和工程决定。 |
| [会议索引](meetings/README.md) | 查找项目讨论、审查和调研会议记录。 |
