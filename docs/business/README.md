# 商业策划索引

本目录记录市场选择、商业模式、供需关系、创作者激励与增长路径等判断。它们用于提出或检验商业假设；只有经项目决定和产品路线图采纳的部分才成为实施范围。

## 策略与商业假设

- [产品形态与创作者交换关系](strategy/2026-09-29-product-form-and-creator-strategy.md)：互动短故事与泛内容的边界、早期用户和作者、工具/分发关系及运营影响。当前是候选判断，不是规格。
- [Liblib 与 Lovart 的平台策略研究](strategy/2026-09-29-liblib-lovart-strategy.md)：从历史证据中推演创作工具、模型供给、分发和商业化之间的关系。

新增材料先判断它属于商业判断还是外部事实研究：有来源的证据放入 [`docs/research/`](../research/README.md)，基于证据作出的市场与商业选择放在本目录。产品专属决策仍写入相应产品文件。
