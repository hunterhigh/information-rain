# 第七次问询｜完整内容稿

作者显示名：林间来信
简介：你刚杀了一个人，开着死者的车，尸体就在后备厢。警灯亮起后，问询开始循环；只有让每个事实彼此一致，才能走出房间。
阅读时长：9分钟
标签：心理悬疑、循环、选择
起点：n1
每条路线有七个选择节点。

## 节点与连接
### n1

雨夜，警灯在挡风玻璃上来回扫。你刚杀了一个人，尸体在这辆车的后备箱里；这辆车属于死者。巡警走到车窗边，问你是否知道为什么被拦。雨刷停在半途，后视镜里却映出一个坐在后座的人影。你可以先回应警员，也可以沉默观察车窗上的倒影。

选择：
- left：平静回应，问清拦停原因 → n2
- right：暂不回答，先看清后视镜里的人影 → n3

### n2

巡警请你出示车辆资料。纸面上的姓名不是你的，警员没有提高音量，只把证件放在车窗灯下。你知道自己刚才做了什么；与此同时，路边的白线像病房地砖一样向远处延伸。可以承认车主不是你，也可以把问题推回给警员。

选择：
- left：承认车不是自己的，等待下一问 → n4
- right：追问警员凭什么怀疑你 → n5

### n3

你没有回答。警员重复问题时，后备厢传来三下轻响。现实里不可能有人从里面敲门——你确认过。倒影里的乘客抬手指向后方，警员却像没听见。你可以回应车辆归属，也可以要求警员说明拦停依据。

选择：
- left：说出车辆登记并非你的名字 → n5
- right：要求对方说明拦停依据 → n4

### n4

警员看着登记资料，问你如何得到这辆车。你脑中闪过几个彼此冲突的答案，但没有一个能改变车主已经死亡、车仍在你手里的事实。对方没有替你补完句子，只等着。你可以承认自己记不清某一段，也可以编造一个笼统说法；后者会让倒影里的乘客露出熟悉的笑。

选择：
- left：承认记忆有缺口，不补造细节 → n6
- right：给出一个笼统说法，看看能否自圆其说 → n7

### n5

警员示意你把手放在看得见的地方。后备厢的敲击又响了一次，这回警员也听见了。他没有让你靠近车辆，只呼叫同伴查看。你可以配合留在原地，也可以继续争辩，试图把注意力从车后转开。

选择：
- left：照做，等待警员处理车辆 → n6
- right：争辩拦停程序，回避后备厢的声音 → n7

### n6

警员问你最后一次见到车主是什么时候。你看见仪表盘反光里浮出两个时间：一个来自记忆，一个来自你刚才说的话。它们不能同时成立。此处没有可藏起的答案，只有你是否愿意修正前面的说法。

选择：
- left：指出自己前后说法不一致并更正 → n8
- right：坚持原说法，不再解释 → n9

### n7

警员绕车一周，停在后备厢旁。你听见金属锁扣轻响，随即闻到雨水和冷铁的气味。车窗里的乘客已经不见，后座空着。警员问车里还有没有其他人。你可以如实回答，也可以否认已经听见的事实。

选择：
- left：承认后备厢里有人，并停止编造 → n8
- right：否认，赌警员不会继续检查 → n9

### n8

第二名警员来到现场，确认后备厢里是死者。没有血腥画面，只有一只从毯边露出的手。主问询的警员问你是否认识死者。你胸口发紧；后视镜里出现的不是乘客，而是此前几名死者的脸。你可以说出你知道的身份，也可以只谈眼前这一具尸体。

选择：
- left：承认自己认识死者，也承认案件不止一宗 → n10
- right：只回答眼前问题，避开其他受害者 → n11

### n9

警员把记录本合上，问你为什么刚才给了两个不同答案。车外的雨声突然像掌声。你可以承认自己慌了，说明记忆出现断裂；也可以把矛盾归咎于疲劳，继续维持先前说法。

选择：
- left：承认慌乱，不再掩饰矛盾 → n10
- right：把矛盾推给疲劳，继续维持说法 → n11

### n10

警员请你从头说到现在。你不必补出没记得的细节；只需把已经确认的事实按发生顺序摆在桌面上：死者是谁、车属于谁、你做了什么。记录本上的空白像一扇没有把手的门。你可以继续说，也可以要求暂停并听听后备厢传来的声音。

选择：
- left：按已知事实说明，不填补记忆空白 → n12
- right：请求暂停，听清那道声音再回答 → n13

### n11

警员问你是否后悔。你想起自己把每次杀人都说成最后一次，直到这个雨夜又重复。倒影里的几张脸并没有责骂，只是等待你叫出他们的名字。你可以承认这是连环杀人，也可以把责任推给一个不存在的替身。

选择：
- left：承认这是自己反复做出的选择 → n12
- right：把罪责推给不存在的另一个人 → n13

### n12

警员放下笔。问询已经走到最后一道门：窗外不再是路边，而是一条白亮的走廊；门牌写着你的名字。你知道这不是现实中能替你免除罪责的捷径。此刻仍可选择说出完整事实、继续否认，或把暴力转向警员。

选择：
- left：完整承认责任，结束这场循环问询 → e1
- right：继续否认，让问询从头开始 → e2
- up：攻击警员，拒绝继续回答 → e3

### n13

警员问你是否愿意继续活着面对自己做过的事。后备厢里传来的敲击变成规律的三拍，像有人在替你呼吸。你可以把事实说完，也可以再次否认；还可以把伤害转向自己。画面不会展示具体方式，只会留下选择后的结果。

选择：
- left：说出事实，接受接下来的责任 → e1
- right：否认一切，被困在重复的问询里 → e2
- up：伤害自己，结束对话 → e4

### e1｜结局：走出问询室

你说出死者的名字，也承认自己杀了他；随后逐一叫出其他受害者。走廊尽头的门打开了。你走出问询室，外面不是自由的街道，而是天亮后的警局大厅：证物袋、值班警员和等候的调查人员都在。你离开了循环，却必须留下来承担真实后果。警灯终于停止在玻璃上闪烁。

结局摘要：如实承认连环杀人并结束循环问询；你离开房间，仍将面对调查与法律后果。

### e2｜结局：再一次拦停

你把否认重复了一遍。警员低头记录，雨声重新响起。下一秒，车窗外又亮起同样的红蓝灯，问题回到最初：「你知道为什么被拦吗？」后备厢里传来三下敲击。你仍坐在车里，仍有机会说出事实；这一次循环没有替你作答。

结局摘要：矛盾和否认让问询回到起点；循环继续。

### e3｜结局：暴力的尽头

你把暴力带进问询室。画面在警员喊出你的名字时切黑；再亮起时，门外多了急促脚步与呼叫声。没有人把这一步写成胜利。记录本留在桌上，问询结束，责任并未消失。

结局摘要：你选择攻击警员，问询以悲剧中断；没有逃脱，也没有抹去罪责。

### e4｜结局：暂停的呼吸

你转而伤害自己。画面淡出，没有呈现过程。再出现时，警员正在呼叫医疗支援，桌上的记录本仍摊开着。你没有因此离开循环；这段故事停在求助到来的瞬间。

结局摘要：你伤害自己，问询中断并进入紧急救助；故事不把自伤写成逃脱。
