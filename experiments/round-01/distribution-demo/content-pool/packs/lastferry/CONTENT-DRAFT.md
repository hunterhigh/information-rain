# 最后一班渡船｜完整内容稿

作者显示名：林间来信
简介：暴雨封住两岸，小满想在弟弟出生前赶到北岸诊所见母亲。渡船只剩一趟油，你得决定先把谁送到哪里。
阅读时长：8分钟
标签：暴雨、亲情、救援
起点：n1

## 节点与连接
### n1

雨把河面打成一张揉皱的黑纸。林岚把渡船靠在南岸避浪时，听见堤边有人喊救命。一个穿红毛衣的小女孩涉水过来，怀里抱着铁皮饼干盒。她叫小满，母亲在北岸诊所待产；她答应过，弟弟出生前要握住妈妈的手。老周检查油桶：油只够再走一趟。北岸桥断了，救援队至少两小时后才能绕到。

选择：
- left：先带小满到南岸求援，可能错过生产 → n2
- right：立刻载她横渡，拿整趟燃油赌一条近路 → n3

### n2

南岸小卖部亮着应急灯。老板娘拨通诊所，护士说小满母亲血压偏高，已经进产房；药箱里有她平时用的药，但暂时稳得住。接生还没开始。线路随即断了。小满把铁盒递给你，里面装着母亲写给未出生孩子的信。巡堤站有一部手摇警报器，能把求援位置送到上游；小卖部扩音器则只能再用一次。

选择：
- left：用扩音器呼叫诊所，确认母亲情况 → n4
- right：带小满去巡堤站，争取让救援队改道 → n5

### n3

渡船离岸，老周把油门推到底。河中央漂来屋梁，撞上船舷，舵轮偏向下游。老周把备用桨递给你：「要绕过断线，得有人站外沿压船头。你滑下去，我来不及救。」小满把红毛衣袖口系在栏杆上，替船系住一根小小的缆绳。北岸诊所的灯在雨里忽明忽暗。

选择：
- left：站到外沿压住船头，走最短水道 → n6
- up：收油顺流，绕开电线和漂木 → n7

### n4

你按下扩音器，电流声盖过雨声。护士听见了，确认小满母亲还在产房，也告诉你药箱里有她的降压药。她会留在诊所等船，但线路只够再说一句。小满抓住话筒，报出母亲的名字；护士回了一句「我听见了」。扩音器随即烧断。老板娘把药箱和手提灯交给你，巡堤站的救援队正在等一个明确的落点。

选择：
- left：把药和灯带去诊所，优先照顾产房 → n8
- right：把灯送到旧渡口，先接上等候的救援队 → n9

### n5

小满把铁盒留在老板娘手里保管，自己跟你跑向巡堤站。值班员接上手摇警报器，收到上游回复：救援队离诊所还远，可以改去旧渡口，也可以赶往下游学校礼堂。每改一次方向，都要有人留在堤边持续摇铃。小满望着北岸的灯：「我想见妈妈，可那边还有人等。」你们只有一盏手提灯，必须先给救援队一个落点。

选择：
- left：把救援队引去诊所一带，给小满留机会 → n8
- up：把救援队引去礼堂，先救更多受困者 → n9

### n6

你踩上船沿，雨衣被风掀起。船头压过第一道浪，备用桨卡进漂木之间。你用肩膀顶住栏杆，老周把船扳回航道。小满的袖口被扯开，她脱下红毛衣，只穿单薄衬衣，却把布条递来给你包住掌心伤口。前方旧缆桩已断，船只能靠人划最后几十米。

选择：
- left：把备用桨交给小满，一起划向诊所 → n10
- right：用布条固定伤手，自己拉住旧缆绳 → n11

### n7

你收下油门，船被水推向下游。断电线擦过桅杆，火花落进河里。老周把船稳在废弃渡口边。岸上旧助产站的窗里传来三下敲击；与此同时，手摇警报器也听见了学校礼堂有人呼救。小满认出助产站是母亲年轻时工作的地方。靠岸查看可能救出里面的人，却会把船和剩余燃油留在下游。

选择：
- left：靠岸查看旧助产站，先确认敲门的人 → n10
- up：拉响警报通知救援队，转去学校礼堂 → n11

### n8

救援队沿着手摇警报声赶到旧渡口，接走了巡堤员和三户被困人家。小满把母亲写的信交给领队，请他带去诊所；领队答应会沿堤传话，却不能保证赶在生产前送到。雨势稍弱时，远处诊所窗户亮起一次灯。你们可以把最后一段灯油用来照亮诊所方向，也可以留给救援队继续转移人家。

选择：
- left：把灯举向诊所，让小满沿堤赶过去 → e1
- right：留灯照明，帮救援队转移更多人 → e2

### n9

你把手提灯挂在旧渡口，救援队看见后先接走了巡堤员和三户人家。诊所方向仍旧漆黑，扩音器也已经烧坏。小满没有等回音，把母亲的信交给老板娘保管，自己沿堤朝诊所走；你可以跟她走完最后一段，也可以留下引导下一批救援船。老周把空油桶踢到一旁，船已不能再发动。

选择：
- left：陪小满沿堤去诊所，灯交给老板娘 → e1
- right：留下引导救援船，接受她独自赶路 → e2

### e1｜结局：灯抵达的岸

你把灯举向诊所，护士看见后在窗边回闪三次。小满赶到时，母亲刚从产房门口转进里间，血压已经稳住，孩子还没出生。她握住妈妈的手，把信放在枕边。天亮后，弟弟平安出生。你和老周失去了最后的灯油，礼堂的居民只能等下一支救援队；但小满没有错过她答应母亲的那一刻。

结局摘要：小满在弟弟出生前赶到母亲身边；下游礼堂的转移延后。

### e2｜结局：先到的人

你把灯留给救援队，三户人家在雨势重新变大前转移到高地。小满沿堤走到诊所时，弟弟已经出生。母亲平安，身边放着被护士收好的铁盒和那封信。小满没能兑现「出生前握住妈妈的手」的承诺，却亲眼见到了母亲和弟弟。你留在旧渡口继续引船，天亮时才发现老板娘一直举着应急灯，为晚到的人照路。

结局摘要：更多受困者先获救；小满错过生产，却与母亲和弟弟团聚。

### e3｜结局：门外的守候

你先把腿伤老人送上高地，再折回诊所。回程时弟弟已经出生，母亲也脱离危险。小满坐在产房门外，手里攥着那封信；她把信读给刚出生的弟弟听，读到一半才哭出来。礼堂的居民没有赶上这一趟船，救援队随后必须再冒雨折返。老周的手臂被缆绳磨伤，你们把渡船留在岸边，等水退后再修。

结局摘要：旧助产站的伤者先获救；小满晚到产房，礼堂救援需要再冒险一趟。

### e4｜结局：绕远的灯

你把救援船和灯油交给礼堂的领队，十七名居民在水漫过门槛前撤到高地。小满留在诊所，赶上弟弟出生后才走出产房。她把信交给母亲，两人一起读给孩子听。你没有陪她等候，老周也因拉缆绳受伤；但礼堂里的人都活了下来。天亮后，小满把一件干衣服披在老周肩上，问他什么时候能再开船。

结局摘要：十七名礼堂居民及时转移；小满与母亲平安团聚，但错过出生前相见。

### n10

你和小满用备用桨划向诊所。她手臂冻得发抖，仍每隔几下就问一次还有多远。到岸时，护士已经把母亲从产房门口转进里间；她的血压稳住了，生产还没开始。小满终于握住母亲的手，把信放在枕边。护士请求你们把剩下的灯油送到下游礼堂，那里还有十七名居民等着转移。

选择：
- left：留在产房外，陪小满等弟弟出生 → e1
- right：把灯油送去礼堂，留下小满陪母亲 → e4

### n11

你用缆绳把船固定在岸边，旧助产站里困着一名腿伤的老人。你们和救援队合力把他抬出来；他认得小满，告诉她母亲已经转到北岸诊所。救援队的船只够再走一趟：可以先送老人去高地，再折回接小满；也可以载小满去诊所，让礼堂的人等下一趟。小满摸着铁盒边缘，没有催你替她决定。

选择：
- left：先送伤者上高地，再折回接小满 → e3
- right：先送小满去诊所，把礼堂留给下一趟 → e4
