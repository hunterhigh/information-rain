# 第一轮实验登记

状态：旧 product-01 v0.1 仍为不合格的内部机制样本；2026-09-28 另行采纳[双产品方向](../../docs/project/decisions/0006-two-products-and-medium-validation.md)，并引入[分发原型](distribution-demo/DEMO-BRIEF.md)作本地界面维护。以下原候选表是旧实验登记，不再代表当前唯一产品结构。

## 当前承接

- 工具产品：文字拓扑 Agent 是主要功能之一；本轮尚未开始该产品的具体 Demo，不凭分发原型反推工具产品规格。
- 分发产品：保留 Kimi 原型中 30 个作品及 30 张封面；仅改界面、交互和视觉元素。原始内容的 48 条失效路径另行记录，不补写或重定向作品分支。完成本地可用性检查后由项目所有者亲自体验，内容价值不由技术测试代判。
- 媒介验证：保留文字 → 插画 → 短视频的战略顺序，不把第一轮旧文字媒介约束扩大成所有后续阶段的禁令。
- 公开发布前：先按[合规初探](../../docs/research/2026-09-28-distribution-compliance.md)处理热门 IP、内容安全、音乐权利与目标地域；本地/私有仓库测试不代表已经许可。

## 本轮问题

探索信息雨、生成式世界与内容、推荐即生成之间的产品平衡。预计研究和讨论约三个各自值得独立使用的产品；每一个都由外部资料、第一性原理推演和 Agent 的设计判断产生。数量可随研究调整。

项目所有者已查看 product-01 v0.1 并明确指出它没有值得阅读的内容、把机制说明当故事、用官网式入口妨碍体验。此前“自动评审通过、待试用”的判断失效。下一步不是美化 v0.1，而是重新判断产品为了什么、创作一段有自身价值的代表性内容，内容审读通过后再决定如何以最少界面承载。三种短规则样本只作为内部检查材料，不是正式内容体验。其余候选仍须研究、推演和自行选择，不复活旧单轴方案。

项目所有者要求本轮重写同步到私有 GitHub 远端。流程修订与旧版撤回记录已同步；当前分发原型的界面维护与战略记录也应以可追溯提交同步，但不得将此视为产品质量、内容完整性或公开发布通过。
