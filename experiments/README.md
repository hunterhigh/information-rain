# 实验与历史样本

本目录只保存有明确问题、范围和退出条件的实验，以及已结束实验的原始材料。当前分发产品源码已迁入 [`products/distribution/reader-web/`](../products/distribution/reader-web/)。

| 材料 | 状态 | 用途 |
| --- | --- | --- |
| [`round-01/product-01/`](round-01/product-01/) | 已撤回，内部机制样本 | 记录旧样本的机制与失效原因；不是当前产品 Demo。见[归档索引](archive/README.md)和[决定 0005](../docs/project/decisions/0005-content-first-demo.md)。 |
| [`round-01/PLAN.md`](round-01/PLAN.md) | 历史实验计划 | 保留第一轮当时的候选与工作流程，不再代表当前产品路线图。 |
| [`archive/`](archive/README.md) | 历史材料索引 | 标明旧内容为什么留下、哪些结论已被取代。 |
| [`_templates/`](../experiments/_templates/) | 新实验模板 | 仅在路线图批准独立实验后使用。 |

当前产品需求和实施计划分别维护在 [`docs/products/`](../docs/products/README.md)；新实验也必须在合适产品边界内立项，不能把旧候选列表当成自动待办。
